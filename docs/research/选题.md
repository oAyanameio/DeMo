# 历史轨迹缺失条件下基于 DeMo 的可靠运动模式捕捉与多模态行人轨迹预测

_研究框架记录 · 更新时间：2026-08-28 · 当前基础模型：DeMo；当前任务形态：无地图、保留行人交互_

## 一、选题定位

本选题以 **DeMo** 为唯一基础模型，先将其适配为 ETH/UCY 行人多模态轨迹预测模型，再研究历史轨迹缺失条件下的可靠运动模式捕捉。

当前模型只关闭不适用于本任务输入形式的 **HD Map 分支**，仍然保留行人轨迹输入和行人之间的交互建模。因此，本研究是“无地图的交互式行人轨迹预测”，不是“无场景上下文预测”或“单行人独立预测”。

核心问题是：

> **在不使用地图、但保留行人交互的条件下，当历史轨迹存在缺失时，模型能否根据剩余运动证据及其可靠性捕捉合理的连续运动模式，并利用该模式辅助未来多模态行人轨迹预测？**

研究分为两个层级：

| 层级 | 内容 | 定位 |
| --- | --- | --- |
| 基础模型 | 无地图、保留行人交互的 DeMo 行人化重构 | 建立可在 ETH/UCY 上运行的多模态预测基础 |
| 结构调整 | 单向时间 Mamba | 任务适配和时间建模选择，不单独作为核心创新 |
| 研究问题 | 缺失历史下的可靠运动模式捕捉 | 论文需要回答的核心科学问题 |

整体研究链为：

```text
不完整的行人历史轨迹
    -> 有效运动证据与行人交互上下文
    -> 运动证据可靠性估计
    -> 缺失条件下的连续运动模式与动态状态
    -> 可靠性条件化的 DeMo Mode/State 融合
    -> 未来多模态行人轨迹预测
```

DeMo 行人化、关闭地图分支和改用单向 Mamba 是研究基础或结构重构，不单独构成核心创新。需要验证的是：**可靠性条件化的显式运动模式是否比普通隐藏状态或简单输入掩码具有独立的未来预测价值。**

## 二、研究对象与概念边界

### 1. 运动模式

本文中的“运动模式”指由历史轨迹、有效运动证据和行人交互上下文支持的连续运动表示，而不是预先定义的行为类别。由于当前任务不使用地图，地图不属于运动模式的输入条件；周围行人轨迹仍然可以作为社会交互上下文。

第一版以方向—动力学作为可解释核心：

```text
方向证据：位移方向、航向变化、曲率、转向趋势
动力学证据：速度、加速度、速度变化、减速或停止趋势
```

完整的运动模式表示还可以结合：

```text
方向与动力学证据
    + 局部行人交互上下文
    + 缺失可靠性
    + 连续隐状态
```

因此，方向—动力学是第一版的主要解释维度，行人交互与缺失可靠性是影响模式判断的条件，最终表示可以位于连续隐空间中。这里的“方向—动力学”不是对运动模式的封闭定义，而是用于第一阶段诊断和监督的可操作维度。

### 2. 运动模式与运动状态估计

| 概念 | 本选题中的含义 |
| --- | --- |
| 运动模式 | 由方向、动力学和上下文证据支持的连续表示 |
| 运动状态估计 | 对当前方向、速度、加速度、转向趋势等的可操作估计 |
| 普通隐藏特征 | 尚未获得运动学解释的网络潜在向量 |
| 未来轨迹模态 | 未来轨迹分布中的一个可能分支 |

普通隐藏特征不天然等于运动状态估计。只有当表示受到运动学证据约束，并且其质量能够通过状态诊断和未来预测验证后，才可以赋予它运动状态含义。

当前研究不要求中间表示具有严格的 Bayesian belief state 形式，除非后续能够明确输出并验证相应的状态后验分布。

### 3. 缺失历史范围

研究对象是一个固定历史窗口内的缺失历史轨迹：

```text
有效时间步 -> 编码真实运动证据
缺失时间步 -> 屏蔽无效证据并降低可靠性
窗口结束 -> 根据证据可靠性形成模式和状态表示
未来时间段 -> 生成多模态轨迹分布
```

缺失统一称为“缺失历史轨迹”。随机缺失、连续缺失或特定时间位置缺失不再作为彼此独立的研究问题；缺失程度、有效观测比例和观测间隔只用于构造不同难度的输入条件。

研究重点不是先恢复一条确定性的完整历史，而是根据可见证据估计当前运动状态及其不确定性。未来轨迹在训练和评测中保持为完整目标，历史缺失只作用于模型输入。

当前实验按两个阶段控制缺失难度：第一阶段使用 0%、12.5% 和 25% 的 v1 条件建立接口与轻度缺失基线；下一轮扩展到随机缺失 3 帧（37.5%）、4 帧（50%），以及连续缺失 4 帧（50%）和 6 帧（75%），并在相同缺失率下比较随机缺失与连续缺失。下一轮方案仍固定历史帧 6、7 可见，以隔离缺失程度变化与局部坐标锚定变化。

## 三、问题背景与研究动机

### 1. 行人预测需要运动状态信息

行人未来轨迹不仅由历史位置决定，也受到当前运动状态影响。相同的局部位置可能对应继续前进、转向、减速、停止或避让等不同未来。

```text
历史位置
    -> 方向与动力学证据
    -> 当前运动模式
    -> 未来多模态轨迹
```

因此，未来预测不仅需要回答“行人在哪里”，还需要利用历史证据判断“行人正在如何运动”。

### 2. 历史缺失会改变运动证据

历史坐标缺失后，丢失的不只是若干位置值，还可能丢失由位置差分得到的方向、速度、加速度和转向证据。

需要区分：

```text
运动模式没有改变，只是可见观测减少

运动模式已经改变，但关键变化证据被缺失遮蔽
```

当缺失遮蔽运动变化证据时，剩余观测可能不足以判断转向、减速、停止或避让等状态变化。

因此，研究重点不是预设缺失一定破坏模式，而是分析：

> **剩余运动证据能否形成合理的运动模式，以及该模式是否能够带来独立的未来预测收益？**

已有研究表明，不完整历史可以直接用于未来轨迹预测，模型不一定需要先恢复一条确定性的完整历史。本选题进一步关注缺失条件下的运动模式如何形成，以及该模式如何服务于多模态预测。

### 3. 无地图不等于无场景上下文

ETH/UCY 的轨迹数据包含多个行人的共同运动过程。当前研究只移除 HD Map 输入，不移除周围行人轨迹和交互建模。这样做的含义是：

```text
不使用地图几何
    + 保留行人之间的社会交互
    + 聚焦历史运动证据与交互条件下的模式捕捉
```

因此，研究结论应表述为“无地图条件下的交互式行人预测”，不能表述为“完全不依赖场景信息”。如果未来要研究真正的单行人预测，必须另行定义数据接口和实验任务。

## 四、DeMo 的基础作用与可复用设计

DeMo 将多模态预测拆分为方向意图和动态状态，并通过 Attention、Mamba 及其耦合结构生成未来轨迹。这与本选题区分运动模式证据和时间变化状态的设想相匹配。

可以复用的设计包括：

| DeMo 设计 | 在本选题中的作用 |
| --- | --- |
| Mode Queries | 表达多个候选方向运动假设，不对应人工行为标签 |
| State Queries | 表达动态状态的时间演化，并作为历史状态编码的结构参考 |
| Mode Cross-Attention / Self-Attention | 从历史和局部行人交互上下文中选择、区分不同运动证据 |
| Attention + Mamba | 分别聚合关系信息和建模时间序列状态 |
| Hybrid Coupling | 融合方向模式和动态状态，形成未来预测条件 |
| 多模态预测头 | 输出多条未来轨迹及其概率或尺度 |

上述结构用于承载研究问题，mode/state 解耦、Mode Query、Attention 与 Mamba 的组合、原始 Hybrid Coupling 以及多模态预测头本身不单独构成创新。

DeMo 原本面向自动驾驶交通参与者。行人化重构需要围绕行人轨迹输入、邻居交互和 ETH/UCY 评测任务建立适配版本。当前适配只关闭地图分支，保留 actor 交互编码和其他行人相关路径。

### 1. 当前结构调整的准确定位

#### 无地图的交互式行人化

当前模型的任务设定为：

```text
focal 行人及邻居历史轨迹
    -> 每个行人的历史时间编码
    -> 行人之间的交互建模
    -> DeMo Mode/State 解耦
    -> 多模态未来轨迹
```

关闭 `use_map` 只表示跳过车道线和地图特征，不表示删除行人交互。因而“无地图”“地图无关”或“actor-only with social interaction”是准确说法，“无场景上下文”“单行人”是不准确说法。

#### 单向 Mamba 的定位

将 BiMamba 改为 UniMamba 可以作为时间建模结构调整。其合理动机是减少不必要的反向时间扫描、保持历史编码的时间方向一致性并降低结构复杂度，但它不能自动成为新的运动模式理论。

当前代码中，历史编码器的 `bimamba` 参数默认关闭，而时间解码器中的两个 Mamba 分支仍有显式的双向配置。因此，实验时应将各路径的方向性参数显式配置，并把 UniMamba/BiMamba 作为独立消融变量，不能仅凭模块名称推断实际使用的算子。

#### 重新包装的边界

可以将整个方法表述为：

> **无地图交互式 DeMo 基础模型 + 缺失历史下的可靠运动模式捕捉与可靠性条件化 Mode/State 融合。**

其中，无地图适配和 UniMamba 是任务适配或结构选择；真正需要主张的算法贡献是缺失运动证据的可靠性建模、可靠性加权运动证据编码、运动模式质量约束以及 Mode/State 的条件化融合。不能把 DeMo 已有的 Mode/State 解耦、Mode Query、Attention、Mamba 或原始 Hybrid Coupling 直接改名后作为原创模块。

### 3. 理论支撑与研究线索

现有文献对本选题的支撑主要来自“部分观测下的状态估计”和“运动不确定性建模”两条理论链，而不是某一篇论文已经直接解决了本研究问题。

#### 3.1 缺失历史轨迹是隐状态估计问题

将完整历史轨迹记为 `Xₜ`，观测掩码记为 `Mₜ`，实际输入可以表示为：

> **公式：** `X̃ₜ = Mₜ ⊙ Xₜ`

模型需要估计的是当前运动状态或信念状态，而不是简单恢复缺失坐标：

> **公式：** `bₜ = p(Sₜ | X̃₁:ₜ, M₁:ₜ, C₁:ₜ)`

其中 `Sₜ` 表示运动状态，`Cₜ` 表示行人交互上下文。

Sun 等人的 Graph-VRNN 将部分观测下的当前状态估计与未来预测统一到图结构变分模型中[^10]，为本研究提供了从不完整观测中建模运动状态不确定性的参考。因此，缺失时间步不应被当作真实坐标或确定性插补结果参与运动模式学习。

#### 3.2 缺失掩码和时间间隔属于运动证据可靠性

STGN-IT 通过观测状态编码区分可见和不可见轨迹，避免模型把填充值误认为真实位置[^3]。GC-VRNN 使用时间衰减模块学习缺失轨迹中的时序模式，并通过共享时空特征联合处理插补与预测[^11]。GRU-D 则将观测掩码、距上次观测的时间间隔和可学习衰减直接融入时序表示[^16]。

这些研究支持将以下信息统一解释为**运动证据可靠性**：

- 当前时间步是否有真实观测；
- 距离上一次有效观测的时间间隔；
- 当前历史状态应保留多少；
- 证据不足时预测分布应扩大多少。

但 GRU-D 关于缺失模式具有任务信息的结论来自医疗时序数据，不能直接假设适用于行人跟踪。对 ETH/UCY 而言，缺失可靠性应作为模型输入和可验证假设，而不是预先确定的行为因果变量。

#### 3.3 部分观测会造成运动模式歧义

Momentary Observation 将历史观测压缩到极端的两帧，指出加速度、减速和转向等时间运动线索会明显缺失，而速度、社会上下文和场景上下文仍可提供补充信息[^12]。DTO 进一步显示，完整观测教师可以帮助少观测学生恢复部分预测能力，但在复杂转向等动态情况下，少量观测仍不足以确定接近真实轨迹的运动模式[^13]。

这两项研究支持本选题的一个重要边界：

> 缺失历史下不应要求模型恢复唯一确定的运动模式，而应输出与证据可靠性相匹配的连续模式表示或模式分布。

#### 3.4 时变潜变量支持多模态运动模式

Graph-VRNN 使用变分隐变量表示部分观测下的状态不确定性[^10]。SocialVAE 在每个预测时间步引入潜变量，并用条件先验、后向后验和社会注意力建模动态决策与多模态轨迹[^15]。DisDis 则将个体运动模式表示为可区分的潜变量分布，并从概率分布层面评价多模态预测[^14]。

这些工作为 DeMo 的 mode/state 解耦提供了补充支撑：

```text
Mode -> 候选方向或运动模式假设
State -> 随时间变化的动力学状态
Hybrid Coupling -> 模式与状态的组合
```

但 Mode Query 或 State Query 本身不等于真实运动状态。只有当其表示与方向、速度、加速度、转向趋势等运动证据一致，并且能够改善未来轨迹预测时，才能认为它具有运动模式含义。

#### 3.5 插补、直接预测与实验评价

GC-VRNN 和 MS-TIP 说明插补与未来预测可以通过共享时空表示联合建模[^11][^5]。TrajImpute 则通过均匀随机缺失、不同缺失程度和统一评价协议，展示了插补误差增加会导致预测性能下降，并指出直接处理缺失坐标的预测模型仍有必要[^6]。

对本研究而言，这些工作提供三点线索：

1. 缺失历史轨迹必须保留在评测中，不能只保留完整样本；
2. 插补结果不能默认等价于真实观测，应保留缺失可靠性信息；
3. 运动模式质量和未来预测质量应同时评价。

随机缺失可以作为构造缺失历史轨迹的实验方式，但不再被定义为独立的研究类型。

#### 3.6 可靠运动模式捕捉的拟议机制

以下内容是用于界定研究假设的概念层机制，不是已经确定的网络层实现。具体采用何种编码器、门控形式或损失函数，应以后续对照实验结果为准。

本选题中的“可靠”不是简单地把有效掩码再次拼接到输入，而是要求模型显式区分真实观测、由真实观测计算出的运动证据和缺失时间步的无效证据。

每个历史时间步可以由以下信息构成运动证据：

```text
位置位移、速度、加速度、方向或曲率
    + 当前时间步是否有真实观测
    + 当前运动证据是否能够由足够的有效观测计算得到
    + 距上一次有效观测的时间间隔
    + 历史窗口中的有效观测比例
```

观测掩码与运动证据掩码不能混为一谈。例如，当前和前一时刻都有位置观测，才可以计算该时间间隔的位移和速度；加速度、曲率和转向趋势通常还需要更多连续有效观测。对于无效时间步，不应通过零填充位置继续计算速度或加速度，否则模型可能将“缺失”误认为“停止”。可定义运动证据可靠性 `ρₜ`：

> **公式：** `ρₜ = f(观测掩码、运动证据掩码、距上一次有效观测的时间间隔、有效观测比例)`

最简单的先验形式是：有效观测的可靠性接近 1，缺失时间步的可靠性随时间间隔增加而衰减。更复杂的形式可以由网络学习，但必须通过实验验证其是否具有实际意义。

运动证据编码可以使用掩码、时间间隔和可学习衰减进行可靠性加权：有效运动证据参与表示学习，缺失时间步的证据被屏蔽或降权，时间间隔越长，可靠性越低。该设计不要求额外增加独立的时序分支。

在此基础上，运动模式可以由 focal 行人的历史表示、有效运动证据和邻居交互上下文共同形成。Mode 表示较长期的候选运动趋势，State 表示随时间变化的动态状态。二者都应是连续表示，不要求预先建立固定的“直行、转弯、停止”等行为类别。若解码阶段使用的是历史窗口级可靠性，应使用历史可靠性摘要，而不能把未来真实观测掩码作为输入。

#### 3.7 可靠性条件化的 Mode/State 融合

原始 DeMo 的 Hybrid Coupling 主要通过模式查询和状态查询的组合形成混合查询。若直接采用固定相加：

> **公式：** `qₖ,ₜ = qₘᵏ + qₛᵗ`

则没有显式考虑当前运动证据是否可靠。

本选题拟研究可靠性条件化的融合方式。可以定义模式—状态门控：

> **公式：** `gₖ,ₜ = σ(MLP([qₘᵏ, qₛᵗ, ρH, c]))`

并使用：

> **公式：** `qₖ,ₜ = LN(qₘᵏ + gₖ,ₜ Wₛ qₛᵗ + Wc c)`

其中 `qₘᵏ` 是第 `k` 个运动模式，`qₛᵗ` 是第 `t` 个动态状态，`c` 是历史窗口对应的邻居行人交互上下文，`ρH` 是由历史证据得到的可靠性表示。

该机制的目标不是在缺失时强行选择一个模式，而是：

```text
证据充分 -> 模式与动态状态进行更确定的耦合
证据不足 -> 保留多个合理模式，减少过早模式坍缩
缺失间隔增加 -> 预测分布表达更大的不确定性
```

因此，可靠性还可以输入轨迹尺度和模态概率预测头，使缺失程度同时影响模式表示、模式—状态融合和最终预测分布。

#### 3.8 训练约束与可验证表示

可靠运动模式不能只通过论文命名获得，需要在训练和评测中获得运动学证据支持。可在原始 DeMo 预测损失之外加入少量辅助约束：

> **公式：** `ℒ = ℒDeMo + λkin ℒkin + λcons ℒcons`

`ℒkin` 用于约束 Mode/State 表示能够预测方向、速度、加速度或转向趋势；`ℒcons` 用于约束同一完整轨迹在完整输入和缺失输入下的表示一致性。不同 Mode Query 存在排列问题，比较前需要根据预测轨迹或模式距离进行匹配。

训练时可以使用完整历史轨迹构造缺失版本，完整历史只提供监督信号，不作为缺失输入的一部分。这样可以研究模型是否从剩余证据恢复合理表示，而不是依赖完整历史。

该设计不要求额外加入插补网络、外部生成式对照或固定行为分类器。最小研究方法应优先验证“可靠性估计 + 可靠性加权运动证据编码 + 条件化融合”这一条主线。

#### 3.9 当前优先方法路线

结合上述文献，当前最推荐的不是同时堆叠多个完整模型，而是形成一条清晰的最小方法链：

```text
GRU-D：观测掩码 / 时间间隔 / 状态衰减
    + DeMo：Mode / State 解耦骨架
    + DeMo++：Mode / State 的运动学和时序监督线索
    + FiLM 或 GMU：可靠性条件化融合
    -> 缺失可靠性条件化的因果 DeMo
```

其中，FiLM 和 GMU 是条件化融合的两种可选实现，不建议第一版同时引入。优先方案是使用由历史可靠性生成的门控，对 Mode 与 State 的耦合强度进行调节：

> **公式：** `gₖ,ₜ = σ(MLP([qₘᵏ, qₛᵗ, ρH, c]))`

> **公式：** `qₖ,ₜ = qₘᵏ + gₖ,ₜ Wₛ qₛᵗ`

该路线不要求复刻每篇论文的完整网络，而是提取以下四个可组合机制：

| 机制 | 主要参考 | 在本选题中的作用 |
| --- | --- | --- |
| 掩码、时间间隔与衰减 | GRU-D [^16] | 构造运动证据可靠性并控制历史状态保留程度 |
| Mode/State 表示与辅助监督 | DeMo [^1]、DeMo++ [^17] | 形成连续运动模式、动态状态及其运动学诊断 |
| 条件化融合 | FiLM [^18]、GMU [^19] | 让可靠性决定 Mode/State 或交互信息的融合强度 |

### 5. 文献支撑下的研究空白

上述文献已经分别解决或讨论了缺失轨迹输入、部分观测状态估计、轨迹插补、短观测预测、时变潜变量和多模态生成。因此，本研究不应声称“首次研究缺失轨迹预测”或“首次利用隐状态处理缺失”。

更准确的研究空白是：

> 现有方法主要关注缺失坐标处理、轨迹插补或最终预测误差。本研究拟进一步统一缺失历史轨迹、可靠运动证据、连续运动模式、行人交互上下文和 DeMo 的 mode/state 多模态预测，并验证运动模式质量是否能够独立传递到未来预测。

本研究的核心线索因此收敛为：

```text
缺失历史轨迹
    -> 有效运动证据与行人交互上下文
    -> 运动证据可靠性
    -> 缺失条件下的连续运动模式与动态状态
    -> 可靠性条件化的 DeMo mode/state 融合
    -> 未来多模态轨迹预测
```

## 六、核心科研问题与假设

### 总问题

> **当历史轨迹存在缺失时，基于 DeMo 的行人轨迹预测模型能否从剩余运动证据中捕捉合理的连续运动模式，并利用该模式辅助未来多模态行人轨迹预测？**

### 子问题

1. **运动证据与模式捕捉**

   历史轨迹不完整时，哪些有效观测仍能支持方向、速度、加速度和转向趋势判断？缺失程度如何影响运动证据可用性？

2. **缺失条件下的模式表示**

   如何利用有效观测、缺失程度、时间间隔和局部行人交互上下文，形成比普通隐藏特征更具有运动学含义的连续运动模式表示？

3. **模式对未来预测的辅助作用**

   显式运动模式表示是否能够改善未来多模态轨迹预测，并在转弯、减速、停止和避让等场景中优于不显式捕捉运动模式的 DeMo 基线？

4. **Mode/State 的可靠性条件化**

   当运动证据可靠性随时间和缺失程度变化时，如何自适应地调整 Mode 与 State 的提取、耦合和预测不确定性，避免固定融合导致的模式过早确定或动态状态误用？

### 核心假设

```text
不完整历史
    -> 有效方向/动力学运动证据与行人交互上下文
    -> 运动证据可靠性
    -> 缺失条件下的运动模式与动态状态
    -> 可靠性条件化的 Mode/State 融合
    -> DeMo 多模态未来预测
```

核心假设为：

> **在历史轨迹缺失条件下，利用观测可靠性形成并融合运动模式与动态状态，比普通隐藏状态、简单输入掩码或固定 Mode/State 融合更能辅助未来多模态轨迹预测。**

该假设需要通过模式诊断和真实未来预测共同验证。

## 七、拟形成的个人创新点

### 1. 缺失运动证据的可靠性建模

针对历史轨迹缺失后运动证据不完整、差分量不可靠的问题，显式建模观测掩码、有效观测间隔和历史有效比例，将它们统一为运动证据可靠性。该可靠性不只是输入特征，还用于调节运动证据编码、Mode/State 表示和预测不确定性。

这部分的基本逻辑是：

```text
真实观测 -> 可靠性加权编码
缺失时间步 -> 无效证据屏蔽与可靠性衰减
窗口结束 -> 形成带可信度的模式/状态表示
```

它借鉴部分观测状态估计和缺失感知时序建模的思想，但研究对象转为行人轨迹中的方向、动力学和交互条件，不声称重新提出缺失数据处理的一般理论。

### 2. 缺失可靠性条件化的 DeMo Mode/State 建模

DeMo 已经提供 Mode/State 解耦骨架。本选题不重新提出该解耦，而是研究可靠性如何进入其内部：

- 有效时间步如何贡献真实方向和动力学证据；
- 缺失时间步如何避免注入伪证据；
- 缺失间隔和可靠性如何影响 mode/state 表示；
- Mode 与 State 如何根据证据可靠性自适应耦合；
- 证据不足时如何保留合理的多模态不确定性。

拟形成的核心方法表述为**缺失可靠性条件化的 DeMo Mode/State 表示与融合**，而不是将原有 Mode/State 解耦简单改名。

### 3. 运动模式的可验证性与预测价值

已有 DeMo 的查询向量不天然具有真实运动学含义。因此，本选题需要通过辅助运动学任务、完整/缺失输入一致性和未来预测结果共同验证：

- 运动模式与完整历史运动证据的一致性；
- 方向、速度、加速度和转向趋势误差；
- 缺失程度增加时的不确定性变化；
- 转弯、减速、停止和避让场景中的未来预测误差；
- 显式运动模式相对于普通隐藏状态的独立收益。

只有当模式质量改善能够传递到真实未来轨迹，并且收益不能由额外参数量或简单掩码输入解释，才能支持方法有效。

### 4. 研究包装与贡献边界

建议将论文整体包装为：

> **无地图交互式 DeMo 基础模型 + 缺失历史下的可靠运动模式捕捉与可靠性条件化 Mode/State 融合。**

更凝练的方法叙事是：

> 本文研究无地图但保留行人交互的历史轨迹预测，在历史观测缺失时，将可见运动信息、观测可靠性和交互上下文统一用于连续运动模式与动态状态估计，并据此进行多模态未来预测。

其中各部分的归属应明确：

| 内容 | 归属 |
| --- | --- |
| ETH/UCY 行人化和无地图输入 | 数据集与任务适配 |
| 保留行人交互 | 任务设定和条件信息 |
| UniMamba | 时间建模结构选择 |
| DeMo Mode/State 解耦 | 基础模型复用 |
| 缺失可靠性估计 | 拟议方法机制 |
| 可靠性加权运动证据编码 | 拟议方法机制 |
| 可靠性条件化的 Mode/State 融合 | 拟议方法机制 |
| 运动学辅助约束和模式诊断 | 可验证性设计 |

不能仅把 DeMo 的 Mode Query、State Query、Attention、Mamba、原始 Hybrid Coupling 或多模态预测头换一种术语后宣称为原创贡献。

## 八、验证框架与实验方向

### 0. 已有基础实验线索

已有的 ETH/UCY 留出对照实验在相同数据协议和评测口径下比较了单向与双向 Mamba。8 帧观测、12 帧预测、`K = 20` 的实验结果显示：

| 结构 | 平均 minADE20 | 平均 minFDE20 |
| --- | ---: | ---: |
| DeMo 单向 Mamba | 0.232 | 0.389 |
| DeMo 双向 Mamba | 0.244 | 0.416 |

双向版本相对单向版本的平均误差更高，且在 ETH 场景退化最明显；这为当前优先采用 UniMamba 提供了经验依据，但不能推出单向 Mamba 在所有数据和实现条件下必然更优。该结果来自既有的 `K=20` 留出实验，最终研究配置若采用其他模态数量，必须重新报告并保持口径一致。详细记录见 [ETHUCY结果对照表](/home/lbh/DeMo/docs/results/ETHUCY结果对照表.md)。

该实验只能支持以下判断：

```text
UniMamba 是当前更合理的基础结构选择
    != UniMamba 本身构成研究创新
    != 双向 Mamba 在所有设置下都无效
```

此外，运行环境和 `mamba_ssm` 版本可能影响 `bimamba` 参数是否真正生效。正式实验必须确认实际使用的算子和方向性配置，不能只依据配置文件名称解释结果。

### 1. 前置验证链

| 阶段 | 验证问题 | 目的 |
| --- | --- | --- |
| P0 | 无地图、保留行人交互的 DeMo 行人化基础模型能否稳定完成标准轨迹预测 | 确认任务适配和基础模型可用 |
| P1 | 缺失历史轨迹是否造成可测量的运动证据损失 | 判断缺失条件是否具有分析价值 |
| P2 | 不完整历史下能否通过可靠性建模捕捉与完整历史相符的运动模式 | 判断表示和可靠性估计是否合理 |
| P3 | 可靠性条件化的 Mode/State 是否改善真实未来预测 | 判断拟议方法是否具有独立收益 |

P1 用于确认缺失历史轨迹是否会造成可测量的运动证据损失，真正需要关注的是显式运动模式在未来预测上是否具有独立收益。

### 2. 缺失条件

实验统一使用“缺失历史轨迹”描述输入条件。缺失程度和有效观测比例只用于构造不同难度的受控样本，不形成独立的缺失类型研究主线。

基础 benchmark 阶段使用完整历史，先验证 DeMo 的 ETH/UCY 迁移能力；缺失研究阶段再从完整历史构造缺失输入，并保持未来轨迹监督目标完整。这样可以将任务适配误差与缺失建模收益分开。

初始缺失实验宜先保证 focal 行人的观测窗口末帧有效，使局部坐标原点和朝向基准保持定义良好；如果允许末帧也缺失，则必须同时重新定义参考位置、参考朝向、预测起始时刻及其时间间隔，不能直接沿用完整观测设置。

### 3. 评价维度

| 维度 | 评价内容 |
| --- | --- |
| 标准预测 | ADE、FDE、minADE、minFDE |
| 模式质量 | 方向、速度、加速度、曲率和转向趋势误差 |
| 模式一致性 | 与完整历史运动证据的差异 |
| 缺失鲁棒性 | 不同缺失程度下的性能曲线 |
| 行为场景 | 转弯、减速、停止、避让窗口误差 |
| 不确定性 | 覆盖率、Energy Score、可靠性和过度自信 |

## 九、对照关系与判断标准

基础模型锁定为 DeMo 后，对照关系按研究问题分层：

1. 完整历史 DeMo；
2. 完整历史与 UniMamba 的 DeMo 行人化模型；
3. 缺失历史与基础输入处理的 DeMo；
4. 缺失掩码直接输入的 DeMo；
5. 普通隐藏状态编码的 DeMo；
6. 时间间隔衰减与可靠性加权基线；
7. 显式方向—动力学运动证据表示；
8. 缺失可靠性条件化的运动模式表示；
9. 缺失可靠性条件化的 Mode/State 融合；
10. 完整研究方法。

### Go 条件

- DeMo 行人化基础模型能够稳定完成标准轨迹预测；
- 不完整历史下能够捕捉具有合理运动学含义的运动模式，或合理表达其不确定性；
- 显式运动模式在相近参数量下优于普通隐藏状态；
- 模式质量改善能够传递到真实未来轨迹；
- 结果不只存在于单一缺失程度、单一行为场景或单一数据场景；
- 缺失程度增加时，模型能够保持合理的不确定性表达。

### No-Go 条件

- 普通隐藏状态或简单缺失处理已经解释全部收益；
- 模式内部指标改善但未来轨迹不改善；
- 收益完全来自额外参数量或额外输入信息；
- 结果只在单一缺失程度或单一场景成立；
- 模型需要完整历史或未来信息才能形成模式表示。

## 十、研究范围与待确定事项

本文档只保留研究问题、基础模型定位、概念边界、相关研究启示、创新假设、验证逻辑和判断标准。网络层修改、数据接口、缺失掩码生成、损失函数、训练配置和具体实验脚本另行设计。

当前仍需通过实验确定的事项包括：

- 可靠性采用固定衰减、可学习函数，还是二者的组合；
- 可靠性加权主要作用于运动证据编码、Mode/State 表示提取，还是二者同时作用；
- Mode/State 条件化主要作用于表示提取、Hybrid Coupling，还是同时作用于预测尺度和模态概率；
- 运动学辅助约束是否带来超出简单掩码输入的独立收益；
- 最终采用的模态数量、缺失难度和评测指标口径。
