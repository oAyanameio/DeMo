# 缺失历史轨迹条件下行人未来运动的结构化多模态预测

## 一、选题定位

行人轨迹预测通常以检测与跟踪系统输出的历史轨迹为输入。然而，遮挡、漏检、短时跟踪中断、帧丢失与定位误差会使历史轨迹出现缺失或时间断裂。完整、连续的固定长度历史轨迹因此并不是始终可得的前提。

本选题研究**缺失历史轨迹条件下的行人多模态轨迹预测**：给定不完整的历史观测、缺失位置及其时间结构，直接预测行人的完整未来轨迹分布。研究目标不是将缺失帧逐点恢复为唯一历史，而是从可见轨迹片段和观测缺失结构中构造可用于未来预测的历史上下文。

DeMo 为本研究提供结构化多模态预测的基础框架。其核心思想可表述为：未来轨迹分布同时包含两类结构，一类是不同候选未来之间的整体差异，另一类是单条候选轨迹沿时间轴的动态演化。DeMo 分别表示这两类结构，并通过联合表征参数化完整的未来轨迹分布[^1]。本研究将这一结构化预测思想引入缺失历史行人轨迹预测，使历史观测缺失不仅作为输入扰动，而是作为条件未来分布建模的一部分。

核心科学问题是：

> **在行人历史轨迹因观测中断而不完整的条件下，如何将可见轨迹片段与缺失结构转化为有效的预测条件，并对未来轨迹分布中的跨候选差异和轨迹内时序演化进行联合建模，从而生成多模态且时间连续的未来轨迹？**

研究定位分为五个层次：

| 层次 | 内容 | 在选题中的作用 |
| --- | --- | --- |
| 现实背景 | 遮挡、漏检、跟踪中断等导致历史轨迹缺失 | 给出问题来源和应用需求 |
| 预测任务 | 不完整历史观测条件下的行人未来轨迹预测 | 定义输入、输出与评测对象 |
| 历史建模 | 观测缺失感知的时序历史表征 | 从可见片段、缺失掩码和时间间隔中构造预测上下文 |
| 未来建模 | 跨候选差异与轨迹内时序演化的结构化条件建模 | 保持多模态性与时间连贯性 |
| 结果验证 | 完整未来轨迹上的准确性、覆盖性、连续性和缺失鲁棒性 | 判断方法是否解决任务问题 |

整体研究链为：

```text
检测/跟踪观测缺陷
    -> 缺失或时间断裂的历史轨迹 X^obs
    -> 观测掩码 M、时间间隔 Delta 与有效运动片段
    -> 共享骨干上下文 H^base（M0）
    -> 缺失观测条件化上下文 H^miss
    -> 未来轨迹的跨候选差异表征 D_1:K
       + 轨迹内时序演化表征 S_1:T_f
    -> 结构化条件未来分布 p(Y_1:T_f | X^obs, M, Delta, C)
    -> 多模态行人未来轨迹预测
```

本选题的核心不是将某一种时序网络本身包装为创新，也不是把编码器隐式特征直接解释为真实“运动意图”或“物理状态”。整体编码器负责聚合历史时序证据、观测结构和行人交互信息；DeMo 的 Mode/State 结构提供未来分布的结构化参数化。为避免基础模型能力不足掩盖缺失感知机制，研究路线分为“共享骨干”与“缺失感知方法层”两层：前者为经过三环境验证的 M0 基线，后者研究缺失观测如何改变历史表征与结构化未来分布。研究创新仍应落在**缺失历史任务建模与缺失条件如何进入未来分布建模**，而不是简单叠加通用网络组件。

### 1.1 共享骨干与方法层版本

当前 DeMo 与公开强基线之间仍存在绝对性能差距，因此不能把所有后续提升都归因于缺失感知设计。M0 为共享骨干与滚动基线：所有方法层版本与 M0 共用相同模型结构、优化配置与评测口径，只在训练目标或训练分布上做单变量增量。这样可以分别回答两个问题：

1. M0 在零缺失条件下能否提供稳定的预测能力（已由 Clean 基线回答）；
2. 在相同骨干上，显式建模缺失过程是否仍能带来独立收益。

模型版本统一定义如下：

| 版本 | 定义 | 研究定位 |
| --- | --- | --- |
| `M0` | 原始 DeMo + 掩码拼输入；Clean 与 TrajGap-Bench Mixed 为当前主协议，旧 Easy/Hard-direct 数字仅作历史 screening | 滚动基线与共享骨干 |

方法层当前无候选版本（2026-09-16 清空）：后续版本与 M0 共用相同模型结构、优化配置与评测口径，只在训练目标、输入特征或训练分布上做单变量增量。

任何版本通过确认性门槛后更新滚动基线；未通过则整体删除，不进入后续组合。

## 二、问题定义与概念体系

### 1. 缺失历史轨迹预测任务

记完整历史轨迹为 `X_1:T_h`，未来轨迹为 `Y_1:T_f`，历史观测掩码为 `M_1:T_h`。其中，`M_t = 1` 表示第 `t` 个历史时刻具有有效观测，`M_t = 0` 表示该时刻的轨迹观测缺失。实际输入可记为：

> **公式：** `X^obs_t = M_t ⊙ X_t`

除位置观测外，模型还可以使用由观测过程导出的时间信息：

```text
M_t       : 当前时刻是否存在有效观测
Delta_t   : 距离最近一次有效观测的时间间隔
E_t       : 由足够有效观测计算得到的运动证据，例如位移或速度
C         : 行人交互上下文
```

任务目标是建模：

> **公式：** `p_theta(Y_1:T_f | X^obs_1:T_h, M_1:T_h, Delta_1:T_h, C)`

未来轨迹在训练和评测中保持完整，缺失只发生在输入历史窗口。轨迹插补可以作为对照方法或可选辅助，但不是本选题的主目标；主目标始终是**缺失历史条件下的未来预测质量**。

### 1.2 误差结构分解与改进依据

预测性能随缺失退化的误差来源与当前覆盖设计：

| 层 | 误差来源 | 覆盖设计 |
| --- | --- | --- |
| ① | 编码器不知道哪些帧可信 | M0 已内置（掩码拼输入）；不再单独设版本 |
| ③ | **证据塌缩**：缺失越大，模态概率越自信、分布越窄，MR 恶化 | 待构思 |
| 泛化层 | 训练缺失分布（Easy 0–4 帧）与高缺失测试分布（Hard 4–7 帧）不匹配 | 待构思 |

关键事实基础：历史 Easy-direct screening 按缺失等级分组显示，MR 的恶化速度显著超过 minFDE（如 ETH 场景 m=0→m=4：MR 约 +50% vs minFDE 约 +9%），表明 best-of-K 之外的概率质量退化是缺失条件下未被现有 direct 方法处理的主要误差源；在当前 TrajGap-Bench Mixed-test 中，缺失等级仅作为内部诊断维度。插补路线（MS-TIP/GC-VRNN/BRITS）不改变预测器的概率头，同样未覆盖此层。误差层③与泛化层是方法层重构时的候选切入点（诊断事实保留，机制假设重新构思）。

### 2. 缺失历史的现实含义与实验抽象

本选题中的“缺失历史轨迹”指历史窗口内部分时刻没有可用的行人位置观测，或观测序列在时间上不连续。它对应以下真实观测现象：

```text
遮挡或视野离开              -> 短时位置不可见
检测漏检或帧丢失            -> 离散时间步缺失
跟踪中断或重新关联          -> 连续历史片段断裂
定位质量下降                -> 后续可扩展为噪声与缺失共存
```

第一版以**历史帧缺失与连续断裂**为可控研究对象。随机缺失、连续缺失、不同缺失比例和不同缺口位置是构造任务难度与模拟观测中断的实验条件，而不是彼此割裂的研究主题。若后续加入坐标噪声、误检或身份切换，应将其作为扩展的观测退化模型，而不是提前并入当前结论。

### 3. 未来轨迹的结构化条件分布

普通多模态预测通常直接从历史上下文产生 `K` 条候选未来。结构化未来建模则进一步规定未来分布的组织方式：未来不是若干条彼此独立的完整轨迹，而是由“候选未来之间的差异”和“单条候选内部的时序演化”两类关系共同决定。前者负责区分不同的未来分支，后者负责组织每条轨迹随时间的变化。

这里的“结构化”指：

```text
不是一个隐藏向量直接对应一条完整轨迹；
而是先表示未来候选之间的差异结构，
再表示单条未来沿时间轴的演化结构，
最后对两类结构进行联合参数化。
```

记：

```text
D_k       : 第 k 个候选未来的跨候选差异表征
S_1:T_f   : 沿预测时间演化的轨迹内时序表征
Q_k,1:T_f : D_k 与 S_1:T_f 的联合未来表征
```

则可将未来轨迹分布理解为：

> **公式：** `p_theta(Y | H^miss, C) = sum_k pi_k p_theta(Y | Q_k,1:T_f, H^miss, C)`

其中：

> **公式：** `D_1:K = f_cross(H^miss, C)`

> **公式：** `S_1:T_f = f_time(H^miss, C)`

> **公式：** `Q_k,t = Phi(D_k, S_t, H^miss, C)`

因此，结构化未来建模可以写成：

```text
历史条件 H
    -> 跨候选差异表征 D_1:K
    -> 轨迹内时序演化表征 S_1:T_f
    -> 联合未来表征 Q_1:K,1:T_f
    -> 多模态未来轨迹分布
```

这是一种对未来轨迹分布的**分解表示与联合参数化**。它不要求 `D_k` 或 `S_t` 对应某个可以直接观测的心理或物理变量。DeMo 原文中的 `Mode Query` 可对应跨候选差异表征，`State Query` 可对应轨迹内时序演化表征，`Hybrid Coupling` 则对应二者的联合参数化[^1]。

### 4. 核心术语

| 术语 | 本选题中的含义 |
| --- | --- |
| 缺失历史轨迹 | 具有缺失时间步或时间断裂的行人历史观测序列 |
| 缺失结构 | 掩码、缺失位置、连续缺口长度、观测间隔等观测过程信息 |
| 缺失感知历史表征 | 同时编码可见轨迹片段及其缺失结构的预测上下文，不将缺失值当作真实运动值 |
| 跨候选差异表征 | 描述多个合理未来分支之间的差异结构，对应 DeMo 的 Mode 维度 |
| 轨迹内时序演化表征 | 描述单条未来轨迹沿时间轴的变化结构，对应 DeMo 的 State 维度 |
| 联合未来表征 | 将跨候选差异与轨迹内演化联合起来，参数化具体未来轨迹 |
| 多模态未来预测 | 对同一历史观测给出多个可能未来分支及其概率或尺度 |
| 时空上下文编码器 | 对带缺失结构的历史轨迹、有效运动关系和行人交互进行联合编码 |

## 三、问题背景与研究动机

### 1. 完整历史假设与真实观测条件之间存在差距

现有行人轨迹预测通常在完整、连续且等间隔的历史轨迹上训练和评测。该设定有利于模型从位置差分中获得速度、方向和转向趋势，但与检测跟踪系统的实际输出存在差距：一旦历史中出现缺口，部分运动变化不再可直接计算，最近观测状态与预测起点之间也可能发生时间脱节。

因此，缺失历史不是单纯少了若干坐标，而是改变了模型可使用的历史时序证据及其时间组织方式。

### 2. 缺失值不能被视为普通轨迹值

对缺失位置进行零填充、前向填充或直接插补后再输入普通预测器，容易混淆以下信息：

```text
真实静止                != 位置缺失后的零位移
低速或减速              != 长时间没有新观测
连续转向趋势            != 被缺口切断后的局部片段
最近状态可见            != 最近状态距离预测起点较远
```

因而，历史编码需要显式区分“观察到的运动几何”和“观察过程本身”，使模型能够根据缺失位置与时间间隔判断哪些历史关系可用、哪些关系不能被当作确定事实。

### 3. 缺失历史会放大未来分布建模难度

行人未来本身具有多模态性：继续前行、转向、减速、停走与避让等运动结果可以共享相似的局部历史。历史发生缺失后，多条未来之间的区分证据进一步减少，普通的一轨迹一查询式预测容易出现两类问题：

```text
多条候选轨迹趋同，无法覆盖合理未来分支；
单条候选轨迹缺少时间连贯性，速度或转向变化不稳定。
```

因此，需要同时解决两个问题：一是从不完整历史中建立有效条件上下文，二是用适合多模态未来的结构化方式表示未来分布。

### 4. 从 DeMo 原始建模视角重新表述缺失历史任务

如果沿用 DeMo 原论文的问题意识，本任务不应首先被描述为“给轨迹模型增加一个缺失掩码”，而应被描述为：**DeMo 原本在完整历史证据下进行运动分解；当历史证据不完整时，这种分解中的两个条件变量都变得不充分，需要研究结构化运动预测如何适应证据缺失。**

#### 4.1 原始 DeMo 实际解决的问题

DeMo 的出发点不是把未来直接看成若干条彼此独立的坐标序列，而是把未来运动拆成两个相互作用的因素：

```text
历史轨迹与场景上下文
        -> Mode Localization：定位不同未来分支
        -> State Consistency：组织每个未来分支内部的时间演化
        -> Hybrid Coupling：将分支差异与时间状态组合
        -> 多模态未来轨迹及其概率/尺度
```

从当前实现对应到 DeMo 的原始模块：

| 原始模块 | 原始任务中的作用 | 不能直接偷换成的含义 |
| --- | --- | --- |
| Scene Context Transformer + 历史 Mamba | 从历史轨迹和其他行人中形成预测上下文 | 不是可直接观测的真实意图或物理状态 |
| State Query / State Consistency | 根据场景条件组织未来沿时间轴的动态演化，并产生 dense prediction | 不是对真实隐藏状态的逐时刻测量 |
| Mode Query / Mode Localization | 在上下文基础上定位多个可能的未来运动分支，并输出候选及其概率 | 不是预先定义的行为类别分类器 |
| Hybrid Coupling | 将每个 mode 与每个 future time state 联合起来，形成具体候选轨迹 | 不是重新提出 Mode/State 解耦本身 |

因此，原始 DeMo 隐含了一个关键前提：**历史编码得到的上下文足以支持未来分支定位和未来时间演化。** 在完整历史上，这一前提通常较为合理；在历史出现缺口时，它需要被重新检查。

#### 4.2 缺失历史改变的不是输入维度，而是运动分解的证据条件

缺失历史会同时影响 DeMo 的两个预测因素，但影响方式不同：

1. **对 Mode Localization 的影响：未来分支定位变得不确定。**
   观测缺失可能抹掉转向、停走、避让等区分不同未来的关键证据。模型面对相同的可见片段时，可能对应多个合理未来；如果仍按完整历史的证据强度输出 mode 概率，候选分支可能覆盖不足，或者概率分布过度自信。

2. **对 State Consistency 的影响：未来时间演化的锚点变弱。**
   缺口会使速度、方向、加速度和最后有效观测到预测时刻之间的时间关系不完整。此时问题不只是“未来应该往哪个方向走”，还包括“从什么运动状态、以多大的不确定性开始继续演化”。

3. **对 Hybrid Coupling 的影响：分支不确定性与时间演化不再能独立处理。**
   某种未来分支的合理性取决于缺失期间可能发生的运动变化；反过来，缺失造成的动态不确定性也可能改变不同 mode 的相对概率。因此，缺失结构不能只被视为编码器输入端的附加标记，还需要检验它是否改变 mode、state 及二者耦合时的条件关系。

这给出了一个比“缺失值处理”更贴近 DeMo 原论文的任务表述：

> **在不完整历史观测下，DeMo 原本依赖的运动分解证据被削弱。研究问题是如何使未来分支定位、轨迹内时间演化及其联合耦合适应不同程度和不同时间结构的观测证据，而不是简单恢复一条唯一的完整历史。**

#### 4.3 用 DeMo 的符号重写任务

在完整历史任务中，可以将 DeMo 的条件上下文记为：

```text
H = Enc(X, C)
```

其中 `X` 是完整历史，`C` 是场景交互上下文。缺失历史任务的条件上下文应写为：

```text
H^obs = Enc(X^obs, M, Delta, C)
```

其中 `M` 描述哪些历史观测有效，`Delta` 描述观测间隔或距最近有效观测的时间关系。于是 DeMo 的结构化未来分布可以被重新表述为：

```text
H^obs
   -> D_1:K^obs, pi_1:K^obs       （缺失条件下的未来分支与概率）
   -> S_1:T_f^obs                  （缺失条件下的未来时间演化）
   -> Q_k,t^obs = Phi(D_k^obs, S_t^obs, H^obs, C)
   -> Y_1:K,1:T_f
```

概念上，条件未来分布从原始的：

```text
p(Y | X, C)
```

改写为：

```text
p(Y | X^obs, M, Delta, C)
```

这不是声称重新发明 DeMo 的概率分解，而是把 DeMo 原有的“由历史证据条件化未来运动”明确扩展到观测过程不完整的条件空间。需要通过实验确定的是：`M` 和 `Delta` 只影响历史上下文是否足够，还是还必须影响 mode 概率、state 演化以及 Hybrid Coupling。

#### 4.4 可直接用于论文 Introduction 的换说法

> DeMo 将行人未来运动建模为两个相互关联的结构：不同候选未来之间的运动分支差异，以及每条候选轨迹沿预测时间轴的动态演化。该建模方式默认历史轨迹能够提供足够完整的运动证据，用于定位未来分支并初始化其时间演化。然而，在真实检测与跟踪系统中，遮挡、漏检和跟踪中断会使历史观测出现时间缺口。此时，缺失不仅减少了输入坐标，还会同时削弱未来分支定位所需的行为证据和未来状态演化所需的运动锚点。因而，缺失历史预测的核心问题不是将观测恢复为某一条唯一轨迹，而是研究在观测证据不完整时，结构化多模态预测如何重新组织未来分支、时间演化及二者之间的耦合关系。本文在 DeMo 的结构化未来建模基础上，将观测掩码和时间间隔纳入条件预测过程，研究缺失证据对未来候选覆盖、概率排序和轨迹内时间连续性的影响。

这段话的逻辑是：**继承 DeMo 的问题结构，指出其完整历史条件在新任务下的失效位置，再提出观测条件化的研究问题。** 它没有把 DeMo 的 Mode/State 分解写成本文原创，也没有把缺失历史泛化成完整的跟踪系统失效。

## 四、核心科研问题与研究假设

### 1. 总问题

> **如何在缺失历史轨迹条件下，将可见轨迹片段、缺失结构和行人交互上下文转化为有效的预测条件，并以跨候选差异与轨迹内时序演化相结合的结构化方式建模未来轨迹分布？**

### 2. 子问题

1. **缺失感知历史表征**

   如何使历史编码器同时识别可见运动片段、缺失位置和观测间隔，避免将缺失误认为静止、低速或确定性运动？

2. **缺失条件下的跨候选未来建模**

   当历史证据不完整时，如何维持候选未来之间的有效差异，使模型能够覆盖多个合理的行人未来分支？

3. **缺失条件下的轨迹内时序建模**

   如何根据不连续历史建立单条未来轨迹的时间演化表征，保持未来速度、方向和转向过程的合理连续性？

4. **缺失结构与联合未来分布的适配**

   缺失位置、连续缺口和观测间隔应如何作用于跨候选差异表征、时序演化表征及其联合建模，使未来分布与历史观测条件相匹配？

5. **任务层有效性**

   相比直接填补缺失值、只拼接掩码或直接复用完整历史预测器，缺失感知的结构化未来分布建模能否在 ETH/UCY 与 SDD 上稳定提高缺失历史条件下的多模态预测质量？

### 3. 可检验假设

| 假设 | 内容 | 需要的证据 |
| --- | --- | --- |
| H2 | 缺失历史下，未来分布的跨候选差异与轨迹内时序演化需要分别建模，才能同时维持模态覆盖与轨迹连续性 | 与一体化预测头、未适配 DeMo 的对照 |
| H3 | 将缺失结构作为结构化未来分布的条件变量，能够减少候选轨迹塌缩并改善连续缺口场景中的预测 | 对比只在输入侧处理缺失与贯穿式条件化 |
| H4 | 本文方法在 TrajGap-Bench Mixed-test 的高缺失分组中仍保持收益，并在跨数据集扩展证据中方向一致 | Mixed-test 高缺失分组与 SDD 扩展验证 |

### 0B. 方法层重构的失败经验与当前边界（2026-10-05）

本节只保留可复用的机制结论，不保留已淘汰版本、半成品产物或训练过程记录。

1. **共享编码器侧的重复注入不再作为默认下一步。** M0 已将历史有效性作为输入信息；再次把缺失统计、缺失摘要或可靠性信号加到 actor token、编码器残差或 Scene Context 注意力分数，新增的往往是同一信息的另一条注入路径，而不是新的观测证据。此类改动会重塑共享编码器，使零缺失子组和缺失子组共同发生表示漂移，初始化时等价不能保证训练后仍等价。
2. **Scene Context 的全局可靠性偏置未通过筛选。** 将邻居有效帧比例直接作为 key 的全局 attention bias，隐含假设“历史越完整的邻居越值得当前 focal 行人关注”。该假设不成立：邻居是否有用取决于 focal–neighbor 的相对位置、相对运动和交互关系，而不是邻居自身的完整度。全局 key 偏置还会同时作用于所有 focal–neighbor 对，覆盖原有内容注意力。在 UNIV-M Mixed 诊断中，该候选的整体 minADE20/minFDE20/MR 为 0.3616/0.5984/0.0462，M0 参考值为 0.3359/0.5602/0.0363，未显示收益；由于两者不是同一代码状态下的配对重训，该数字用于候选筛选判负，不作为严格因果效应估计。
3. **“零初始化”只是起点保护，不是训练后隔离。** 新分支初始为零只能保证初始 forward 接近 M0；训练后，新增参数和共享 Scene Transformer 参数都会更新，条件化训练仍可能污染 mathematically no-op 的完整历史样本。因此任何新模块必须单独报告 m=0/完整历史子组，并把该子组作为首要证伪器。
4. **可靠性不能脱离关系建模。** 若未来重新改造 Scene Context，可靠性必须作为 focal–neighbor 关系的一部分，与相对几何、相对速度、距离、方向或时间同步共同决定消息，而不能只按邻居的 valid rate 统一升降权重。否则该模块只是一个与交互对象无关的全局先验。
5. **Scene Context 的集合语义必须保持。** actor token 是无序集合，不得直接沿 actor 文件顺序使用 Mamba/SSM 扫描；若引入扫描或顺序化模块，必须先定义可复现的 canonical order，并通过 actor permutation 测试。对当前短序列、小规模行人集合，不能以效率作为替换全注意力的主要动机。
6. **下一候选必须说明增量信息。** 在已有 mask/validity 输入的前提下，若新模块只能再次读取同一 valid rate、missing count 或 missing summary，却不能说明它如何改变状态传播、未来分布或训练分布，则不启动。新 Scene Context 候选至少要同时通过：padding 隔离、actor permutation、相对关系负对照、随机可靠性打乱和 m=0 不退化。
7. **场景编码层暂时降为观察对象，不再连续堆叠模块。** 在没有新的关系级证据前，不继续尝试普通可靠性 bias、一般社会注意力、actor-axis Mamba 或同类 token/summary 注入。后续优先从尚未覆盖且对共享编码器暴露较小的层面寻找候选：未来概率分布/概率头（MR、b-minFDE、校准）和训练缺失分布（Easy→Hard 失配）；若重新进入 Scene Context，必须先证明其新增信息不是已有缺失信号的重复。


### 1. DeMo 原始机制在缺失历史下的重新定位

| DeMo 原始机制 | 在完整历史中的作用 | 缺失历史下需要重新回答的问题 |
| --- | --- | --- |
| 历史 Mamba + Scene Context Transformer | 聚合目标行人历史、其他行人和空间上下文，形成运动预测条件 | 如何区分可见运动证据、缺失区间和距最近观测的时间关系，避免把缺失当成真实运动 |
| State Query / State Consistency | 组织未来沿时间轴的动态演化，并提供 dense prediction | 当速度、方向和最后有效观测锚点不完整时，未来状态演化应如何表达不确定性 |
| Mode Query / Mode Localization | 从场景条件中定位多个可能的未来运动分支，并产生候选及其概率 | 当转向、停走或避让证据被缺失抹去时，如何维持候选覆盖并避免概率过度自信 |
| Hybrid Coupling | 将每个 mode 与每个 future time state 联合，形成具体未来轨迹 | 缺失结构是否需要改变分支差异与时间演化之间的耦合，而不是只影响编码器输入 |
| 预测概率与尺度输出 | 对候选未来进行排序并表示预测离散程度 | 低证据条件下，概率排序和候选覆盖是否与实际未来不确定性匹配 |

因此，DeMo 在本文中是**结构化未来条件建模的继承骨架**，不是本文重新提出的创新模块。本文真正要检验的是：当完整历史这一条件假设被打破后，观测缺失如何改变 DeMo 的分支定位、时间演化和联合耦合，以及哪些改动能够在不破坏零缺失性能的前提下改善缺失条件下的未来预测。

## 七、论文叙事与拟形成贡献

### 1. 论文主叙事

本文面向遮挡、漏检和跟踪中断导致的行人历史轨迹缺失问题。不同于假设完整历史可用的传统预测方法，本文在统一协议下以经过三环境验证的 M0 为共享骨干，将历史观测缺失视为条件预测中的观测过程变量：模型从可见轨迹片段、缺失掩码和时间间隔中构造缺失感知历史上下文，并基于结构化多模态未来分布建模，分别表示候选未来之间的差异和单条未来轨迹内部的时序演化，最终生成与不完整历史观测相匹配的多模态行人未来轨迹。缺失观测条件化才是本文的主要方法问题。

本文使用的 TrajGap-Bench 是一个由本文定义的 direct 缺失历史预测基准协议（benchmark protocol）：它在数据层复用 TrajImpute 官方发布的 Easy/Hard pkl，在任务层取消先插补再预测的步骤，在协议层将两类 release 样本统一组织为 Mixed train/val/test。TrajImpute 原论文和官方仓库提供的是缺失数据 release 及 Clean/Easy-impute/Hard-impute 等插补后预测参考，并未提供本文所使用的原生 direct evaluator。因此，论文中应将 TrajGap-Bench 的数据来源、适配规则、Mixed 组织和评测结果明确归属于本文，不能称为“TrajImpute 官方 direct benchmark”或“TrajImpute 官方 direct 结果”。

论文叙事应明确区分两种性能目标：`M0` 与外部强基线的比较反映模型的绝对预测竞争力；同一 `M0` 上方法层版本的配对比较反映该版本机制的独立价值（方法层待重构）。两者不能合并成一个无法归因的“整体提升”。

### 2. 拟形成的贡献

1. **任务建模贡献**

   将行人轨迹预测从“完整历史到未来”的标准设定扩展为“缺失历史观测到未来”的条件预测问题，以掩码、观测间隔和有效轨迹片段共同描述历史输入。

2. **结构化未来分布贡献**

   将缺失条件引入 DeMo 式跨候选差异表征、轨迹内时序演化表征及其联合参数化过程，使多模态未来生成与历史观测完整程度相适配（方法层待重构）。

3. **实证、协议与诊断贡献**

### 0. TrajGap-Bench 与 TrajImpute 的关系（论文身份边界）

TrajGap-Bench 是本文定义的**直接缺失历史预测基准协议**（direct missing-history forecasting benchmark protocol），基于 TrajImpute 官方发布的 Easy/Hard release 构造。TrajImpute 在本文中只承担两种角色：提供经审计的缺失数据 release，以及提供原论文中的插补后预测参考结果。TrajGap-Bench 的 Mixed 数据组织、direct 输入形式、checkpoint 选择和主评测口径均属于本文协议；TrajGap-Bench 不是 TrajImpute 官方原生 direct benchmark，本文结果也不是 TrajImpute 官方 direct 结果。

本文不提出 TrajImpute 的插补模型，也不把 TrajImpute 的数据发布工作重新包装为本文创新；本文研究问题仍是直接缺失感知的多模态未来轨迹预测。论文中必须区分以下两类协议：

**TrajImpute 官方参考协议（插补后预测）**

```text
Clean        : 完整历史上的预测参考结果
Easy-impute  : 缺失历史先经外部插补器恢复、再输入预测器的参考结果
Hard-impute  : 高缺失历史先经外部插补器恢复、再输入预测器的参考结果
```

这三者是 TrajImpute 原论文/README 的预测参考协议，主要对应**插补后预测**结果，作为本文的**有限范围外部参考**，不是本文方法的原生 benchmark。

**本文 TrajGap-Bench 直接缺失预测协议（本文定义的 direct missing-aware evaluation）**

```text
Clean        : 原始 ETH/UCY 零篡改（经典完整历史预测，原始 ETH/UCY LOO 数据）。
               本文 Clean 基线 = 本项目 DeMo 复现结果，暂定 DeMo-单向 0.232/0.389
               （2026-08-28 轮，见《完整数据基线对比》）；原论文数字为外部参照。
Easy/Hard 来源：直接使用 TrajImpute 官方 release 发布并审计的缺失样本；
               Easy 为 0–4 帧，Hard 为 4–7 帧。它们是 TrajGap-Bench 的底层
               数据来源，不等于 TrajImpute 官方 direct 评测协议。
Mixed 组织：本文在适配层将同一 split 的 Easy/Hard 样本合并为 Mixed；
               缺失历史 + missing mask + 有效观测间隔 + 场景信息直接输入本文模型，
               不经过外部插补器，由本文评测器预测完整未来。
```

**工程验收状态（2026-09-08 修正）**：release 审计、30 个 pkl 的五场景适配扫描、TrajGap-Bench direct 评估器、M0 forward/backward 和真实数据分组评估均已在项目指定 DeMo 环境中通过；（2026-09-13 更正：早期自建 benchmark_v1 与 Clean-direct runner 已移除，TrajGap-Bench 为当前正式 direct 协议。）`target_mask` 的 padding actor 语义已修正为无效，不会进入其他 actor 辅助损失。该验收只说明本文 direct 管线可运行，不构成任何模型性能结论。Easy 的零缺失子集仅保留为诊断用途。

若未来 release 不可得而需本地构造 4–7 帧缺失，则该结果只能称“TrajImpute-based 补充压力测试”，不与 TrajImpute 官方 Hard-impute 结果直接对照，也不进入 TrajGap-Bench direct 主表。

**数据来源与“缺失样本”的谨慎表述**（官方事实核验状态见 §八.0.1，release 审计见 §八.0.2）：

### 1.2 统一验收标准

方法层版本必须同时通过性能、稳定性和归因三道门槛。

#### 性能门槛

以 `minFDE20` 作为第一主指标（主链 K=20，§1.6），以 `minADE20`、`MR` 和 `b-minFDE20` 作为辅助指标。候选增强至少应满足以下之一：

- 在 TrajGap-Bench Mixed-test 的零缺失分组（m=0）上，`minFDE20` 和 `minADE20` 均不劣于当前基线，并在至少一个主指标上出现具有实际意义的改善；
- 主指标改善幅度有限，但同时降低 `MR` 或 `b-minFDE20`，说明增强改善了失败样本或最差预测，而不只是平均值波动；
- 零缺失分组近似持平，但在 TrajGap-Bench Mixed-test 的缺失分组上表现出稳定收益，且收益能够由新增信息解释。

不能将仅有一个指标变好、其他关键指标明显退化的版本直接定义为“方法版本有效”。

#### 稳定性门槛

首轮可以使用已有单种子结果进行筛选，但进入主链前应至少进行相同数据划分下的 3 个种子复验

#### 归因门槛

每次实验只改变一个主要因素，并记录以下内容：

- 基础结构差异；
- 输入特征差异；
- 训练目标和损失权重差异；
- 缺失掩码及数据协议差异；
- 解码方式、采样数和后处理差异。

如果一个版本同时修改结构、特征和训练策略，即使最终数值提升，也只能作为工程候选，不能作为论文中的因果消融结论。方法层实验还必须同时报告零缺失分组与缺失分组结果，避免出现“零缺失变强、缺失退化”却仍被直接定义为共享骨干升级的情况。

表二固定 `M0`，在 TrajGap-Bench Mixed-train/val/test 口径下按方法层版本逐级比较（版本序列待重构，见 §五.0A）；缺失等级只作为 Mixed-test 内部诊断分组。每一行只能新增一个逻辑模块，同时报告相对于 `M0` 的变化量，而不仅是绝对值。这样才能清楚区分“骨干能力”与“方法机制带来的增益”。

#### 表三：TrajGap-Bench Mixed-test 上的高缺失鲁棒性与退化分析

表三在 TrajGap-Bench Mixed-test 内部的高缺失分组（缺失 4–7 帧，底层官方 release 的分布见 §八.0.2）上报告各版本相对低缺失参考分组的性能退化率。该分组不是独立的官方 direct benchmark：

\[
\Delta_{high} = \frac{m_{high\text{-}missing}-m_{low\text{-}missing}}{m_{low\text{-}missing}}.
\]

对于误差类指标，退化率越低越好。缺失帧数、最长连续缺口、最后有效观测间隔等分组分析均属于 TrajGap-Bench Mixed-test 的内部诊断，不构成 TrajImpute 官方 direct 协议，也不构成新的正式协议。

#### 表四：直接缺失预测与插补后预测基线的公平比较

表四在相同测试样本上比较两类路径，必须明确区分并分别标注口径：

```text
直接预测     ：缺失历史 + missing mask → 本文模型 → 未来预测
插补后预测   ：缺失历史 → 外部插补器 → 预测器 → 未来预测
```

本文直接缺失输入的 `minADE_K`/`minFDE_K` 与插补后预测的单轨 ADE/FDE 属于不同口径，不得混为同一可比数字，不得把二者的结果不加说明地放在同一个“官方 benchmark 数值”表中。若官方基准仅报单轨 ADE/FDE，应分别报告“TrajImpute 原论文可参考指标”与“本文多模态预测指标”。

### 1.6 指标与评价口径

三类指标不得互相替代：

- **TrajImpute 原论文可参考指标**：ADE/FDE，具体口径按其预测实验与外部模型实现核验（官方仓库无原生 evaluator，见 §八.0.1）。不声称 TrajImpute 官方 evaluator 原生支持本文的多模态指标。
- **本文多模态预测指标**：主指标族为三件套 `minFDE_K` + `b-minFDE_K` + `MR`（minFDE 看最优模态，b-minFDE 捕捉概率质量，MR 观测证据塌缩）；`minADE_K`、ADE@1/FDE@1、覆盖率与时间连续性作为辅助。**主链 K=20（2026-09-08 裁定，与 TrajImpute 官方预测协议对齐）**：全部正式实验（P0 起）统一 `num_modes=20`、指标名 minFDE20/minADE20/b-minFDE20，与官方插补后预测及 ETH/UCY 社区 K=20 惯例同口径，直接可比。K=6 仅为历史预实验口径，不再使用、不再续跑；历史 K=6 数字不与 K=20 主结果混排。
- **插补质量指标**：MAE、MSE、RMSE、MRE，仅用于插补器对照（外部参考），不用于替代本文未来预测指标。

历史 v1/v2/v3 的 `minFDE6` 结果只在历史预实验文档内部比较，不进入 direct 主表，也不与官方插补后预测数字并排。

### 1.7 当前阶段的最终决策规则

执行顺序固定为：

1. M0 Clean 与 TrajGap-Bench Mixed 基线已冻结，作为滚动基线；
2. 方法层新候选在 TrajGap-Bench Mixed 主协议上验证，以 Mixed-test 内部缺失等级分组分析呈现机制差异；
3. 验证通过后进行 Mixed-test 高缺失分组的鲁棒性与退化分析；
4. 最后进行多种子、TrajImpute 官方插补后预测外部参考与 SDD 扩展证据的完整比较。

如果复验后仍没有稳定的缺失感知收益，应把研究问题收敛为“缺失历史条件下的退化建模、协议分析与可靠性评估”，而不是继续堆叠模块。如果复验出现稳定收益，再进入更完整的耦合模型，并用表二和表三分别证明模块增量与缺失鲁棒性。

这种推进方式保留已有工作的价值和选题的连续性：M0 基线回答“模型本身是否可靠”；方法层版本检验新机制能否在可靠骨干上产生独立贡献。

### 2. 实验任务协议

**正式主协议（2026-10-05 修订）**：TrajGap-Bench Mixed 使用 TrajImpute 官方 Easy/Hard release pkl 作为底层文件来源，并在本文适配层合并同一 split 的 Easy/Hard 样本；训练、验证和测试均为 Mixed，直接预测、不经外部插补。缺失历史 + missing mask + 有效观测间隔 + 场景信息直接输入模型，预测完整未来轨迹。Clean = 原始 ETH/UCY 零篡改（本文 Clean 基线 = DeMo 复现，暂定 0.232/0.389，8/28 轮；原论文数字为外部参照）；自建 benchmark_v1 已移除。Easy/Hard 只保留为来源标签和 Mixed-test 内部诊断分组，不是独立主榜协议。

**外部参考协议（TrajImpute 官方插补后预测）**：官方 Clean / Easy-impute / Hard-impute 结果（缺失历史经外部插补器恢复后预测）仅用于有限范围的外部对照，不与本文 direct 结果混入同一“官方 benchmark 数值”表。

**历史自定义协议（已归档，不作为待执行主计划）**：v1（帧 0–5 缺失、帧 6/7 恒可见）、v2_high（同保护规则、37.5%–75% 高缺失）、v3_noguard（帧 0–7 全窗口无保护、锚点回退最后可见帧）。这些协议用于历史预实验与问题定位，其结果不与 direct 主结果混合。缺失帧数、连续缺口、缺口位置等维度若重新引入，只能作为基于直接预测扩展数据的**分组分析或补充分析**，不能作为新的正式协议。

ETH/UCY 与 SDD 用于检验方法在不同场景、坐标尺度与行人运动模式下的稳定性。无地图设置不作为论文主叙事，只作为当前行人轨迹输入条件。

### 4. 基线与消融关系

建议将对照设计围绕研究假设组织，而不是按网络组件堆叠：

| 对照组 | 回答的问题 |
| --- | --- |
| Easy m=0（零缺失）分组 `M0` | 零缺失条件下的基准 |
| 缺失历史 + 原始输入处理 | 原始模型面对缺失的自然退化 |
| 缺失历史 + 零填充/前向填充 | 简单缺失处理是否已足够 |
| 插补后预测或插补预测联合方法 | 直接预测与显式插补路线的关系（表四范式级比较） |

为保证每个结果可归因，正式实验至少应保留以下三组比较；每个方法版本统一报告 TrajGap-Bench Mixed-train/Mixed-val/Mixed-test；Easy/Hard 来源标签及缺失等级仅用于 Mixed-test 内部诊断，不另设独立主协议：

```text
缺失历史增益：  方法层版本 - M0
协议退化：      同一模型在 Mixed-test 内部的缺失等级退化曲线
```

其中，缺失历史增益回答“新机制是否有效”，协议退化回答“模型在缺失程度变化下是否稳健”。两者必须使用相同的 fold、seed、训练数据边界、checkpoint 选择规则和评测口径；不能用 `M0` 与方法层版本的非配对结果直接声称缺失感知带来全部提升。

其结果保持为单种子探索性证据，可进入研究记录与方法筛选，但不作为论文主表中的确认性证据。

### 5. 评价维度

| 维度 | 评价内容 |
| --- | --- |
| 预测准确性 | ADE、FDE、minADE、minFDE、Miss Rate |
| 缺失鲁棒性 | 不同缺失比例、连续长度、缺口位置下的性能曲线 |
| 多模态覆盖 | 最优候选命中、终点/方向多样性、合理未来分支覆盖 |
| 时间连续性 | 速度、加速度、曲率、转向变化的合理性与稳定性 |
| 概率与不确定性 | 模态概率、尺度、覆盖率、Energy Score 或校准指标 |
| 跨场景泛化 | ETH/UCY 不同场景与 SDD 上的趋势一致性 |
| 定性案例 | 转弯、减速、停走、避让、长连续遮挡后的未来预测 |

内部表示诊断可以辅助解释模型行为，但不应替代未来轨迹上的任务评价。论文结论应以缺失历史条件下的未来预测、覆盖性和连续性证据为主。

### 6. Go / No-Go 判断标准

**Go 条件**

- 缺失感知历史表征相对于零填充、简单掩码或未适配编码带来稳定收益；
- 缺失条件进入结构化未来分布后，除误差外还能改善模态覆盖或时间连续性中的至少一项；
- 收益在 TrajGap-Bench Mixed-test 的高缺失分组中仍可观察到，而非只存在于低缺失分组；
- 主结果能够在 TrajGap-Bench 五场景的多数子集上复现一致趋势，SDD 扩展证据方向不冲突；
- 零缺失分组（m=0）性能不发生不可接受的退化。

**No-Go 信号**

- 基础模型增强与缺失感知增强同时引入，导致无法分离两者的贡献；
- 简单填充或单纯拼接掩码已解释全部收益；
- 缺失感知历史编码无效，而复杂未来结构只增加参数量；
- 方法仅改善内部表征诊断，不改善真实未来预测、覆盖性或连续性；
- 收益只出现于 Mixed-test 的低缺失分组或单一数据场景，高缺失分组下方向反转；
- 未适配 DeMo 在所有缺失条件下已达到相同效果。

若出现 No-Go 信号，应据证据收缩论文主张：可能转向“缺失历史下 DeMo 的系统性评估与失败边界”，或重新定位新增方法的有效作用位置。

### 2. 暂不作为第一版主线的内容

```text
完整轨迹插补作为最终目标
直接解释隐藏向量为真实心理意图或物理状态

同时复现多个完整外部模型
```

这些方向可作为对照、扩展或后续工作，但不应稀释当前“缺失历史条件下的结构化多模态行人轨迹预测”主线。

### 3. 后续需要通过实验确定的事项

- 缺失条件最有效的表示是掩码、时间间隔、有效运动片段，还是三者的组合；
- 缺失条件应只影响历史编码，还是还应作用于 Mode/State Query 与 Hybrid Coupling；
- 是否需要显式插补分支、完整历史教师或运动学辅助约束；
- 不同缺失类型的训练测试分布应如何组织，才能同时反映适应性与泛化性；
- 最终采用的模态数量、缺失难度、概率评价指标和统计检验口径。
