# 部分观测条件下行人运动意图与动态状态的可靠解耦推断及多模态轨迹预测

_研究框架记录 · 更新时间：2026-09-01 · 研究领域：行人轨迹预测；基础建模框架：DeMo_

## 一、选题定位

本选题研究部分观测条件下的行人多模态轨迹预测。核心不是恢复缺失坐标，而是研究历史运动证据不完整时，行人未来运动中的潜在因素能否被可靠地分解和推断。

DeMo 提出的基本方法假设是：未来轨迹中的多模态差异主要体现为不同的运动意图，而单条未来轨迹内部的时间变化体现为动态状态。该假设将“不同未来之间的差异”和“同一未来内部的演化”分开建模，再通过混合耦合形成完整轨迹[^1]。本选题进一步研究，当历史轨迹只能被部分观测时，这种运动意图—动态状态分解是否仍然具有可辨识性，以及观测可靠性如何影响二者的推断、耦合和未来预测。

核心问题是：

> **当行人历史轨迹只能被部分观测时，运动意图与动态状态能否从有限运动证据中被可靠解耦推断，并通过二者的组合形成合理的多模态未来轨迹？**

研究框架分为四个层次：

| 层级 | 内容 | 定位 |
| --- | --- | --- |
| 研究对象 | 部分观测下的潜在运动意图与动态状态 | 需要解释和推断的潜在运动因素 |
| 建模假设 | 运动意图—动态状态解耦 | 将跨未来差异与单轨迹时间演化分开表示 |
| 研究机制 | 观测可靠性条件化的因素推断与运动意图—动态状态耦合 | 研究部分观测如何影响两个因素及其组合 |
| 预测结果 | 多个未来运动演化假设 | 以多模态未来轨迹验证因素推断的功能价值 |

整体研究链为：

```text
部分观测历史 X^obs、观测可用性 M 与交互上下文 C
    -> 有限运动证据及其可靠性
    -> 潜在运动意图 I 与动态状态 Z 的解耦推断
    -> 观测可靠性条件化的运动意图—动态状态耦合
    -> 多个未来运动演化假设
    -> 多模态行人轨迹预测
```

本选题的核心不是 UniMamba 或数据集本身，而是**部分观测如何改变运动意图与动态状态的可辨识性，以及观测可靠性条件化的解耦表示能否改善多模态未来预测**。UniMamba 负责聚合历史证据，DeMo 的 Mode/State 结构承载运动因素分解；“运动模式”只作为意图与动态状态组合后在未来轨迹中的功能性表现进行评价。

## 二、研究对象与概念边界

### 1. 潜在运动因素

本文中的“潜在运动因素”包括运动意图和动态状态。它们不是预先定义的行为类别，也不等同于某一个瞬时物理量，而是对行人未来运动差异及其时间演化的连续描述。

```text
运动意图 I：不同未来之间较稳定的方向性或长期运动倾向
动态状态 Z：单条未来轨迹内部随时间变化的速度、加速度、转向和停走状态
```

第一版以方向—动力学作为可解释核心：

```text
方向证据：位移方向、航向变化、曲率、转向趋势
动力学证据：速度、加速度、速度变化、减速或停止趋势
```

完整的潜在运动因素推断还可以结合：

```text
方向与动力学证据
    + 局部行人交互上下文
    + 观测可靠性
    + 连续潜在状态
```

因此，方向—动力学是第一版的主要解释维度，行人交互与观测可靠性是影响因素推断的条件，最终表示可以位于连续潜在空间中。这里的“方向—动力学”不是对潜在运动因素的封闭定义，而是用于第一阶段诊断和监督的可操作维度。

### 2. 输入侧证据推断与输出侧 DeMo 表示

| 概念 | 本选题中的含义 |
| --- | --- |
| 部分观测下的运动因素推断 | 根据有限观测证据，对运动意图、动态状态及其不确定性的推断 |
| 历史运动表征 | 对部分观测历史进行编码后得到的网络潜在向量，尚未自动获得运动学解释 |
| 运动意图 | 跨多个未来假设相对稳定的方向性或长期运动倾向，对应 DeMo 的 Mode 维度 |
| 动态状态 | 沿未来时间演化的运动状态，对应 DeMo 的 State 维度 |
| 运动模式 | 运动意图与动态状态组合后在未来轨迹中表现出的功能性结果，不是独立的核心中间变量 |
| 未来轨迹模态 | 未来轨迹分布中的一个可能分支 |

UniMamba 输出的历史运动表征属于输入侧的证据摘要，不等于运动意图或动态状态。DeMo 的 Mode Query 和 State Query 属于输出侧的结构化未来表示，也不应直接等同于当前时刻的物理状态。只有当这些表示能够分别与方向性证据、动力学证据和未来轨迹建立稳定关系时，才可以认为它们承担了有效的运动因素推断功能。

概念上，研究对象可以写为：

> **公式：** `p(I, Z_{1:T_f} | X^obs_{1:T_h}, M_{1:T_h}, C)`

该表达用于说明部分观测下的因素推断对象，不要求模型实际输出严格的 Bayesian posterior。证据不足时，允许运动意图和动态状态表现为多个合理假设及其不确定性。

### 3. 部分观测历史范围

研究对象是一个固定历史窗口内的部分观测历史轨迹：

```text
有效时间步 -> 编码真实运动证据
缺失时间步 -> 屏蔽无效证据并降低可靠性
窗口结束 -> 根据证据可靠性推断潜在运动因素及其不确定性
未来时间段 -> 将运动意图与动态状态组合为多个未来运动演化假设
```

本文统一使用“部分观测历史”描述输入条件。随机缺失、连续缺失或特定时间位置缺失只是构造观测条件的方式，不再作为彼此独立的科学问题；缺失程度、有效观测比例和观测间隔只用于改变运动因素推断的难度。

研究重点不是先恢复一条确定性的完整历史，而是根据可见证据推断未来相关的运动意图和动态状态及其不确定性。未来轨迹在训练和评测中保持为完整目标，历史部分观测只作用于模型输入；运动模式仅作为解耦运动因素对未来轨迹产生作用时的功能性结果。

当前实验按两个阶段控制缺失难度：第一阶段使用 0%、12.5% 和 25% 的 v1 条件建立接口与轻度缺失基线；下一轮扩展到随机缺失 3 帧（37.5%）、4 帧（50%），以及连续缺失 4 帧（50%）和 6 帧（75%），并在相同缺失率下比较随机缺失与连续缺失。下一轮方案仍固定历史帧 6、7 可见，以隔离缺失程度变化与局部坐标锚定变化。

## 三、问题背景与研究动机

### 1. 行人预测需要区分运动意图与动态状态

行人未来轨迹不仅由历史位置决定，也受到潜在运动意图和动态状态的共同影响。相同的局部位置可能对应继续前进、转向、减速、停止或避让等不同未来；即使总体方向相近，速度变化和转向过程也可能不同。

```text
历史位置
    -> 方向与动力学证据
    -> 运动意图与动态状态
    -> 未来多模态轨迹
```

因此，未来预测不仅需要回答“行人在哪里”，还需要区分“不同未来为什么不同”以及“同一未来如何随时间演化”。

### 2. 部分观测会影响运动因素的可辨识性

历史坐标部分不可见后，丢失的不只是若干位置值，还可能丢失由位置差分得到的方向、速度、加速度和转向证据。这样会同时影响运动意图判断和动态状态判断，但二者受到影响的方式可能不同。

需要区分：

```text
潜在运动因素没有改变，只是可见观测减少

潜在运动因素已经改变，但关键变化证据被缺失遮蔽

同一部分观测对应多个合理的运动意图—动态状态组合
```

当部分观测遮蔽运动变化证据时，剩余观测可能不足以判断转向、减速、停止或避让等状态变化，也可能使不同运动因素在潜在表示中发生混淆。

因此，研究重点不是预设部分观测一定导致某一种固定未来模式，而是分析：

> **在有限运动证据下，运动意图与动态状态是否仍然能够被可靠解耦推断？观测可靠性如何影响二者的可辨识性、耦合方式和未来预测？**

已有研究表明，不完整历史可以直接用于未来轨迹预测，模型不一定需要先恢复一条确定性的完整历史。本选题进一步关注部分观测条件下运动因素如何被推断、如何保持各自的功能语义，以及这种因素化表示如何服务于多模态预测。

## 四、DeMo 的方法假设与本选题映射

DeMo 的核心方法假设不是单纯使用某一种时序网络，而是将未来轨迹中的两类变化因素分开建模：`Mode Query` 负责表示不同未来之间的方向性运动意图，`State Query` 负责表示单条未来轨迹内部随时间变化的动态状态，随后通过 Hybrid Coupling 将二者组合为完整轨迹[^1]。

这一方法为本选题提供了一个可检验的因素化建模框架。本选题的科学问题是：当历史只能被部分观测时，有限运动证据是否仍足以支持这两个因素的区分？如果不能完全确定，观测可靠性是否可以指导模型保留合理的因素不确定性，并避免意图与动态状态相互混淆？

可以复用的设计包括：

| DeMo 设计 | 在本选题中的作用 |
| --- | --- |
| Mode Queries | 表达多个候选运动意图，刻画不同未来之间的方向性差异 |
| State Queries | 表达每个未来时间步的动态状态，刻画单条轨迹内部的时间演化 |
| Mode Localization | 从历史和行人交互上下文中区分不同运动意图假设 |
| State Consistency | 约束动态状态沿未来时间的连续演化 |
| Attention + Mamba | 分别聚合关系信息和历史时序运动证据 |
| Hybrid Coupling | 组合运动意图与动态状态，形成具体未来运动演化 |
| 多模态预测头 | 将多个因素组合转化为未来轨迹及其概率或尺度 |

因此，DeMo 中的三个关键操作在本选题中具有明确的科学含义：

```text
运动意图分离 -> 不同未来之间的因素可辨识性
动态状态建模 -> 单条未来内部的时间一致性
运动意图—动态状态耦合 -> 多个因素能否组合成合理未来
```

本选题不是把 DeMo 的模块重新命名，而是将部分观测作为新的观测条件，研究 DeMo 的运动因素分解在有限证据下是否仍成立，以及不确定性如何在分解表示和未来预测之间传递。

DeMo 的运动因素解耦假设最初在交通参与者预测中提出。本选题以行人轨迹作为新的运动形态与观测条件载体，使用 ETH/UCY、SDD 检验该假设在行人运动预测中的成立条件。

### 1. 当前结构调整的准确定位

#### 面向部分观测的运动因素推断

当前模型的任务设定为：

```text
focal 行人及邻居历史轨迹
    -> 每个行人的历史运动证据编码
    -> 行人之间的交互建模
    -> 运动意图与动态状态解耦
    -> 运动意图—动态状态组合
    -> 多模态未来轨迹
```

部分观测条件下，模型首先需要形成观测条件化的历史运动表征，再由 DeMo 的 Mode/State 结构表达未来相关的运动因素。这里的关键不是隐藏表征是否具有某个固定物理名称，而是其是否能够支持运动意图区分、动态状态连续性和未来轨迹组合。

#### 单向 Mamba 的定位

UniMamba 在本选题中承担历史运动证据的有序聚合功能，形成对当前可见历史的观测条件化表征。它不是运动意图提取器，也不是动态状态估计理论本身；真正需要验证的是，该历史表征能否在部分观测下支撑后续运动因素的可靠解耦。

当前代码中，历史编码器的 `bimamba` 参数默认关闭，而时间解码器中的两个 Mamba 分支仍有显式的双向配置。因此，实验时应将各路径的方向性参数显式配置，并把 UniMamba/BiMamba 作为独立消融变量，不能仅凭模块名称推断实际使用的算子。

#### 研究框架的准确表述

可以将整个方法表述为：

> **部分观测条件下行人运动意图与动态状态的可靠解耦推断及多模态轨迹预测。**

其中，DeMo 提供运动意图—动态状态解耦和混合预测的主体方法框架，UniMamba 提供历史证据聚合，部分观测提供研究条件，观测可靠性提供因素推断的条件变量。真正需要研究的是：有限证据下两个运动因素的可辨识性、时间一致性、组合关系和不确定性传递。运动模式只作为因素组合在未来轨迹中的功能性表现，不作为独立的核心中间变量。

### 3. 理论支撑与研究线索

现有文献对本选题的支撑主要来自“部分观测下的潜在状态推断”和“运动因素分解与不确定性建模”两条理论链，而不是某一篇论文已经直接解决了本研究问题。

#### 3.1 部分观测历史是潜在运动因素推断问题

将完整历史轨迹记为 `Xₜ`，观测掩码记为 `Mₜ`，实际输入可以表示为：

> **公式：** `X̃ₜ = Mₜ ⊙ Xₜ`

模型需要推断的是与未来相关的潜在运动因素，而不是简单恢复缺失坐标：

> **公式：** `p(I, Z_{1:T_f} | X^obs_{1:T_h}, M_{1:T_h}, C)`

其中 `I` 表示运动意图，`Z_{1:T_f}` 表示未来动态状态序列，`C` 表示行人交互上下文。

Sun 等人的 Graph-VRNN 将部分观测下的状态估计与未来预测统一到图结构变分模型中[^10]，为本研究提供了从不完整观测中建模潜在状态不确定性的参考。因此，缺失时间步不应被当作真实坐标或确定性插补结果参与运动因素推断。

#### 3.2 观测可用性决定运动证据可靠性

STGN-IT 通过观测状态编码区分可见和不可见轨迹，避免模型把填充值误认为真实位置[^3]。GC-VRNN 使用时间衰减模块学习缺失轨迹中的时序模式，并通过共享时空特征联合处理插补与预测[^11]。GRU-D 则将观测掩码、距上次观测的时间间隔和可学习衰减直接融入时序表示[^16]。

这些研究支持将以下信息统一解释为**运动证据可靠性**：

- 当前时间步是否有真实观测；
- 距离上一次有效观测的时间间隔；
- 历史运动表征应保留多少；
- 运动意图和动态状态应具有多大的推断不确定性；
- 证据不足时未来预测分布应扩大多少。

但 GRU-D 关于缺失模式具有任务信息的结论来自医疗时序数据，不能直接假设适用于行人轨迹预测。对行人轨迹而言，观测可靠性应作为模型输入和可验证假设，而不是预先确定的行为因果变量。

#### 3.3 部分观测会造成运动因素推断歧义

Momentary Observation 将历史观测压缩到极端的两帧，指出加速度、减速和转向等时间运动线索会明显缺失，而速度、社会上下文和场景上下文仍可提供补充信息[^12]。DTO 进一步显示，完整观测教师可以帮助少观测学生恢复部分预测能力，但在复杂转向等动态情况下，少量观测仍不足以确定唯一的运动意图和动态状态组合[^13]。

这两项研究支持本选题的一个重要边界：

> 部分观测下不应要求模型恢复唯一确定的运动因素，而应输出与证据可靠性相匹配的意图—状态假设及其不确定性。

#### 3.4 DeMo 解耦表示支持多模态因素推断

Graph-VRNN 使用变分隐变量表示部分观测下的状态不确定性[^10]。SocialVAE 在每个预测时间步引入潜变量，并用条件先验、后向后验和社会注意力建模动态决策与多模态轨迹[^15]。DisDis 则将个体运动因素表示为可区分的潜变量分布，并从概率分布层面评价多模态预测[^14]。

这些工作为 DeMo 的 mode/state 解耦提供了补充支撑：

```text
Mode -> 候选运动意图假设
State -> 随时间变化的动态状态
Hybrid Coupling -> 运动意图与动态状态的组合
```

但 Mode Query 或 State Query 本身不等于真实运动因素。只有当 Mode 能够区分不同未来之间的方向性差异，State 能够保持单条未来内部的动态连续性，并且二者的组合能够改善未来轨迹预测时，才能认为该解耦表示具有有效的运动因素推断功能。

#### 3.5 插补、直接预测与实验评价

GC-VRNN 和 MS-TIP 说明插补与未来预测可以通过共享时空表示联合建模[^11][^5]。TrajImpute 则通过均匀随机缺失、不同缺失程度和统一评价协议，展示了插补误差增加会导致预测性能下降，并指出直接处理缺失坐标的预测模型仍有必要[^6]。

对本研究而言，这些工作提供三点线索：

1. 部分观测历史必须保留在评测中，不能只保留完整样本；
2. 插补结果不能默认等价于真实观测，应保留观测可靠性信息；
3. 运动因素推断质量和未来预测质量应同时评价。

随机缺失可以作为构造部分观测历史的实验方式，但不再被定义为独立的研究类型。

#### 3.6 观测可靠性条件化的运动因素推断机制

以下内容是用于界定研究假设的概念层机制，不是已经确定的网络层实现。具体采用何种编码器、门控形式或损失函数，应以后续对照实验结果为准。

本选题中的“可靠”不是简单地把有效掩码再次拼接到输入，而是要求模型显式区分真实观测、由真实观测计算出的运动证据和不可观测时间步的无效证据，并让这种证据可靠性影响运动因素推断的确定性。

每个历史时间步可以由以下信息构成运动证据：

```text
位置位移、速度、加速度、方向或曲率
    + 当前时间步是否有真实观测
    + 当前运动证据是否能够由足够的有效观测计算得到
    + 距上一次有效观测的时间间隔
    + 历史窗口中的有效观测比例
```

观测掩码与运动证据掩码不能混为一谈。例如，当前和前一时刻都有位置观测，才可以计算该时间间隔的位移和速度；加速度、曲率和转向趋势通常还需要更多连续有效观测。对于无效时间步，不应通过零填充位置继续计算速度或加速度，否则模型可能将“缺失”误认为“停止”。可定义运动证据可靠性 `ρₜ`：

> **公式：** `ρₜ = f(观测掩码、运动证据掩码、距上一次有效观测的时间间隔、有效观测比例)`

最简单的先验形式是：有效观测的可靠性接近 1，不可观测时间步的可靠性随时间间隔增加而衰减。更复杂的形式可以由网络学习，但必须通过实验验证其是否具有实际意义。

运动证据编码可以使用掩码、时间间隔和可学习衰减进行可靠性加权：有效运动证据参与表示学习，不可观测时间步的证据被屏蔽或降权，时间间隔越长，可靠性越低。由此形成的历史运动表征只作为因素推断的条件，不直接被赋予运动意图或动态状态的物理含义。

在此基础上，运动意图与动态状态的推断由历史运动表征、有效运动证据和行人交互上下文共同支持。DeMo 的 Mode 表示跨多个未来假设相对稳定的运动意图，State 表示每个未来时间步的动态状态，二者共同构成未来运动因素表示。二者都可以是连续表示，不要求预先建立固定的“直行、转弯、停止”等行为类别。若解码阶段使用历史窗口级可靠性，应使用由历史证据得到的可靠性摘要，而不能使用未来真实观测信息。

#### 3.7 可靠性条件化的运动意图—动态状态耦合

原始 DeMo 的 Hybrid Coupling 主要通过运动意图查询和动态状态查询的组合形成混合查询。若直接采用固定相加：

> **公式：** `qₖ,ₜ = qₘᵏ + qₛᵗ`

则没有显式考虑当前运动证据是否可靠。

本选题拟研究观测可靠性条件化的因素耦合方式。可以定义运动意图—动态状态门控：

> **公式：** `gₖ,ₜ = σ(MLP([qₘᵏ, qₛᵗ, ρH, c]))`

并使用：

> **公式：** `qₖ,ₜ = LN(qₘᵏ + gₖ,ₜ Wₛ qₛᵗ + Wc c)`

其中 `qₘᵏ` 是第 `k` 个运动意图假设，`qₛᵗ` 是第 `t` 个动态状态，`c` 是历史窗口对应的行人交互上下文，`ρH` 是由历史证据得到的可靠性表示。

该机制的目标不是在部分观测时强行选择一个意图，而是：

```text
证据充分 -> 运动意图与动态状态进行更确定的耦合
证据不足 -> 保留多个合理的意图—状态组合，减少过早收缩到单一未来
观测间隔增加 -> 因素推断和未来预测表达更大的不确定性
```

因此，可靠性还可以输入轨迹尺度和模态概率预测头，使观测条件同时影响因素表示、意图—状态耦合和最终预测分布。

#### 3.8 解耦表示的语义约束与可验证性

运动意图与动态状态不能只通过结构命名获得，需要在训练和评测中获得相互区分的运动学证据支持。可在原始 DeMo 预测损失之外加入少量辅助约束：

> **公式：** `ℒ = ℒDeMo + λkin ℒkin + λcons ℒcons`

`ℒkin` 用于约束运动意图与动态状态分别保留方向性信息和时间变化信息；`ℒcons` 用于约束同一完整轨迹在完整观测和部分观测下的因素表示具有合理一致性。验证时需要区分三类性质：Mode 是否区分不同未来，State 是否保持单条未来内部的时间连续性，Hybrid Coupling 是否能将二者组合为合理轨迹。不同 Mode Query 存在排列问题，比较前需要根据预测轨迹或意图距离进行匹配。

训练时可以使用完整历史轨迹构造部分观测版本，完整历史只提供监督信号，不作为部分观测输入的一部分。这样可以研究模型是否从有限证据推断合理的运动因素，而不是依赖完整历史。

该设计不要求额外加入插补网络、外部生成式对照或固定行为分类器。最小研究方法应优先验证“运动证据可靠性 + 运动意图—动态状态解耦 + 观测可靠性条件化耦合”这一条主线。

#### 3.9 当前优先方法路线

结合上述文献，当前最推荐的不是同时堆叠多个完整模型，而是形成一条清晰的最小方法链：

```text
GRU-D：观测掩码 / 时间间隔 / 状态衰减
    + DeMo：运动意图—动态状态解耦骨架
    + DeMo 的运动意图定位、动态状态一致性与 Hybrid Coupling
    + FiLM 或 GMU：观测可靠性条件化耦合
    -> 部分观测条件下的运动因素解耦推断
```

其中，FiLM 和 GMU 是条件化融合的两种可选实现，不建议第一版同时引入。优先方案是使用由历史观测可靠性生成的门控，对 Mode 与 State 的耦合强度进行调节：

> **公式：** `gₖ,ₜ = σ(MLP([qₘᵏ, qₛᵗ, ρH, c]))`

> **公式：** `qₖ,ₜ = qₘᵏ + gₖ,ₜ Wₛ qₛᵗ`

该路线不要求复刻每篇论文的完整网络，而是提取以下四个可组合机制：

| 机制 | 主要参考 | 在本选题中的作用 |
| --- | --- | --- |
| 掩码、时间间隔与衰减 | GRU-D [^16] | 构造运动证据可靠性并控制历史状态保留程度 |
| 运动意图—动态状态表示与辅助监督 | DeMo [^1]、DeMo++ [^17] | 区分跨未来意图和单轨迹动态演化，并进行运动学诊断 |
| 条件化因素耦合 | FiLM [^18]、GMU [^19] | 让观测可靠性决定运动意图、动态状态和交互信息的融合强度 |

### 5. 文献支撑下的研究空白

上述文献已经分别解决或讨论了缺失轨迹输入、部分观测状态估计、轨迹插补、短观测预测、时变潜变量和多模态生成。因此，本研究不应声称“首次研究缺失轨迹预测”或“首次利用隐状态处理缺失”。

更准确的研究空白是：

> 现有方法主要关注缺失坐标处理、轨迹插补、一般隐状态估计或最终预测误差。相比之下，较少工作直接检验：在部分观测条件下，未来运动的跨模态意图因素与单轨迹动态因素是否仍可被区分；这种区分如何受到观测可靠性和行人交互的影响；以及因素化表示能否通过组合带来独立的多模态预测收益。

本研究的核心线索因此收敛为：

```text
部分观测历史
    -> 有效运动证据与行人交互上下文
    -> 运动证据可靠性
    -> 运动意图与动态状态的可辨识性及其不确定性
    -> 可靠性条件化的运动意图—动态状态耦合
    -> 多个未来运动演化假设
    -> 未来多模态轨迹预测
```

## 六、核心科研问题与假设

### 总问题

> **当行人历史轨迹只能被部分观测时，运动意图与动态状态能否从有限运动证据中被可靠解耦推断，并通过二者的组合形成合理的多模态未来轨迹？**

### 子问题

1. **运动因素的可辨识性**

   历史轨迹不完整时，哪些有效观测仍能支持运动意图判断，哪些有效观测仍能支持动态状态判断？部分观测程度如何影响两个因素的可辨识性、混淆和不确定性？

2. **部分观测下的运动意图—动态状态解耦**

   如何利用有效观测、观测间隔和行人交互上下文，形成比普通隐藏特征更具有运动学含义、且能够区分跨未来意图与单轨迹动态演化的因素化表示？

3. **解耦因素对未来预测的功能价值**

   运动意图—动态状态的解耦推断是否能够改善未来多模态轨迹预测，并在转弯、减速、停止和避让等场景中优于仅依赖普通隐藏状态或固定耦合的 DeMo 基线？

4. **可靠性条件化的因素耦合**

   当运动证据可靠性随时间和部分观测程度变化时，如何自适应地调整运动意图与动态状态的提取、耦合和预测不确定性，避免固定耦合导致过早收缩到单一未来？

### 核心假设

```text
部分观测历史
    -> 有效方向/动力学运动证据与行人交互上下文
    -> 运动证据可靠性
    -> 运动意图与动态状态的可靠解耦推断及其不确定性
    -> 可靠性条件化的运动意图—动态状态耦合
    -> DeMo 多模态未来预测
```

核心假设为：

> **在历史部分观测条件下，利用观测可靠性对运动意图与动态状态进行解耦推断，并根据可靠性调节二者耦合，比普通隐藏状态、简单输入掩码或固定耦合更能保留未来相关运动信息，从而改善多模态轨迹预测。**

该假设需要通过因素可辨识性诊断、动态状态一致性分析、因素不确定性分析和真实未来预测共同验证。

## 七、拟形成的研究贡献

### 1. 部分观测下的运动因素推断问题

将历史轨迹部分观测下的行人预测问题表述为运动意图与动态状态的潜在因素推断问题，而不仅是缺失坐标处理或轨迹补全问题。研究重点是分析有限历史证据对两个因素的可辨识性影响，以及部分观测造成的不确定性如何传递到未来预测。

这部分的基本逻辑是：

```text
部分观测历史 -> 有限运动证据
观测可用性 -> 运动证据可靠性
有限证据 -> 运动意图与动态状态的概率性推断
```

这部分借鉴部分观测状态估计和缺失感知时序建模的思想，但研究对象聚焦于行人未来运动中的意图因素、动态因素及其相互关系，不声称重新提出缺失数据处理的一般理论。

### 2. 部分观测条件下的 DeMo 运动因素解耦

DeMo 已经提供运动意图—动态状态解耦和 Hybrid Coupling 框架。本选题研究部分观测条件下该解耦假设是否仍然成立：

- 有限运动证据能否区分跨未来的运动意图；
- 动态状态能否保持单条未来轨迹内部的时间连续性；
- 运动意图与动态状态是否会因部分观测而相互混淆；
- 观测可靠性如何影响因素表示和二者的耦合；
- 证据不足时如何保留合理的意图—状态组合及其不确定性。

拟形成的核心方法表述为**部分观测条件下的观测可靠性条件化运动意图—动态状态解耦推断**。DeMo 的因素分解和组合预测作为主体框架，本选题的研究重点是其在有限运动证据下的可辨识性和可靠性。

### 3. 解耦因素的语义可验证性与预测价值

已有 DeMo 的查询向量不天然具有真实运动学含义。因此，本选题需要通过因素诊断、完整/部分观测输入一致性和未来预测结果共同验证：

- Mode 是否能够区分不同未来之间的方向性差异；
- State 是否能够保持单条未来内部的动态连续性；
- 完整观测和部分观测下因素表示是否具有合理一致性；
- 方向、速度、加速度和转向趋势误差；
- 缺失程度增加时的不确定性变化；
- 转弯、减速、停止和避让场景中的未来预测误差；
- 解耦因素相对于普通隐藏状态或固定耦合的独立收益。

只有当因素表示的语义区分和不确定性表达能够传递到真实未来轨迹，并且收益不能由额外参数量或简单掩码输入解释，才能支持方法有效。

### 4. 研究包装与贡献边界

建议将论文整体包装为：

> **部分观测条件下行人运动意图与动态状态的可靠解耦推断及多模态轨迹预测。**

更凝练的方法叙事是：

> 本文研究部分观测条件下的行人多模态轨迹预测。基于 DeMo 的运动意图—动态状态解耦方法，模型根据有限运动证据、观测可靠性和行人交互上下文，推断不同未来之间的运动意图及每条未来内部的动态状态，并通过 Hybrid Coupling 形成多个未来运动演化假设。研究重点是分析部分观测如何影响运动因素的可辨识性、时间一致性、耦合关系和不确定性传递。

其中各部分的归属应明确：

| 内容 | 归属 |
| --- | --- |
| ETH/UCY、SDD | 行人运动预测中的部分观测研究场景 |
| 行人交互信息 | 运动因素推断的上下文条件 |
| UniMamba | 时间建模结构选择 |
| DeMo 运动意图—动态状态解耦 | 因素化预测框架 |
| 观测可靠性估计 | 因素推断的条件变量 |
| 可靠性加权运动证据编码 | 有限证据建模机制 |
| 可靠性条件化的意图—状态耦合 | 因素组合机制 |
| 因素语义约束和运动学诊断 | 可验证性设计 |

本选题可以直接采用 DeMo 的 Mode Query、State Query、Attention、Mamba、Hybrid Coupling 和多模态预测头作为主体框架。与原研究的区别不在于重新命名这些模块，而在于提出并检验一个新的研究条件：当历史运动证据不完整时，DeMo 的运动意图—动态状态分解是否仍然可辨识、可组合，并能否改善多模态未来预测。

## 八、验证框架与实验方向

### 0. 已有基础实验线索

已有的 ETH/UCY 留出对照实验在相同数据协议和评测口径下比较了单向与双向 Mamba。8 帧观测、12 帧预测、`K = 20` 的实验结果显示：

| 结构 | 平均 minADE20 | 平均 minFDE20 |
| --- | ---: | ---: |
| DeMo 单向 Mamba | 0.232 | 0.389 |
| DeMo 双向 Mamba | 0.244 | 0.416 |

双向版本相对单向版本的平均误差更高，且在 ETH 场景退化最明显；这为当前优先采用 UniMamba 提供了经验依据，但不能推出单向 Mamba 在所有数据和实现条件下必然更优。该结果来自既有的 `K=20` 留出实验，最终研究配置若采用其他模态数量，必须重新报告并保持口径一致。详细记录见 [ETHUCY结果对照表](/home/lbh/DeMo/docs/results/ETHUCY结果对照表.md)。

该实验只能支持以下判断：

```text
UniMamba 是当前更合理的基础结构选择
    != UniMamba 本身构成研究创新
    != 双向 Mamba 在所有设置下都无效
```

此外，运行环境和 `mamba_ssm` 版本可能影响 `bimamba` 参数是否真正生效。正式实验必须确认实际使用的算子和方向性配置，不能只依据配置文件名称解释结果。

### 1. 前置验证链

| 阶段 | 验证问题 | 目的 |
| --- | --- | --- |
| P0 | 完整历史下 DeMo 的运动意图—动态状态解耦能否在行人轨迹预测中形成有效多模态预测 | 确认基础因素化预测框架可用 |
| P1 | 部分观测历史是否降低运动意图与动态状态的可辨识性 | 确认部分观测确实改变因素推断难度 |
| P2 | 观测可靠性条件化是否能够保持意图区分性和动态状态连续性 | 判断解耦表示及可靠性建模是否合理 |
| P3 | 意图—状态解耦及其可靠性条件化耦合是否改善真实未来预测 | 判断因素化建模是否具有独立收益 |

P1 用于确认部分观测历史是否会造成可测量的因素可辨识性损失，真正需要关注的是解耦因素的区分、组合和不确定性表达是否能够转化为独立的未来预测收益。

### 2. 部分观测条件

实验统一使用“部分观测历史”描述输入条件。缺失程度和有效观测比例只用于构造不同难度的受控样本，不形成独立的缺失类型研究主线。

基础 benchmark 阶段使用完整历史，先验证 DeMo 的运动意图—动态状态解耦在行人轨迹预测中的预测能力；部分观测研究阶段再从完整历史构造部分观测输入，并保持未来轨迹监督目标完整。这样可以将基础因素化预测能力与部分观测下的解耦推断收益分开。

初始缺失实验宜先保证 focal 行人的观测窗口末帧有效，使局部坐标原点和朝向基准保持定义良好；如果允许末帧也缺失，则必须同时重新定义参考位置、参考朝向、预测起始时刻及其时间间隔，不能直接沿用完整观测设置。

### 3. 评价维度

| 维度 | 评价内容 |
| --- | --- |
| 标准预测 | ADE、FDE、minADE、minFDE |
| 运动意图可辨识性 | 不同未来之间的方向、终点位移和长期运动倾向区分度 |
| 动态状态连续性 | 单条未来轨迹内部的速度、加速度、曲率和转向变化一致性 |
| 因素一致性 | 完整观测与部分观测下的意图—状态表示及其未来功能一致性 |
| 部分观测鲁棒性 | 不同观测程度下的因素区分、轨迹预测和性能变化曲线 |
| 未来运动场景 | 转弯、减速、停止、避让等场景中的因素组合和预测误差 |
| 因素与预测不确定性 | 意图—状态假设的多样性、覆盖率、Energy Score、可靠性和过度自信 |

## 九、对照关系与判断标准

基础模型锁定为 DeMo 后，对照关系按研究问题分层：

1. 完整历史 DeMo；
2. 完整历史与 UniMamba 历史编码的 DeMo；
3. 部分观测历史与原始输入处理的 DeMo；
4. 部分观测历史与观测掩码输入的 DeMo；
5. 部分观测历史与普通隐藏状态编码的 DeMo；
6. 部分观测历史与显式运动证据编码的 DeMo；
7. 部分观测历史与原始固定意图—状态耦合的 DeMo；
8. 部分观测历史与观测可靠性条件化的运动因素解耦；
9. 加入因素语义约束的解耦模型；
10. 完整研究方法。

### Go 条件

- 完整历史下 DeMo 的运动意图—动态状态解耦能够形成有效多模态预测；
- 部分观测下 Mode 能够保留不同未来之间的方向性区分，State 能够保留单条未来内部的动态连续性；
- 部分观测下的解耦因素相对于普通隐藏状态或固定耦合具有独立收益；
- 因素表示的改善能够传递到真实未来轨迹，而不是只改善内部诊断指标；
- 结果不只存在于单一观测程度、单一行为场景或单一数据场景；
- 观测证据减少时，因素假设和未来预测能够保持合理的不确定性表达。

### No-Go 条件

- 普通隐藏状态、简单输入掩码或固定耦合已经解释全部收益；
- 因素内部指标改善但未来轨迹不改善；
- 收益完全来自额外参数量或额外输入信息；
- 结果只在单一观测程度或单一场景成立；
- 模型需要完整历史或未来信息才能形成运动因素表示。

## 十、研究范围与待确定事项

本文档只保留研究问题、基础模型定位、概念边界、相关研究启示、创新假设、验证逻辑和判断标准。网络层修改、数据接口、缺失掩码生成、损失函数、训练配置和具体实验脚本另行设计。

当前仍需通过实验确定的事项包括：

- 可靠性采用固定衰减、可学习函数，还是二者的组合；
- 可靠性加权主要作用于运动证据编码、运动因素表示提取，还是二者同时作用；
- 可靠性条件化主要作用于因素表示提取、Hybrid Coupling，还是同时作用于预测尺度和模态概率；
- 运动学辅助约束是否带来超出简单掩码输入的独立收益；
- 最终采用的模态数量、缺失难度和评测指标口径。

第二轮高缺失实验的正式条件、命名、掩码规则、审计要求和训练/零样本评估边界见[ETH/UCY 与 SDD 第二轮高缺失历史实验方案](ETHUCY与SDD第二轮高缺失历史实验方案.md)。v2 数据和实验管线已经落地，第二轮实验已于 2026-09-01 启动；实验结果尚未汇总，不应在当前选题阶段写成已验证结论。

这些事项属于后续实现与实验设计，不应在当前选题阶段预先写成已验证结论。
