## 一、选题定位

行人轨迹预测通常以检测与跟踪系统输出的历史轨迹为输入。然而，遮挡、漏检、短时跟踪中断、帧丢失与定位误差会使历史轨迹出现缺失或时间断裂。完整、连续的固定长度历史轨迹因此并不是始终可得的前提。

本选题研究**缺失历史轨迹条件下的行人多模态轨迹预测**：给定不完整的历史观测、缺失位置及其时间结构，直接预测行人的完整未来轨迹分布。研究目标不是将缺失帧逐点恢复为唯一历史，而是从可见轨迹片段和观测缺失结构中构造可用于未来预测的历史上下文。

DeMo 为本研究提供结构化多模态预测的基础框架。其核心思想可表述为：未来轨迹分布同时包含两类结构，一类是不同候选未来之间的整体差异，另一类是单条候选轨迹沿时间轴的动态演化。DeMo 分别表示这两类结构，并通过联合表征参数化完整的未来轨迹分布[^1]。本研究将这一结构化预测思想引入缺失历史行人轨迹预测，使历史观测缺失不仅作为输入扰动，而是作为条件未来分布建模的一部分。

核心科学问题是：

> **在行人历史轨迹因观测中断而不完整的条件下，如何将可见轨迹片段与缺失结构转化为有效的预测条件，并对未来轨迹分布中的跨候选差异和轨迹内时序演化进行联合建模，从而生成多模态且时间连续的未来轨迹？**

研究定位分为五个层次：

| 层次 | 内容 | 在选题中的作用 |
| --- | --- | --- |
| 现实背景 | 遮挡、漏检、跟踪中断等导致历史轨迹缺失 | 给出问题来源和应用需求 |
| 预测任务 | 不完整历史观测条件下的行人未来轨迹预测 | 定义输入、输出与评测对象 |
| 历史建模 | 观测缺失感知的时序历史表征 | 从可见片段、缺失掩码和时间间隔中构造预测上下文 |
| 未来建模 | 跨候选差异与轨迹内时序演化的结构化条件建模 | 保持多模态性与时间连贯性 |
| 结果验证 | 完整未来轨迹上的准确性、覆盖性、连续性和缺失鲁棒性 | 判断方法是否解决任务问题 |

整体研究链为：

```text
检测/跟踪观测缺陷
    -> 缺失或时间断裂的历史轨迹 X^obs
    -> 观测掩码 M、时间间隔 Delta 与有效运动片段
    -> 共享基础运动/交互上下文 H^base
    -> 缺失观测条件化上下文 H^miss
    -> 未来轨迹的跨候选差异表征 D_1:K
       + 轨迹内时序演化表征 S_1:T_f
    -> 结构化条件未来分布 p(Y_1:T_f | X^obs, M, Delta, C)
    -> 多模态行人未来轨迹预测
```

本选题的核心不是将某一种时序网络本身包装为创新，也不是把编码器隐式特征直接解释为真实“运动意图”或“物理状态”。整体编码器负责聚合历史时序证据、观测结构和行人交互信息；DeMo 的 Mode/State 结构提供未来分布的结构化参数化。为避免基础模型能力不足掩盖缺失感知机制，研究路线分为“共享基础模型增强层”和“缺失感知方法层”两层：前者负责建立稳定、具有竞争力的通用预测条件，后者负责研究缺失观测如何改变历史表征与结构化未来分布。研究创新仍应落在**缺失历史任务建模、观测缺失感知的时空上下文表征，以及缺失条件如何进入结构化未来分布建模**，而不是简单叠加通用网络组件。

### 1.1 基础模型增强与缺失感知创新的分层

当前 DeMo 与公开强基线之间仍存在绝对性能差距，因此不能把所有后续提升都归因于缺失感知设计。选题采用如下分层原则：

```text
共享基础模型层 B
    -> 提升完整历史下的运动表征、交互表征和多模态优化质量

缺失感知方法层 M
    -> 描述观测是否可用、缺口如何组织，以及缺失如何调制未来分布
```

共享基础模型层的改动必须同时应用于完整历史基线、缺失历史基线和最终方法；缺失感知层的改动才是本选题的主要方法变量。这样可以分别回答两个问题：

1. 基础模型本身能否在零缺失条件下提供稳定的预测能力；
2. 在相同基础模型上，显式建模缺失过程是否仍能带来独立收益。

模型版本统一定义如下：

| 版本 | 定义 | 研究定位 |
| --- | --- | --- |
| `M0-current` | 当前原始 DeMo，不增加基础运动/交互特征 | 历史连续性基线 |
| `M0-strong` | `M0-current` 加经验证的通用运动或交互增强 | 正式缺失方法的共享基础模型 |
| `M1'` | `M0-strong` + 证据时钟解码：State Query 时间嵌入改为距最后有效观测的时间（t_evidence = forecast_gap + t） | 缺失改变输出分布的时间形状（误差层②） |
| `M2'` | `M1'` + 社会证据补偿：时间对齐的跨行人证据注意力（focal 缺失帧消费邻居同期观测+邻居掩码；解耦规则：M1' 无增益时可从 M0-strong 直接出发） | 多主体证据互补（误差层④），差异化主贡献 |
| `M3'` | `M2'` + 证据校准：模态熵正则 λ(gap)·KL(π‖高熵先验) + Laplace scale 由缺失摘要条件化（Query 条件化为实现载体） | 对抗证据塌缩（误差层③） |
| `M4'` | `M3'` + 缺失增广训练：Easy 训练时随机追加合成缺失（0–7 帧），测试用官方原样 | 训练分布扩展，Easy→Hard 泛化 |

旧特征工程版本（M1_obs 时间步特征 / M2_history 缺失摘要 / M3 Query 条件化 / M4 Hybrid 门控）已被上表替代；`M0_base`、`M1_obs`、`M2_history` 的历史实验保留为特征工程路线的对照证据，不再有对应确认性版本。`M0-strong` 不应覆盖或改写 `M0-current` 的历史结果。

## 二、问题定义与概念体系

### 1. 缺失历史轨迹预测任务

记完整历史轨迹为 `X_1:T_h`，未来轨迹为 `Y_1:T_f`，历史观测掩码为 `M_1:T_h`。其中，`M_t = 1` 表示第 `t` 个历史时刻具有有效观测，`M_t = 0` 表示该时刻的轨迹观测缺失。实际输入可记为：

> **公式：** `X^obs_t = M_t ⊙ X_t`

除位置观测外，模型还可以使用由观测过程导出的时间信息：

```text
M_t       : 当前时刻是否存在有效观测
Delta_t   : 距离最近一次有效观测的时间间隔
E_t       : 由足够有效观测计算得到的运动证据，例如位移或速度
C         : 行人交互上下文
```

任务目标是建模：

> **公式：** `p_theta(Y_1:T_f | X^obs_1:T_h, M_1:T_h, Delta_1:T_h, C)`

未来轨迹在训练和评测中保持完整，缺失只发生在输入历史窗口。轨迹插补可以作为对照方法或可选辅助，但不是本选题的主目标；主目标始终是**缺失历史条件下的未来预测质量**。

### 1.2 误差结构四层分解与改进依据（证据中心版核心）

预测性能随缺失退化可分解为四层误差来源。旧方法层只覆盖第①层，本选题方法层针对②③④层：

| 层 | 误差来源 | 覆盖设计 |
| --- | --- | --- |
| ① | 编码器不知道哪些帧可信 | M0 已内置（掩码拼输入）；不再单独设版本 |
| ② | **时间语义断裂**：最后有效观测在帧 s 时，未来的真实预测时域为 12+(7-s) 帧，但 State Query 仍按固定 12 帧解码 | **M1' 证据时钟解码** |
| ③ | **证据塌缩**：缺失越大，模态概率越自信、分布越窄，MR 恶化 | **M3' 证据校准** |
| ④ | **社会证据丢弃**：focal 缺失时段的信息部分存在于邻居的同期观测中，逐轨迹独立处理全部丢弃 | **M2' 社会证据补偿** |

关键事实基础（区别于所有插补路线工作）：TrajImpute 的缺失按轨迹独立生成，focal 缺失的帧邻居大概率仍有观测；行人成组运动的先验使邻居同期观测对 focal 缺失时段构成强约束。MS-TIP（ICML 2024，与 TrajImpute 同作者组）、GC-VRNN、BRITS 均为单主体插补路线，未利用多主体证据互补；DeMo 原文的场景注意力亦无时间对齐的缺失感知。此为本文差异化 novelty 的主要落点。

**证据中心统一叙事**（贯穿所有模块的单一句式）：

> 模型显式建模证据三要素——**知道了什么（what：观测掩码）**、**多久前知道的（when：证据时钟/forecast gap）**、**还有谁看到了（who：邻居观测掩码）**——并让三要素同时作用于历史编码与未来分布构造。

### 2. 缺失历史的现实含义与实验抽象

本选题中的“缺失历史轨迹”指历史窗口内部分时刻没有可用的行人位置观测，或观测序列在时间上不连续。它对应以下真实观测现象：

```text
遮挡或视野离开              -> 短时位置不可见
检测漏检或帧丢失            -> 离散时间步缺失
跟踪中断或重新关联          -> 连续历史片段断裂
定位质量下降                -> 后续可扩展为噪声与缺失共存
```

第一版以**历史帧缺失与连续断裂**为可控研究对象。随机缺失、连续缺失、不同缺失比例和不同缺口位置是构造任务难度与模拟观测中断的实验条件，而不是彼此割裂的研究主题。若后续加入坐标噪声、误检或身份切换，应将其作为扩展的观测退化模型，而不是提前并入当前结论。

### 3. 未来轨迹的结构化条件分布

普通多模态预测通常直接从历史上下文产生 `K` 条候选未来。结构化未来建模则进一步规定未来分布的组织方式：未来不是若干条彼此独立的完整轨迹，而是由“候选未来之间的差异”和“单条候选内部的时序演化”两类关系共同决定。前者负责区分不同的未来分支，后者负责组织每条轨迹随时间的变化。

这里的“结构化”指：

```text
不是一个隐藏向量直接对应一条完整轨迹；
而是先表示未来候选之间的差异结构，
再表示单条未来沿时间轴的演化结构，
最后对两类结构进行联合参数化。
```

记：

```text
D_k       : 第 k 个候选未来的跨候选差异表征
S_1:T_f   : 沿预测时间演化的轨迹内时序表征
Q_k,1:T_f : D_k 与 S_1:T_f 的联合未来表征
```

则可将未来轨迹分布理解为：

> **公式：** `p_theta(Y | H^miss, C) = sum_k pi_k p_theta(Y | Q_k,1:T_f, H^miss, C)`

其中：

> **公式：** `D_1:K = f_cross(H^miss, C)`

> **公式：** `S_1:T_f = f_time(H^miss, C)`

> **公式：** `Q_k,t = Phi(D_k, S_t, H^miss, C)`

因此，结构化未来建模可以写成：

```text
历史条件 H
    -> 跨候选差异表征 D_1:K
    -> 轨迹内时序演化表征 S_1:T_f
    -> 联合未来表征 Q_1:K,1:T_f
    -> 多模态未来轨迹分布
```

这是一种对未来轨迹分布的**分解表示与联合参数化**。它不要求 `D_k` 或 `S_t` 对应某个可以直接观测的心理或物理变量。DeMo 原文中的 `Mode Query` 可对应跨候选差异表征，`State Query` 可对应轨迹内时序演化表征，`Hybrid Coupling` 则对应二者的联合参数化[^1]。

### 4. 核心术语

| 术语 | 本选题中的含义 |
| --- | --- |
| 缺失历史轨迹 | 具有缺失时间步或时间断裂的行人历史观测序列 |
| 缺失结构 | 掩码、缺失位置、连续缺口长度、观测间隔等观测过程信息 |
| 缺失感知历史表征 | 同时编码可见轨迹片段及其缺失结构的预测上下文，不将缺失值当作真实运动值 |
| 跨候选差异表征 | 描述多个合理未来分支之间的差异结构，对应 DeMo 的 Mode 维度 |
| 轨迹内时序演化表征 | 描述单条未来轨迹沿时间轴的变化结构，对应 DeMo 的 State 维度 |
| 联合未来表征 | 将跨候选差异与轨迹内演化联合起来，参数化具体未来轨迹 |
| 多模态未来预测 | 对同一历史观测给出多个可能未来分支及其概率或尺度 |
| 时空上下文编码器 | 对带缺失结构的历史轨迹、有效运动关系和行人交互进行联合编码 |

## 三、问题背景与研究动机

### 1. 完整历史假设与真实观测条件之间存在差距

现有行人轨迹预测通常在完整、连续且等间隔的历史轨迹上训练和评测。该设定有利于模型从位置差分中获得速度、方向和转向趋势，但与检测跟踪系统的实际输出存在差距：一旦历史中出现缺口，部分运动变化不再可直接计算，最近观测状态与预测起点之间也可能发生时间脱节。

因此，缺失历史不是单纯少了若干坐标，而是改变了模型可使用的历史时序证据及其时间组织方式。

### 2. 缺失值不能被视为普通轨迹值

对缺失位置进行零填充、前向填充或直接插补后再输入普通预测器，容易混淆以下信息：

```text
真实静止                != 位置缺失后的零位移
低速或减速              != 长时间没有新观测
连续转向趋势            != 被缺口切断后的局部片段
最近状态可见            != 最近状态距离预测起点较远
```

因而，历史编码需要显式区分“观察到的运动几何”和“观察过程本身”，使模型能够根据缺失位置与时间间隔判断哪些历史关系可用、哪些关系不能被当作确定事实。

### 3. 缺失历史会放大未来分布建模难度

行人未来本身具有多模态性：继续前行、转向、减速、停走与避让等运动结果可以共享相似的局部历史。历史发生缺失后，多条未来之间的区分证据进一步减少，普通的一轨迹一查询式预测容易出现两类问题：

```text
多条候选轨迹趋同，无法覆盖合理未来分支；
单条候选轨迹缺少时间连贯性，速度或转向变化不稳定。
```

因此，需要同时解决两个问题：一是从不完整历史中建立有效条件上下文，二是用适合多模态未来的结构化方式表示未来分布。

### 4. DeMo 为缺失历史预测提供的结构化基础

DeMo 将多模态未来轨迹的跨分支差异与轨迹内时间演化分开表示，再通过联合表征形成具体轨迹[^1]。这一思想适合被重新放置到缺失历史任务中：当历史证据存在断裂时，模型不应只依赖单一隐藏向量直接输出未来，而应在缺失条件下分别保持候选未来的差异性和单条轨迹的时间组织。

本研究的主张不是重新定义 DeMo 的原始 Mode/State 创新，而是提出：

> **缺失历史行人预测需要观测过程条件化的历史表征，并需要将该条件上下文贯穿到结构化多模态未来分布的构造中。**

## 四、核心科研问题与研究假设

### 1. 总问题

> **如何在缺失历史轨迹条件下，将可见轨迹片段、缺失结构和行人交互上下文转化为有效的预测条件，并以跨候选差异与轨迹内时序演化相结合的结构化方式建模未来轨迹分布？**

### 2. 子问题

1. **缺失感知历史表征**

   如何使历史编码器同时识别可见运动片段、缺失位置和观测间隔，避免将缺失误认为静止、低速或确定性运动？

2. **缺失条件下的跨候选未来建模**

   当历史证据不完整时，如何维持候选未来之间的有效差异，使模型能够覆盖多个合理的行人未来分支？

3. **缺失条件下的轨迹内时序建模**

   如何根据不连续历史建立单条未来轨迹的时间演化表征，保持未来速度、方向和转向过程的合理连续性？

4. **缺失结构与联合未来分布的适配**

   缺失位置、连续缺口和观测间隔应如何作用于跨候选差异表征、时序演化表征及其联合建模，使未来分布与历史观测条件相匹配？

5. **任务层有效性**

   相比直接填补缺失值、只拼接掩码或直接复用完整历史预测器，缺失感知的结构化未来分布建模能否在 ETH/UCY 与 SDD 上稳定提高缺失历史条件下的多模态预测质量？

## 五、研究内容与方法框架

### 0A. 证据中心预测框架（方法层权威定义，2026-09-08 改版）

**M1' 证据时钟解码（Evidence-Clock Decoding）**——对应误差层②

State Query 的时间嵌入从"距历史窗口末端的时间"改为"距最后有效观测的时间"：

```text
t_evidence(t) = forecast_gap_steps + t        # 替代 t
State Query_t = TimeEmbed(t_evidence(t) · dt) + W_state(r_h)（可选保留）
```

机制含义：同样解码"未来第 5 帧"，证据新（gap=1）与证据旧（gap=6）对应不同的不确定度演化阶段——前者接近确定外推，后者应已进入高熵区。缺失由此直接改变**输出分布的时间形状**，而非仅扰动输入特征。实现边界：仅改 time embedding 的输入自变量（`model_forecast.py` 中 `time = time * dt + dt` 一处），forecast_gap_steps 字段已存在于现有 dataset 输出。旧 `use_gap_condition` 标量加法保留为 M1' 的退化对照。

**M2' 社会证据补偿（Social Evidence Compensation）**——对应误差层④，差异化主贡献

Scene Context Transformer 从"行人级 token 交互"升级为"时间对齐的跨行人证据注意力"：focal 的缺失帧 token 不再是零向量，而是显式消费 [邻居同绝对时刻观测, 邻居自身可信度掩码, 相对几何]，通过跨行人注意力聚合为该缺失帧的补偿表征；注意力掩码 = focal 缺失帧 × 邻居有效帧（双重掩码，时间对齐）。设计要点：①**不做历史恢复**——补偿表征只进入编码上下文，不产生"重建的历史轨迹"输出，与插补路线（MS-TIP/GC-VRNN/BRITS）划清边界；②轻量实现——邻居帧级 token（线性投影+位置/时间嵌入+双重掩码）加入现有 Scene Context Transformer 的 key/value，参数量增量预计 <5%；③消融支撑——天然给出"邻居有效帧数 → 补偿收益"分组分析。

**M3' 证据校准的多模态（Evidence-Calibrated Multimodality）**——对应误差层③

两个显式校准机制，均以 r_h（缺失摘要，含 forecast_gap）为条件：①**模态熵正则** `L_cal = λ(gap) · KL(π ‖ 高熵先验)`，权重随 forecast_gap 单调增大——缺失越大越强制分布摊开，直接对抗证据塌缩；②**异方差尺度**——Laplace scale 由 r_h 条件化（scale 头输入拼接缺失摘要）。Query 条件化（旧 M3 的 Mode/State 条件注入）保留为实现载体，不再是独立版本。

**M4' 缺失增广训练（Missingness Augmentation）**——训练策略层，零新增参数

Easy-direct 训练时对仍有效的历史帧随机追加合成缺失（覆盖 0–7 帧全范围），测试用官方原样样本。约束：合成缺失只作用于历史、不触未来标签、掩码同步更新、生成规则与测试分布无耦合（复用历史 v1/v2/v3 的确定性掩码生成逻辑作为增广器；生成脚本已随历史协议删除，可自 git 历史恢复）。收益：Easy→Hard 泛化 gap 缩小；P5 Hard-direct 可复用 Easy 训练模型（零样本上 Hard）；历史掩码生成资产转化为新组件。

**版本阶梯与约束**：

| 版本 | 定义 | 单变量增量 | 对应误差层 |
| --- | --- | --- | --- |

### 3. 研究空白

> **针对缺失历史行人轨迹，如何将观测缺失结构显式引入历史上下文与结构化未来分布建模，使模型在不完整输入下同时保持候选未来的覆盖性和单条轨迹的时间连贯性？**

本研究的差异化不在于声称首次研究缺失轨迹，也不在于重新命名 DeMo，而在于将以下两条已有研究线系统结合并进行任务级验证：

```text
缺失观测感知的历史时序建模
    +
多模态未来分布的跨候选/时序结构化参数化
    ->
缺失历史条件下的行人多模态轨迹预测
```

基础运动与交互增强属于支撑上述两条研究线的共享能力层，而不是第三条独立创新线。它们的作用是让比较从一个可靠的预测起点开始；真正需要在论文中重点论证的仍是：同一基础骨干在观测缺失后，是否能够通过显式观测过程条件化保持未来分支覆盖和轨迹内时间连贯性。

## 七、论文叙事与拟形成贡献

### 1. 论文主叙事

本文面向遮挡、漏检和跟踪中断导致的行人历史轨迹缺失问题。不同于假设完整历史可用的传统预测方法，本文先在统一协议下建立具有稳定运动与交互表征能力的共享基础模型，再将历史观测缺失视为条件预测中的观测过程变量：模型从可见轨迹片段、缺失掩码和时间间隔中构造缺失感知历史上下文，并基于结构化多模态未来分布建模，分别表示候选未来之间的差异和单条未来轨迹内部的时序演化，最终生成与不完整历史观测相匹配的多模态行人未来轨迹。基础模型增强用于保证比较的起点可靠，缺失观测条件化才是本文的主要方法问题。

论文叙事应明确区分两种性能目标：`M0-strong` 与外部强基线的比较反映模型的绝对预测竞争力；同一 `M0-strong` 上 `M1'` 至 `M4'` 的配对比较反映证据中心机制的独立价值。两者不能合并成一个无法归因的“整体提升”。

### 2. 拟形成的贡献

1. **任务建模贡献**

   将行人轨迹预测从“完整历史到未来”的标准设定扩展为“缺失历史观测到未来”的条件预测问题，以掩码、观测间隔和有效轨迹片段共同描述历史输入。

2. **历史表征贡献**

   在共享基础运动与交互表征之上，提出观测缺失感知的历史运动上下文建模思路，使模型区分真实轨迹变化与观测缺口，并在不连续历史下保留可用于未来预测的时序关系。加速度、转向变化和相对交互等通用增强只作为受控基础层，不单独计入缺失感知创新。

3. **结构化未来分布贡献**

   将缺失条件引入 DeMo 式跨候选差异表征、轨迹内时序演化表征及其联合参数化过程，使多模态未来生成与历史观测完整程度相适配。

4. **实证与诊断贡献**

   在 TrajImpute 官方 Easy/Hard release 上构造直接缺失预测评估（Clean 基线 = 本文 DeMo 在原始完整数据上的复现结果，暂定 0.232/0.389；原论文数字为外部参照）：先验证共享基础模型增强的有效性，再系统比较直接预测、掩码感知、插补后预测外部参考和结构化未来分布建模，并分析官方缺失设置下的准确性、覆盖性、时间连续性和退化行为；SDD 旧自定义缺失结果仅作为历史预实验证据，不构成正式主结果。

### 3. 题目与方法名称

当前推荐题目：

> **缺失历史轨迹条件下行人未来运动的结构化多模态预测**

可选的更方法化表述：

> **基于观测缺失感知历史表征与结构化未来分布建模的行人轨迹预测**

推荐的方法总称：

> **观测过程条件化的结构化多模态轨迹预测**

### 1.1 当前阶段的具体执行顺序

当前不再把“提升基础模型”和“验证缺失感知方法”混在同一轮实验中，而是先固定基础能力，再验证缺失感知增量。已有 `M0_base`、`M1_obs`、`M2_history` 结果全部保留，作为问题定位和探索性证据，不回退、不覆盖，也不直接解释为最终方法结论。

#### 第一步：冻结已有探索性证据

将第一轮结果明确归入 `M0-current` 体系。由于该轮使用 `bimamba=true`，并采用 v3 无保护协议，它可以回答“当前实现是否已经表现出稳定的缺失感知收益”，但不能直接承担最终骨干模型、受控消融或论文主表的结论。特别是，`M1_obs` 和 `M2_history` 相对 `M0_base` 的退化应作为后续校准的依据，不能通过更换指标、挑选单个场景或只报告最优种子来掩盖。

冻结内容包括数据划分、训练适配方式、指标定义、缺失掩码生成规则、随机种子记录方式、当前版本号及已有结果表。后续候选增强均须保留与 `M0-current` 的差异记录，避免把基础结构变化误认为缺失感知模块带来的收益。

#### 第二步：基础增强筛选（2026-09-13 修订：Easy-direct 单环境）

在缺失感知模块关闭的条件下，按逐项增量方式比较以下版本。**修订（2026-09-13）**：Clean 自建臂作废后，筛选环境改为 Easy-direct 单环境（M0 vs 候选增强同协议单变量对照）；Clean 不作为筛选环境，其基线采已有复现结果（《完整数据基线对比》8/28 轮，0.232/0.389）。代理环境断链问题随之消除——筛选即在目标环境进行。

- `B0`：当前模型结构和训练目标，只进行必要的优化配置校准（lr 1e-3 / wd 1e-4 / 100ep / K=20 / val_minFDE20 为既有校准配置，Easy 臂沿用；B0≈M0-current，无需重跑）；
- `B1`：在 `B0` 上加入低风险运动证据特征——跨缺口速度、加速度、速度变化率、转向变化率（跨缺口语义已统一，见 `src/datamodule/b1_motion_features.py`）。**剔除"有效观测长度"**（Clean 下恒为常数 8 的死特征，属掩码函数，归入方法层 M1' 的条件变量）；
- `B2`：**降级为条件触发候选**——仅当 M2' 社会证据补偿实验显示邻居信息有价值后再评估其手工特征相对 Scene Context Transformer 的独立增量；不再作为 M0-strong 必跑项（DeMo 已有学习式交互模块，手工交互特征与其大量重叠）。

筛选执行：

1. **筛选（Easy-direct 五场景，与主链同协议）**：候选增强与 M0-current 单变量对照，回答"缺失目标环境有无增量"（2026-09-13：原 Clean-direct 主筛选臂随自建数据作废，代理环境断链问题随之消除——筛选即在目标环境进行）；
2. **副筛选（Easy-direct 五场景 train_adapt）**：B1 与已完成的 M0-current Easy 臂同协议单变量对照，直接测 B1 的设计目标场景（缺失条件下的运动证据显式化）。

#### 第三步：固定 `M0-strong`（2026-09-13 修订）

决策规则（2026-09-13 修订：单环境）：

- B1 在 Easy-direct 五场景改善 ≥2%（minFDE20 均值）且无场景明显退化 → `M0-strong = B1`；
- 其他情况 → `M0-strong = B0`，B1 整体排除。

选择逻辑补充：只在单个场景、单个种子或单一指标上有效的增强不纳入 `M0-strong`，保留为补充实验候选。

**裁定结果（2026-09-10，2026-09-13 口径更正）**：B1 在 Easy-direct 均值改善 −2.49%（≥2% 阈值），5 场景 3 改善 2 持平 0 退化，`M0-strong = B1`，定性为证据中心输入层；原 Clean 臂数字（+0.17%）随自建数据作废，裁定仅依据 Easy-direct 单环境（详见 [主线实验记录](../results/主线实验记录.md)）。P1–P5 全部缺失感知实验自 B1 配置出发。

`M0-strong` 的目标是建立性能稳定、归因清晰、能够公平承载后续方法增量的研究骨干，而不是在缺失感知实验启动前追平所有外部 SOTA。基础模型与公开强基线之间的绝对性能差距必须优先缩小，但是否进入下一阶段仍由稳定性和可归因性决定。

#### 第四步：在 Easy-direct 上验证 `M1'` 与 `M2'`

`M0-strong`（=B1）固定后，按 §五.0A 版本阶梯验证证据中心模块：`M1'` 证据时钟解码（State Query 时间嵌入重参数化，已实现并通过单元测试，P1 五场景 train_adapt 已于 2026-09-10 启动）；`M2'` 社会证据补偿（时间对齐的跨行人证据注意力；解耦规则允许 M1' 无增益时从 M0-strong 直接出发）。验证在 Easy-direct 上进行；随机/连续缺口、末端缺失等机制差异不作为新的正式协议，只作为基于直接预测扩展数据的分组分析。若某模块在特定分组（如长连续缺口）中失效，结论应限定为“对特定缺失结构无效”，不能概括为普适的缺失鲁棒性。（2026-09-13 更正：Clean-direct 完整历史退化检查随 Clean 臂作废；模块验收以 Easy-direct 主指标 + Hard-direct 鲁棒性为准。）

#### 第五步：通过确认性门槛后再进入 `M3'/M4'`

`M3'`（证据校准）与 `M4'`（缺失增广训练）引入新的训练目标与训练分布变化，训练难度和解释成本增加（M4' 零新增参数）。因此只有同时满足以下条件，才进入下一段模型搭建：

- `M0-strong`（=B1）在 Easy-direct 上稳定优于 `M0-current`（P0.5 裁定），且差异可由统一协议解释；
- `M1'` 或 `M2'` 至少在一种代表性缺失机制下改善主要指标，且不是单种子偶然结果；
- 改进在 Hard-direct 上方向不反转，或退化能够被明确说明为可接受的鲁棒性权衡；
- 缺失掩码、训练目标和评估协议已经固定，新增结构不会再次改变问题定义。

若条件未满足，应优先定位信息利用、训练目标或协议问题，而不是继续堆叠更复杂模块。

### 1.2 基础增强的统一验收标准

基础模型增强必须同时通过性能、稳定性和归因三道门槛。性能门槛用于判断增强是否真正改善预测，稳定性门槛用于排除单次偶然，归因门槛用于保证论文能够说明收益来自什么。

#### 性能门槛

以 `minFDE20` 作为第一主指标（主链 K=20，§1.6），以 `minADE20`、`MR` 和 `b-minFDE20` 作为辅助指标。候选增强至少应满足以下之一：

- 在 Easy-direct 零缺失分组（m=0）上，`minFDE20` 和 `minADE20` 均不劣于当前基线，并在至少一个主指标上出现具有实际意义的改善；
- 主指标改善幅度有限，但同时降低 `MR` 或 `b-minFDE20`，说明增强改善了失败样本或最差预测，而不只是平均值波动；
- 零缺失分组近似持平，但在缺失分组（m=1–4）表现出稳定收益，且收益能够由新增信息解释。

不能将仅有一个指标变好、其他关键指标明显退化的版本直接定义为“基础模型增强成功”。尤其不能只依据 `minADE20` 的改善宣称模型更强，因为终点误差、失败率和最差预测质量可能呈现不同变化方向。

#### 稳定性门槛

首轮可以使用已有单种子结果进行筛选，但入选 `M0-strong` 前应至少进行相同数据划分下的 3 个种子复验，并报告均值、标准差以及最佳和最差种子。若资源允许，再在五折结果上报告折间波动。候选增强不应只在一个种子上领先，而应在大多数种子或折上保持方向一致。

#### 归因门槛

每次实验只改变一个主要因素，并记录以下内容：

- 基础结构差异；
- 输入特征差异；
- 训练目标和损失权重差异；
- 缺失掩码及数据协议差异；
- 解码方式、采样数和后处理差异。

如果一个版本同时修改结构、特征和训练策略，即使最终数值提升，也只能作为工程候选，不能作为论文中的因果消融结论。基础增强实验还必须同时报告零缺失分组与缺失分组结果，避免出现“零缺失变强、缺失退化”却仍被直接定义为共享骨干升级的情况。

### 1.6 指标与评价口径

三类指标不得互相替代：

- **TrajImpute 原论文可参考指标**：ADE/FDE，具体口径按其预测实验与外部模型实现核验（官方仓库无原生 evaluator，见 §八.0.1）。不声称 TrajImpute 官方 evaluator 原生支持本文的多模态指标。
- **本文多模态预测指标**：主指标族为三件套 `minFDE_K` + `b-minFDE_K` + `MR`（与证据中心机制匹配：minFDE 看最优模态，b-minFDE 捕捉概率校准即 M3' 熵正则的直接受益项，MR 观测证据塌缩）；`minADE_K`、ADE@1/FDE@1、覆盖率与时间连续性作为辅助。**主链 K=20（2026-09-08 裁定，与 TrajImpute 官方预测协议对齐）**：全部正式实验（P0 起）统一 `num_modes=20`、指标名 minFDE20/minADE20/b-minFDE20，与官方插补后预测及 ETH/UCY 社区 K=20 惯例同口径，直接可比。K=6 仅为历史 v1/v2/v3 预实验与 v3 首筛的口径，不再使用、不再续跑；历史 K=6 数字不与 K=20 主结果混排。
- **插补质量指标**：MAE、MSE、RMSE、MRE，仅用于插补器对照（外部参考），不用于替代本文未来预测指标。

历史 v1/v2/v3 的 `minFDE6` 结果只在历史预实验文档内部比较，不进入 direct 主表，也不与官方插补后预测数字并排。

### 1.7 当前阶段的最终决策规则

当前不需要因为已有 `M0-M2` 结果不理想而废弃选题，也不应直接跳到复杂的 `M3'/M4'`。执行顺序固定为：

1. 保留已有结果作为问题证据，明确标注其为 `M0-current`、历史 v3 无保护、单种子探索性结果（见 §八.0 统一说明）；
2. 在 Easy-direct 上完成 `B0/B1/B2` 基础增强筛选，并用多种子确认 `M0-strong`；
3. 在相同强基础骨干（`M0-strong`=B1）上、于 Easy-direct 验证 `M1'/M2'`，缺失机制差异以直接预测扩展数据的分组分析呈现；
4. 只有确认性结果成立后，才进入 `M3'/M4'` 与 Hard-direct 高缺失鲁棒性实验；
5. 最后再进行多种子、direct 两协议（Easy/Hard）、外部插补后预测参考与 SDD 扩展证据的完整比较。

如果复验后仍没有稳定的缺失感知收益，应把研究问题收敛为“缺失历史条件下的退化建模、协议分析与可靠性评估”，而不是继续堆叠模块。如果复验出现稳定收益，再进入更完整的耦合模型，并用表二和表三分别证明模块增量与缺失鲁棒性。

这种推进方式同时保留已有工作的价值和当前选题的连续性：已有 `M0-M2` 解释了直接加入缺失模块为何没有自动带来提升；基础增强阶段解决基础能力差距和实验归因问题；后续 `M1'` 至 `M4'` 则检验证据中心方法能否在更可靠的骨干上产生独立贡献。

### 2. 实验任务协议

**正式主协议（2026-09-13 修订）**：Easy-direct/Hard-direct 使用 TrajImpute 官方 Easy/Hard release pkl，均为直接预测，不经外部插补；缺失历史 + missing mask + 有效观测间隔 + 场景信息直接输入模型，预测完整未来轨迹。Clean = 原始 ETH/UCY 零篡改（本文 Clean 基线 = DeMo 复现，暂定 0.232/0.389，8/28 轮；原论文数字为外部参照）；自建 benchmark_v1 已作废。

**历史自定义协议（已归档，不作为待执行主计划）**：v1（帧 0–5 缺失、帧 6/7 恒可见）、v2_high（同保护规则、37.5%–75% 高缺失）、v3_noguard（帧 0–7 全窗口无保护、锚点回退最后可见帧）。这些协议用于历史预实验与问题定位，其结果不与 direct 主结果混合。缺失帧数、连续缺口、缺口位置等维度若重新引入，只能作为基于直接预测扩展数据的**分组分析或补充分析**，不能作为新的正式协议。

### 4. 基线与消融关系

建议将对照设计围绕研究假设组织，而不是按网络组件堆叠：

| 对照组 | 回答的问题 |
| --- | --- |
| Easy m=0（零缺失）分组 `M0-current` | 零缺失条件下的历史基准 |
| Easy m=0（零缺失）分组 `M0-strong` | 经过受控增强后的基线能力 |
| 缺失历史 + 原始输入处理 | 原始模型面对缺失的自然退化 |
| 缺失历史 `M0-strong` | 强基础模型面对缺失的自然退化 |
| 缺失历史 + 零填充/前向填充 | 简单缺失处理是否已足够 |
| 旧 `M1_obs`/`M2_history`（历史结果引用） | 输入特征工程路线是否无增益（排除平凡解释的对照） |
| `M1'`：证据时钟解码 | 时间重参数化是否改善缺失下输出分布的时间形状 |
| `M2'`：`M1'` + 社会证据补偿 | 邻居同期观测能否补偿 focal 缺失证据 |
| `M3'`：`M2'` + 证据校准 | 熵正则/异方差尺度能否对抗模态塌缩 |
| `M4'`：`M3'` + 缺失增广训练 | 训练分布扩展能否缩小 Easy→Hard 泛化 gap |
| 插补后预测或插补预测联合方法 | 直接预测与显式插补路线的关系（表四范式级比较） |

为保证每个结果可归因，正式实验至少应保留以下三组比较；每个方法版本报告 train_adapt（Easy-direct 同分布）；zero-shot 线（Easy 训练→Hard 测试）由 P5 承担，机制假说预期在 Hard-direct 上最显形：

```text
基础增益：      M0-strong - M0-current
缺失历史增益：  M1'/M2'/M3'/M4' - M0-strong
协议退化：      同一模型的 Easy-direct -> Hard-direct test
```

其中，基础增益回答“模型本身是否变强”，缺失历史增益回答“观测过程条件化是否有效”，协议退化回答“模型在缺失程度变化下是否稳健”。三者必须使用相同的 fold、seed、训练数据边界、checkpoint 选择规则和评测口径；不能用 `M0-current` 与 `M4'` 的非配对结果直接声称缺失感知带来全部提升。

| `M0_base` | `M0-current` 上的缺失历史基线 | 已由 B1（=M0-strong）Easy 臂与 M1'–M4' 阶梯接管 | 当前 DeMo 对缺失输入的自然退化 |
| `M1_obs` | 观测时间步特征探索 | 无确认版本（特征工程路线已证伪） | 输入特征工程无增益的对照证据 |
| `M2_history` | 历史级缺失摘要探索 | r_h 保留为 M3' 校准条件变量，无独立确认版本 | 同上 |

其结果保持为单种子探索性证据，可进入研究记录与方法筛选，但不作为论文主表中的确认性证据。

### 5. 评价维度

| 维度 | 评价内容 |
| --- | --- |
| 预测准确性 | ADE、FDE、minADE、minFDE、Miss Rate |
| 缺失鲁棒性 | 不同缺失比例、连续长度、缺口位置下的性能曲线 |
| 多模态覆盖 | 最优候选命中、终点/方向多样性、合理未来分支覆盖 |
| 时间连续性 | 速度、加速度、曲率、转向变化的合理性与稳定性 |
| 概率与不确定性 | 模态概率、尺度、覆盖率、Energy Score 或校准指标 |
| 跨场景泛化 | ETH/UCY 不同场景与 SDD 上的趋势一致性 |
| 定性案例 | 转弯、减速、停走、避让、长连续遮挡后的未来预测 |

内部表示诊断可以辅助解释模型行为，但不应替代未来轨迹上的任务评价。论文结论应以缺失历史条件下的未来预测、覆盖性和连续性证据为主。

### 6. Go / No-Go 判断标准

**Go 条件**

- `M0-strong` 在 Easy-direct 相对于 `M0-current` 有跨场景、跨 seed 的稳定改善（P0.5 单种子已裁定，多种子复验待补），或至少显著降低了基础模型的优化不稳定性；
- 缺失感知历史表征相对于零填充、简单掩码或未适配编码带来稳定收益；
- 缺失条件进入结构化未来分布后，除误差外还能改善模态覆盖或时间连续性中的至少一项；
- 收益在 Hard-direct 高缺失扩展评估中仍可观察到，而非只存在于 Easy-direct 轻度缺失；
- 主结果能够在 TrajImpute 官方五场景的多数子集上复现一致趋势，SDD 扩展证据方向不冲突；
- 零缺失分组（m=0）性能不发生不可接受的退化。

**No-Go 信号**

- `M0-strong` 的所谓提升只出现在单一 seed、单一场景或测试集调参后；
- 基础模型增强与缺失感知增强同时引入，导致无法分离两者的贡献；
- 简单填充或单纯拼接掩码已解释全部收益；
- 缺失感知历史编码无效，而复杂未来结构只增加参数量；
- 方法仅改善内部表征诊断，不改善真实未来预测、覆盖性或连续性；
- 收益只出现于 Easy-direct 或单一数据场景，Hard-direct 下方向反转；
- 未适配 DeMo 在所有缺失条件下已达到相同效果。

若出现 No-Go 信号，应据证据收缩论文主张：可能转向“缺失历史下 DeMo 的系统性评估与失败边界”，或重新定位新增方法的有效作用位置。

## 九、研究范围与待确定事项

### 1. 当前范围

```text
任务对象      : 行人历史轨迹缺失条件下的多模态未来预测
数据基准来源  : Easy/Hard-direct 使用 TrajImpute 官方 release pkl；Clean = 本文 DeMo 复现（暂定 0.232/0.389）
本文评估协议  : Easy-direct / Hard-direct（直接缺失预测；Clean = 本文复现基线）
外部参考协议  : TrajImpute 官方 Clean / Easy-impute / Hard-impute（插补后预测）
扩展验证数据  : SDD（跨数据集扩展证据；旧自定义缺失结果不构成正式主结果）
基础框架      : DeMo 的结构化多模态未来建模
共享基础层    : 运动与轻量相对交互增强，形成 M0-strong
缺失编码层    : 缺失观测感知的行人时空上下文编码器
核心新增方向  : 缺失感知历史表征 + 缺失条件化结构化未来分布
主要评价      : 预测准确性、模态覆盖、时间连续性、缺失鲁棒性
```

历史 v1/v2/v3 自定义协议及其结果文档已删除（2026-09-13），结论并入本文档（§八.0 统一标注、§八.1 首筛表）；不作为正式主实验协议。

### 2. 暂不作为第一版主线的内容

```text
完整轨迹插补作为最终目标
直接解释隐藏向量为真实心理意图或物理状态
地图信息建模
定位噪声、误检、身份切换的联合退化建模
同时复现多个完整外部模型
```

这些方向可作为对照、扩展或后续工作，但不应稀释当前“缺失历史条件下的结构化多模态行人轨迹预测”主线。

### 3. 后续需要通过实验确定的事项

- 哪些通用运动或交互增强能够稳定改善 `M0-current`，并值得进入共享基础模型 `M0-strong`；
- 缺失条件最有效的表示是掩码、时间间隔、有效运动片段，还是三者的组合；
- 缺失条件应只影响历史编码，还是还应作用于 Mode/State Query 与 Hybrid Coupling；
- 是否需要显式插补分支、完整历史教师或运动学辅助约束；
- 不同缺失类型的训练测试分布应如何组织，才能同时反映适应性与泛化性；
- 最终采用的模态数量、缺失难度、概率评价指标和统计检验口径。

历史 v1/v2/v3 自定义协议及其全部结果文档已删除（2026-09-13），保留结论：浅层"加输入通道"式缺失感知（M1_obs/M2_history 首筛，+7.8%/+3.0% 恶化）无增益，作为"输入特征工程路线无增益"的对照证据（§八.1）。当前正式协议见 §八.0。
