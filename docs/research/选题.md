# 部分观测条件下行人可靠连续运动状态估计与多模态轨迹预测

_研究框架记录 · 更新时间：2026-09-01 · 当前基础模型：DeMo；研究领域：行人轨迹预测_

## 一、选题定位

本选题面向行人轨迹预测，以 **DeMo** 为基础模型，将其应用于 ETH/UCY 和 SDD 等行人轨迹预测数据集，并进一步研究历史轨迹只能被部分观测时的可靠连续运动状态估计问题。

核心问题是：

> **在行人历史轨迹只能被部分观测时，模型能否根据有限运动证据及其可靠性，估计面向未来预测的连续运动状态，并将状态估计转化为合理的多模态未来轨迹？**

研究分为两个层级：

| 层级 | 内容 | 定位 |
| --- | --- | --- |
| 基础模型 | DeMo 在行人轨迹预测领域的应用 | 建立可在 ETH/UCY 和 SDD 上运行的多模态预测基础 |
| 结构调整 | 单向时间 Mamba | 历史时序编码的结构选择，不单独作为核心创新 |
| 研究问题 | 部分观测下的可靠连续运动状态估计 | 论文需要回答的核心科学问题 |

整体研究链为：

```text
部分观测的行人历史轨迹
    -> 可用运动证据与行人交互上下文
    -> 运动证据可靠性判断
    -> 可靠连续运动状态估计
    -> 宏观运动趋势与动态状态组合
    -> 多个未来运动演化假设
    -> 多模态行人轨迹预测
```

DeMo 在行人轨迹预测领域的应用和 UniMamba 历史编码是研究基础或结构选择，不单独构成核心创新。需要验证的是：**可靠连续运动状态估计是否比普通隐藏状态或简单输入掩码保留更多面向未来的运动信息，并由此改善多模态轨迹预测。**运动模式不再作为独立的中间研究对象，而作为状态估计在未来轨迹中的功能性表现进行观察和评价。

## 二、研究对象与概念边界

### 1. 连续运动状态

本文中的“连续运动状态”指由历史轨迹、有效运动证据和行人交互上下文共同支持的、面向未来预测的潜在状态估计。它不是预先定义的行为类别，也不等同于某一个瞬时物理量，而是对行人当前运动条件及其短期演化倾向的连续描述。

第一版以方向—动力学作为可解释核心：

```text
方向证据：位移方向、航向变化、曲率、转向趋势
动力学证据：速度、加速度、速度变化、减速或停止趋势
```

完整的运动状态估计还可以结合：

```text
方向与动力学证据
    + 局部行人交互上下文
    + 观测可靠性
    + 连续潜在状态
```

因此，方向—动力学是第一版的主要解释维度，行人交互与观测可靠性是影响状态估计的条件，最终状态可以位于连续潜在空间中。这里的“方向—动力学”不是对运动状态的封闭定义，而是用于第一阶段诊断和监督的可操作维度。

### 2. 运动状态估计与运动模式的关系

| 概念 | 本选题中的含义 |
| --- | --- |
| 可靠连续运动状态估计 | 根据有限观测证据，对方向、速度、加速度、转向趋势等未来相关状态及其不确定性的估计 |
| 历史运动表征 | 对部分观测历史进行编码后得到的网络潜在向量，尚未自动获得运动学解释 |
| 运动模式 | 连续运动状态在未来轨迹中表现出的持续方向、速度变化、转向或停走等功能性结果，不是独立的核心中间变量 |
| 未来轨迹模态 | 未来轨迹分布中的一个可能分支 |

普通隐藏特征不天然等于运动状态估计。只有当历史表征受到运动学证据约束，并且其质量能够通过状态诊断、状态不确定性校准和未来预测验证后，才可以将其解释为可靠连续运动状态。运动模式只用于检验这种状态估计是否对未来运动演化有实际作用。

当前研究不要求中间表示具有严格的 Bayesian belief state 形式，除非后续能够明确输出并验证相应的状态后验分布；在缺失证据不足时，允许状态估计表现为带有歧义和不确定性的连续表示。

### 3. 部分观测历史范围

研究对象是一个固定历史窗口内的部分观测历史轨迹：

```text
有效时间步 -> 编码真实运动证据
缺失时间步 -> 屏蔽无效证据并降低可靠性
窗口结束 -> 根据证据可靠性估计当前连续运动状态及其不确定性
未来时间段 -> 将状态估计转化为多个未来运动演化假设
```

本文统一使用“部分观测历史”描述输入条件。随机缺失、连续缺失或特定时间位置缺失不再作为彼此独立的研究问题；缺失程度、有效观测比例和观测间隔只用于构造不同难度的输入条件。

研究重点不是先恢复一条确定性的完整历史，而是根据可见证据估计当前连续运动状态及其不确定性。未来轨迹在训练和评测中保持为完整目标，历史部分观测只作用于模型输入；运动模式仅作为状态估计对未来轨迹产生作用时的功能性结果。

当前实验按两个阶段控制缺失难度：第一阶段使用 0%、12.5% 和 25% 的 v1 条件建立接口与轻度缺失基线；下一轮扩展到随机缺失 3 帧（37.5%）、4 帧（50%），以及连续缺失 4 帧（50%）和 6 帧（75%），并在相同缺失率下比较随机缺失与连续缺失。下一轮方案仍固定历史帧 6、7 可见，以隔离缺失程度变化与局部坐标锚定变化。

## 三、问题背景与研究动机

### 1. 行人预测需要运动状态信息

行人未来轨迹不仅由历史位置决定，也受到当前运动状态影响。相同的局部位置可能对应继续前进、转向、减速、停止或避让等不同未来。

```text
历史位置
    -> 方向与动力学证据
    -> 当前连续运动状态
    -> 未来多模态轨迹
```

因此，未来预测不仅需要回答“行人在哪里”，还需要利用历史证据判断“行人正在如何运动”。

### 2. 历史缺失会改变运动证据

历史坐标缺失后，丢失的不只是若干位置值，还可能丢失由位置差分得到的方向、速度、加速度和转向证据。

需要区分：

```text
潜在运动状态没有改变，只是可见观测减少

潜在运动状态已经改变，但关键变化证据被缺失遮蔽
```

当缺失遮蔽运动变化证据时，剩余观测可能不足以判断转向、减速、停止或避让等状态变化。

因此，研究重点不是预设缺失一定破坏模式，而是分析：

> **剩余运动证据能否支持可靠的连续运动状态估计，以及这种状态估计是否能够带来独立的未来预测收益？**

已有研究表明，不完整历史可以直接用于未来轨迹预测，模型不一定需要先恢复一条确定性的完整历史。本选题进一步关注部分观测条件下的连续运动状态如何形成，以及这种状态估计如何服务于多模态预测。

## 四、DeMo 的基础作用与可复用设计

DeMo 将多模态预测拆分为方向意图和动态状态，并通过 Attention、Mamba 及其耦合结构生成未来轨迹。这与本选题将潜在运动状态分解为宏观运动趋势和动态状态的设想相匹配。

可以复用的设计包括：

| DeMo 设计 | 在本选题中的作用 |
| --- | --- |
| Mode Queries | 表达多个候选宏观运动趋势，不对应人工行为标签 |
| State Queries | 表达动态状态的时间演化，并作为历史状态估计的结构参考 |
| Mode Cross-Attention / Self-Attention | 从历史和行人交互上下文中选择、区分不同运动证据 |
| Attention + Mamba | 分别聚合关系信息和建模时间序列状态 |
| Hybrid Coupling | 融合宏观运动趋势和动态状态，形成未来预测条件 |
| 多模态预测头 | 输出多条未来轨迹及其概率或尺度 |

上述结构作为本选题的主体建模框架直接使用。研究重点不在于回避或重新命名 DeMo 的原有设计，而在于考察趋势—状态分解框架应用于行人轨迹预测和部分观测状态估计时，对有限运动证据、不确定性和未来预测的作用。

DeMo 原本面向自动驾驶交通参与者。本选题将其应用于行人轨迹预测领域，并围绕行人轨迹输入、邻居交互和 ETH/UCY、SDD 评测任务建立适配版本。

### 1. 当前结构调整的准确定位

#### 面向行人轨迹预测的任务应用

当前模型的任务设定为：

```text
focal 行人及邻居历史轨迹
    -> 每个行人的历史时间编码
    -> 行人之间的交互建模
    -> DeMo 趋势/状态解耦
    -> 多模态未来轨迹
```

ETH/UCY 和 SDD 在本选题中作为行人轨迹预测领域的应用数据集，用于检验趋势—状态分解框架在行人运动预测任务中的适用性。

#### 单向 Mamba 的定位

将 BiMamba 改为 UniMamba 可以作为历史时间建模结构调整。其合理动机是保持历史编码的时间方向一致性并降低结构复杂度，但它不能自动成为新的运动状态理论。

当前代码中，历史编码器的 `bimamba` 参数默认关闭，而时间解码器中的两个 Mamba 分支仍有显式的双向配置。因此，实验时应将各路径的方向性参数显式配置，并把 UniMamba/BiMamba 作为独立消融变量，不能仅凭模块名称推断实际使用的算子。

#### 重新包装的边界

可以将整个方法表述为：

> **面向行人轨迹预测的 DeMo 趋势—状态建模 + 部分观测条件下的可靠连续运动状态估计。**

其中，DeMo 向行人轨迹预测领域的应用和 UniMamba 是任务适配或结构选择；真正需要研究的是部分观测条件下运动证据的可靠性、连续运动状态估计，以及状态估计对趋势—状态融合和未来预测的影响。运动模式只作为连续运动状态对未来轨迹产生作用时的功能性表现，不单独作为原创模块。

### 3. 理论支撑与研究线索

现有文献对本选题的支撑主要来自“部分观测下的状态估计”和“运动不确定性建模”两条理论链，而不是某一篇论文已经直接解决了本研究问题。

#### 3.1 部分观测历史是潜在运动状态估计问题

将完整历史轨迹记为 `Xₜ`，观测掩码记为 `Mₜ`，实际输入可以表示为：

> **公式：** `X̃ₜ = Mₜ ⊙ Xₜ`

模型需要估计的是当前运动状态或信念状态，而不是简单恢复缺失坐标：

> **公式：** `bₜ = p(Sₜ | X̃₁:ₜ, M₁:ₜ, C₁:ₜ)`

其中 `Sₜ` 表示运动状态，`Cₜ` 表示行人交互上下文。

Sun 等人的 Graph-VRNN 将部分观测下的当前状态估计与未来预测统一到图结构变分模型中[^10]，为本研究提供了从不完整观测中建模运动状态不确定性的参考。因此，缺失时间步不应被当作真实坐标或确定性插补结果参与运动状态估计。

#### 3.2 缺失掩码和时间间隔属于运动证据可靠性

STGN-IT 通过观测状态编码区分可见和不可见轨迹，避免模型把填充值误认为真实位置[^3]。GC-VRNN 使用时间衰减模块学习缺失轨迹中的时序模式，并通过共享时空特征联合处理插补与预测[^11]。GRU-D 则将观测掩码、距上次观测的时间间隔和可学习衰减直接融入时序表示[^16]。

这些研究支持将以下信息统一解释为**运动证据可靠性**：

- 当前时间步是否有真实观测；
- 距离上一次有效观测的时间间隔；
- 当前历史状态应保留多少；
- 证据不足时预测分布应扩大多少。

但 GRU-D 关于缺失模式具有任务信息的结论来自医疗时序数据，不能直接假设适用于行人轨迹预测。对行人轨迹而言，观测可靠性应作为模型输入和可验证假设，而不是预先确定的行为因果变量。

#### 3.3 部分观测会造成运动状态估计歧义

Momentary Observation 将历史观测压缩到极端的两帧，指出加速度、减速和转向等时间运动线索会明显缺失，而速度、社会上下文和场景上下文仍可提供补充信息[^12]。DTO 进一步显示，完整观测教师可以帮助少观测学生恢复部分预测能力，但在复杂转向等动态情况下，少量观测仍不足以确定接近真实轨迹的运动状态[^13]。

这两项研究支持本选题的一个重要边界：

> 部分观测下不应要求模型恢复唯一确定的运动状态，而应输出与证据可靠性相匹配的连续状态估计及其不确定性。

#### 3.4 时变潜变量支持多模态状态推断

Graph-VRNN 使用变分隐变量表示部分观测下的状态不确定性[^10]。SocialVAE 在每个预测时间步引入潜变量，并用条件先验、后向后验和社会注意力建模动态决策与多模态轨迹[^15]。DisDis 则将个体运动状态表示为可区分的潜变量分布，并从概率分布层面评价多模态预测[^14]。

这些工作为 DeMo 的 mode/state 解耦提供了补充支撑：

```text
Mode -> 候选宏观运动趋势假设
State -> 随时间变化的动力学状态
Hybrid Coupling -> 趋势与状态的组合
```

但 Mode Query 或 State Query 本身不等于真实运动状态。只有当其表示能够与方向、速度、加速度、转向趋势等运动证据建立稳定关系，并且能够改善未来轨迹预测时，才能认为它承担了有效的运动状态估计功能。

#### 3.5 插补、直接预测与实验评价

GC-VRNN 和 MS-TIP 说明插补与未来预测可以通过共享时空表示联合建模[^11][^5]。TrajImpute 则通过均匀随机缺失、不同缺失程度和统一评价协议，展示了插补误差增加会导致预测性能下降，并指出直接处理缺失坐标的预测模型仍有必要[^6]。

对本研究而言，这些工作提供三点线索：

1. 部分观测历史必须保留在评测中，不能只保留完整样本；
2. 插补结果不能默认等价于真实观测，应保留观测可靠性信息；
3. 运动状态估计质量和未来预测质量应同时评价。

随机缺失可以作为构造部分观测历史的实验方式，但不再被定义为独立的研究类型。

#### 3.6 可靠连续运动状态估计的拟议机制

以下内容是用于界定研究假设的概念层机制，不是已经确定的网络层实现。具体采用何种编码器、门控形式或损失函数，应以后续对照实验结果为准。

本选题中的“可靠”不是简单地把有效掩码再次拼接到输入，而是要求模型显式区分真实观测、由真实观测计算出的运动证据和缺失时间步的无效证据。

每个历史时间步可以由以下信息构成运动证据：

```text
位置位移、速度、加速度、方向或曲率
    + 当前时间步是否有真实观测
    + 当前运动证据是否能够由足够的有效观测计算得到
    + 距上一次有效观测的时间间隔
    + 历史窗口中的有效观测比例
```

观测掩码与运动证据掩码不能混为一谈。例如，当前和前一时刻都有位置观测，才可以计算该时间间隔的位移和速度；加速度、曲率和转向趋势通常还需要更多连续有效观测。对于无效时间步，不应通过零填充位置继续计算速度或加速度，否则模型可能将“缺失”误认为“停止”。可定义运动证据可靠性 `ρₜ`：

> **公式：** `ρₜ = f(观测掩码、运动证据掩码、距上一次有效观测的时间间隔、有效观测比例)`

最简单的先验形式是：有效观测的可靠性接近 1，缺失时间步的可靠性随时间间隔增加而衰减。更复杂的形式可以由网络学习，但必须通过实验验证其是否具有实际意义。

运动证据编码可以使用掩码、时间间隔和可学习衰减进行可靠性加权：有效运动证据参与表示学习，缺失时间步的证据被屏蔽或降权，时间间隔越长，可靠性越低。该设计不要求额外增加独立的时序分支。

在此基础上，连续运动状态估计由 focal 行人的历史运动表征、有效运动证据和行人交互上下文共同支持。DeMo 的 Mode 表示较长期的候选宏观运动趋势，State 表示随时间变化的动态状态，二者共同构成面向未来的运动状态表示。二者都可以是连续表示，不要求预先建立固定的“直行、转弯、停止”等行为类别。若解码阶段使用的是历史窗口级可靠性，应使用历史可靠性摘要，而不能把未来真实观测掩码作为输入。

#### 3.7 可靠性条件化的趋势—状态融合

原始 DeMo 的 Hybrid Coupling 主要通过趋势查询和状态查询的组合形成混合查询。若直接采用固定相加：

> **公式：** `qₖ,ₜ = qₘᵏ + qₛᵗ`

则没有显式考虑当前运动证据是否可靠。

本选题拟研究可靠性条件化的融合方式。可以定义趋势—状态门控：

> **公式：** `gₖ,ₜ = σ(MLP([qₘᵏ, qₛᵗ, ρH, c]))`

并使用：

> **公式：** `qₖ,ₜ = LN(qₘᵏ + gₖ,ₜ Wₛ qₛᵗ + Wc c)`

其中 `qₘᵏ` 是第 `k` 个宏观运动趋势假设，`qₛᵗ` 是第 `t` 个动态状态，`c` 是历史窗口对应的行人交互上下文，`ρH` 是由历史证据得到的可靠性表示。

该机制的目标不是在缺失时强行选择一个模式，而是：

```text
证据充分 -> 宏观趋势与动态状态进行更确定的耦合
证据不足 -> 保留多个合理状态假设，减少过早收缩到单一未来
缺失间隔增加 -> 预测分布表达更大的不确定性
```

因此，可靠性还可以输入轨迹尺度和模态概率预测头，使观测条件同时影响状态表示、趋势—状态融合和最终预测分布。

#### 3.8 训练约束与可验证表示

可靠连续运动状态不能只通过论文命名获得，需要在训练和评测中获得运动学证据支持。可在原始 DeMo 预测损失之外加入少量辅助约束：

> **公式：** `ℒ = ℒDeMo + λkin ℒkin + λcons ℒcons`

`ℒkin` 用于约束趋势—状态表示能够预测方向、速度、加速度或转向趋势；`ℒcons` 用于约束同一完整轨迹在完整输入和部分观测输入下的状态表示一致性。不同 Mode Query 存在排列问题，比较前需要根据预测轨迹或趋势距离进行匹配。

训练时可以使用完整历史轨迹构造部分观测版本，完整历史只提供监督信号，不作为部分观测输入的一部分。这样可以研究模型是否从剩余证据估计合理状态，而不是依赖完整历史。

该设计不要求额外加入插补网络、外部生成式对照或固定行为分类器。最小研究方法应优先验证“可靠性估计 + 可靠性加权运动证据编码 + 趋势—状态条件化融合”这一条主线。

#### 3.9 当前优先方法路线

结合上述文献，当前最推荐的不是同时堆叠多个完整模型，而是形成一条清晰的最小方法链：

```text
GRU-D：观测掩码 / 时间间隔 / 状态衰减
    + DeMo：Mode / State 解耦骨架
    + DeMo++：Mode / State 的运动学和时序监督线索
    + FiLM 或 GMU：可靠性条件化融合
    -> 部分观测条件下的可靠性条件化 DeMo
```

其中，FiLM 和 GMU 是条件化融合的两种可选实现，不建议第一版同时引入。优先方案是使用由历史观测可靠性生成的门控，对 Mode 与 State 的耦合强度进行调节：

> **公式：** `gₖ,ₜ = σ(MLP([qₘᵏ, qₛᵗ, ρH, c]))`

> **公式：** `qₖ,ₜ = qₘᵏ + gₖ,ₜ Wₛ qₛᵗ`

该路线不要求复刻每篇论文的完整网络，而是提取以下四个可组合机制：

| 机制 | 主要参考 | 在本选题中的作用 |
| --- | --- | --- |
| 掩码、时间间隔与衰减 | GRU-D [^16] | 构造运动证据可靠性并控制历史状态保留程度 |
| Mode/State 表示与辅助监督 | DeMo [^1]、DeMo++ [^17] | 形成连续运动状态表示及其运动学诊断 |
| 条件化融合 | FiLM [^18]、GMU [^19] | 让可靠性决定 Mode/State 或交互信息的融合强度 |

### 5. 文献支撑下的研究空白

上述文献已经分别解决或讨论了缺失轨迹输入、部分观测状态估计、轨迹插补、短观测预测、时变潜变量和多模态生成。因此，本研究不应声称“首次研究缺失轨迹预测”或“首次利用隐状态处理缺失”。

更准确的研究空白是：

> 现有方法主要关注缺失坐标处理、轨迹插补或最终预测误差。本研究拟进一步统一部分观测历史、运动证据可靠性、连续运动状态估计、行人交互上下文和 DeMo 的趋势—状态多模态预测，并验证状态估计质量能否独立传递到未来预测。

本研究的核心线索因此收敛为：

```text
部分观测历史
    -> 有效运动证据与行人交互上下文
    -> 运动证据可靠性
    -> 连续运动状态估计及其不确定性
    -> 可靠性条件化的 DeMo 趋势—状态融合
    -> 多个未来运动演化假设
    -> 未来多模态轨迹预测
```

## 六、核心科研问题与假设

### 总问题

> **当行人历史轨迹只能被部分观测时，基于 DeMo 的预测模型能否从有限运动证据中估计可靠的连续运动状态，并将该状态估计转化为合理的多模态未来轨迹？**

### 子问题

1. **运动证据与状态可观测性**

   历史轨迹不完整时，哪些有效观测仍能支持方向、速度、加速度和转向趋势判断？部分观测程度如何影响运动状态的可辨识性和不确定性？

2. **部分观测下的连续运动状态估计**

   如何利用有效观测、观测间隔和行人交互上下文，形成比普通隐藏特征更具有运动学含义的连续运动状态表示？

3. **状态估计对未来预测的功能价值**

   连续运动状态估计是否能够改善未来多模态轨迹预测，并在转弯、减速、停止和避让等场景中优于仅依赖普通隐藏状态的 DeMo 基线？

4. **可靠性条件化的趋势—状态融合**

   当运动证据可靠性随时间和部分观测程度变化时，如何自适应地调整宏观运动趋势与动态状态的提取、耦合和预测不确定性，避免固定融合导致过早收缩到单一未来？

### 核心假设

```text
部分观测历史
    -> 有效方向/动力学运动证据与行人交互上下文
    -> 运动证据可靠性
    -> 可靠连续运动状态及其不确定性
    -> 可靠性条件化的趋势—状态融合
    -> DeMo 多模态未来预测
```

核心假设为：

> **在历史部分观测条件下，利用观测可靠性形成连续运动状态估计，并将其分解为宏观运动趋势与动态状态，比普通隐藏状态、简单输入掩码或固定趋势—状态融合更能保留未来相关运动信息，从而改善多模态轨迹预测。**

该假设需要通过状态诊断、状态不确定性分析和真实未来预测共同验证。

## 七、拟形成的个人创新点

### 1. 部分观测运动证据的可靠性建模

针对历史轨迹部分观测后运动证据不完整、差分量不可靠的问题，显式建模观测掩码、有效观测间隔和历史有效比例，将它们统一为运动证据可靠性。该可靠性不只是输入特征，还用于调节运动证据编码、趋势—状态表示和预测不确定性。

这部分的基本逻辑是：

```text
真实观测 -> 可靠性加权编码
缺失时间步 -> 无效证据屏蔽与可靠性衰减
窗口结束 -> 形成带可信度的连续运动状态表示
```

它借鉴部分观测状态估计和缺失感知时序建模的思想，但研究对象转为行人轨迹中的方向、动力学和交互条件，不声称重新提出缺失数据处理的一般理论。

### 2. 可靠性条件化的 DeMo 趋势—状态建模

DeMo 已经提供 Mode/State 解耦骨架。本选题不重新提出该解耦，而是研究可靠性如何进入其内部：

- 有效时间步如何贡献真实方向和动力学证据；
- 缺失时间步如何避免注入伪证据；
- 观测间隔和可靠性如何影响趋势—状态表示；
- 宏观运动趋势与动态状态如何根据证据可靠性自适应耦合；
- 证据不足时如何保留合理的多模态不确定性。

拟形成的核心方法表述为**部分观测条件下的可靠性条件化 DeMo 趋势—状态表示与融合**。DeMo 的趋势—状态分解作为主体建模框架直接使用，本选题的研究重点是其在部分观测状态估计任务中的作用。

### 3. 连续运动状态的可验证性与预测价值

已有 DeMo 的查询向量不天然具有真实运动学含义。因此，本选题需要通过辅助运动学任务、完整/部分观测输入一致性和未来预测结果共同验证：

- 连续运动状态估计与完整历史运动证据的一致性；
- 方向、速度、加速度和转向趋势误差；
- 缺失程度增加时的不确定性变化；
- 转弯、减速、停止和避让场景中的未来预测误差；
- 连续运动状态估计相对于普通隐藏状态的独立收益。

只有当状态估计质量的改善能够传递到真实未来轨迹，并且收益不能由额外参数量或简单掩码输入解释，才能支持方法有效。

### 4. 研究包装与贡献边界

建议将论文整体包装为：

> **面向行人轨迹预测的 DeMo 趋势—状态建模 + 部分观测条件下的可靠连续运动状态估计。**

更凝练的方法叙事是：

> 本文面向行人轨迹预测，研究历史观测不完整时的连续运动状态估计问题。模型根据有限运动证据、观测可靠性和行人交互上下文，估计行人面向未来的潜在运动状态，并将其分解为宏观运动趋势与动态状态，最终生成多个未来运动演化假设。

其中各部分的归属应明确：

## 八、验证框架与实验方向

### 0. 已有基础实验线索

已有的 ETH/UCY 留出对照实验在相同数据协议和评测口径下比较了单向与双向 Mamba。8 帧观测、12 帧预测、`K = 20` 的实验结果显示：

| 结构 | 平均 minADE20 | 平均 minFDE20 |
| --- | ---: | ---: |
| DeMo 单向 Mamba | 0.232 | 0.389 |
| DeMo 双向 Mamba | 0.244 | 0.416 |

双向版本相对单向版本的平均误差更高，且在 ETH 场景退化最明显；这为当前优先采用 UniMamba 提供了经验依据，但不能推出单向 Mamba 在所有数据和实现条件下必然更优。该结果来自既有的 `K=20` 留出实验，最终研究配置若采用其他模态数量，必须重新报告并保持口径一致。详细记录见 [ETHUCY结果对照表](/home/lbh/DeMo/docs/results/ETHUCY结果对照表.md)。

该实验只能支持以下判断：

```text
UniMamba 是当前更合理的基础结构选择
    != UniMamba 本身构成研究创新
    != 双向 Mamba 在所有设置下都无效
```

此外，运行环境和 `mamba_ssm` 版本可能影响 `bimamba` 参数是否真正生效。正式实验必须确认实际使用的算子和方向性配置，不能只依据配置文件名称解释结果。

### 1. 前置验证链

| 阶段 | 验证问题 | 目的 |
| --- | --- | --- |
| P0 | DeMo 应用于行人轨迹预测领域后能否稳定完成标准轨迹预测 | 确认任务适配和基础模型可用 |
| P1 | 部分观测历史是否造成可测量的运动证据损失 | 判断状态估计问题是否具有分析价值 |
| P2 | 部分观测下能否通过可靠性建模形成与完整历史相符的连续运动状态估计 | 判断状态表示和可靠性估计是否合理 |
| P3 | 可靠性条件化的趋势—状态建模是否改善真实未来预测 | 判断拟议方法是否具有独立收益 |

P1 用于确认部分观测历史是否会造成可测量的运动证据损失，真正需要关注的是连续运动状态估计在未来预测上是否具有独立收益。

### 2. 缺失条件

实验统一使用“部分观测历史”描述输入条件。缺失程度和有效观测比例只用于构造不同难度的受控样本，不形成独立的缺失类型研究主线。

基础 benchmark 阶段使用完整历史，先验证 DeMo 在行人轨迹预测领域的应用能力；部分观测研究阶段再从完整历史构造部分观测输入，并保持未来轨迹监督目标完整。这样可以将任务适配误差与部分观测状态估计收益分开。

初始缺失实验宜先保证 focal 行人的观测窗口末帧有效，使局部坐标原点和朝向基准保持定义良好；如果允许末帧也缺失，则必须同时重新定义参考位置、参考朝向、预测起始时刻及其时间间隔，不能直接沿用完整观测设置。

### 3. 评价维度

| 维度 | 评价内容 |
| --- | --- |
| 标准预测 | ADE、FDE、minADE、minFDE |
| 状态估计质量 | 方向、速度、加速度、曲率和转向趋势误差 |
| 状态一致性 | 与完整历史运动证据或完整观测状态估计的差异 |
| 缺失鲁棒性 | 不同缺失程度下的性能曲线 |
| 行为场景 | 转弯、减速、停止、避让窗口误差 |
| 状态与预测不确定性 | 覆盖率、Energy Score、可靠性和过度自信 |

## 九、对照关系与判断标准

基础模型锁定为 DeMo 后，对照关系按研究问题分层：

1. 完整历史 DeMo；
2. 完整历史与 UniMamba 的 DeMo 行人预测应用模型；
3. 部分观测历史与基础输入处理的 DeMo；
4. 观测掩码直接输入的 DeMo；
5. 普通隐藏状态编码的 DeMo；
6. 时间间隔衰减与可靠性加权基线；
7. 显式方向—动力学运动证据表示；
8. 部分观测可靠性条件化的连续运动状态估计；
9. 部分观测可靠性条件化的趋势—状态融合；
10. 完整研究方法。

### Go 条件

- DeMo 应用于行人轨迹预测领域后能够稳定完成标准轨迹预测；
- 部分观测下能够形成具有合理运动学含义的连续运动状态估计，或合理表达其不确定性；
- 连续运动状态估计在相近参数量下优于普通隐藏状态；
- 状态估计质量改善能够传递到真实未来轨迹；
- 结果不只存在于单一缺失程度、单一行为场景或单一数据场景；
- 缺失程度增加时，模型能够保持合理的不确定性表达。

### No-Go 条件

- 普通隐藏状态或简单缺失处理已经解释全部收益；
- 状态估计内部指标改善但未来轨迹不改善；
- 收益完全来自额外参数量或额外输入信息；
- 结果只在单一缺失程度或单一场景成立；
- 模型需要完整历史或未来信息才能形成状态估计。

## 十、研究范围与待确定事项

本文档只保留研究问题、基础模型定位、概念边界、相关研究启示、创新假设、验证逻辑和判断标准。网络层修改、数据接口、缺失掩码生成、损失函数、训练配置和具体实验脚本另行设计。

当前仍需通过实验确定的事项包括：

- 可靠性采用固定衰减、可学习函数，还是二者的组合；
- 可靠性加权主要作用于运动证据编码、趋势—状态表示提取，还是二者同时作用；
- Mode/State 条件化主要作用于表示提取、Hybrid Coupling，还是同时作用于预测尺度和模态概率；
- 运动学辅助约束是否带来超出简单掩码输入的独立收益；
- 最终采用的模态数量、缺失难度和评测指标口径。

第二轮高缺失实验的正式条件、命名、掩码规则、审计要求和训练/零样本评估边界见[ETH/UCY 与 SDD 第二轮高缺失历史实验方案](ETHUCY与SDD第二轮高缺失历史实验方案.md)。v2 数据和实验管线已经落地，第二轮实验已于 2026-09-01 启动；实验结果尚未汇总，不应在当前选题阶段写成已验证结论。
