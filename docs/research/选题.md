# 缺失历史轨迹条件下行人未来运动的结构化多模态预测

_研究框架记录 · 更新时间：2026-09-02 · 研究领域：行人轨迹预测；基础建模框架：DeMo_

## 一、选题定位

行人轨迹预测通常以检测与跟踪系统输出的历史轨迹为输入。然而，遮挡、漏检、短时跟踪中断、帧丢失与定位误差会使历史轨迹出现缺失或时间断裂。完整、连续的固定长度历史轨迹因此并不是始终可得的前提。

本选题研究**缺失历史轨迹条件下的行人多模态轨迹预测**：给定不完整的历史观测、缺失位置及其时间结构，直接预测行人的完整未来轨迹分布。研究目标不是将缺失帧逐点恢复为唯一历史，而是从可见轨迹片段和观测缺失结构中构造可用于未来预测的历史上下文。

DeMo 为本研究提供结构化多模态预测的基础框架。其核心思想可表述为：未来轨迹分布同时包含两类结构，一类是不同候选未来之间的整体差异，另一类是单条候选轨迹沿时间轴的动态演化。DeMo 分别表示这两类结构，并通过联合表征参数化完整的未来轨迹分布[^1]。本研究将这一结构化预测思想引入缺失历史行人轨迹预测，使历史观测缺失不仅作为输入扰动，而是作为条件未来分布建模的一部分。

核心科学问题是：

> **在行人历史轨迹因观测中断而不完整的条件下，如何将可见轨迹片段与缺失结构转化为有效的预测条件，并对未来轨迹分布中的跨候选差异和轨迹内时序演化进行联合建模，从而生成多模态且时间连续的未来轨迹？**

研究定位分为五个层次：

| 层次 | 内容 | 在选题中的作用 |
| --- | --- | --- |
| 现实背景 | 遮挡、漏检、跟踪中断等导致历史轨迹缺失 | 给出问题来源和应用需求 |
| 预测任务 | 不完整历史观测条件下的行人未来轨迹预测 | 定义输入、输出与评测对象 |
| 历史建模 | 观测缺失感知的时序历史表征 | 从可见片段、缺失掩码和时间间隔中构造预测上下文 |
| 未来建模 | 跨候选差异与轨迹内时序演化的结构化条件建模 | 保持多模态性与时间连贯性 |
| 结果验证 | 完整未来轨迹上的准确性、覆盖性、连续性和缺失鲁棒性 | 判断方法是否解决任务问题 |

整体研究链为：

```text
检测/跟踪观测缺陷
    -> 缺失或时间断裂的历史轨迹 X^obs
    -> 观测掩码 M、时间间隔 Delta 与有效运动片段
    -> 缺失感知的历史运动上下文 H^miss
    -> 未来轨迹的跨候选差异表征 D_1:K
       + 轨迹内时序演化表征 S_1:T_f
    -> 结构化条件未来分布 p(Y_1:T_f | X^obs, M, Delta, C)
    -> 多模态行人未来轨迹预测
```

本选题的核心不是将某一种时序网络本身包装为创新，也不是把编码器隐式特征直接解释为真实“运动意图”或“物理状态”。整体编码器负责聚合缺失历史中的时序证据、观测结构和行人交互信息；DeMo 的 Mode/State 结构提供未来分布的结构化参数化；研究创新应落在**缺失历史任务建模、观测缺失感知的时空上下文表征，以及缺失条件如何进入结构化未来分布建模**。

## 二、问题定义与概念体系

### 1. 缺失历史轨迹预测任务

记完整历史轨迹为 `X_1:T_h`，未来轨迹为 `Y_1:T_f`，历史观测掩码为 `M_1:T_h`。其中，`M_t = 1` 表示第 `t` 个历史时刻具有有效观测，`M_t = 0` 表示该时刻的轨迹观测缺失。实际输入可记为：

> **公式：** `X^obs_t = M_t ⊙ X_t`

除位置观测外，模型还可以使用由观测过程导出的时间信息：

```text
M_t       : 当前时刻是否存在有效观测
Delta_t   : 距离最近一次有效观测的时间间隔
E_t       : 由足够有效观测计算得到的运动证据，例如位移或速度
C         : 行人交互上下文
```

任务目标是建模：

> **公式：** `p_theta(Y_1:T_f | X^obs_1:T_h, M_1:T_h, Delta_1:T_h, C)`

未来轨迹在训练和评测中保持完整，缺失只发生在输入历史窗口。轨迹插补可以作为对照方法或可选辅助，但不是本选题的主目标；主目标始终是**缺失历史条件下的未来预测质量**。

### 2. 缺失历史的现实含义与实验抽象

本选题中的“缺失历史轨迹”指历史窗口内部分时刻没有可用的行人位置观测，或观测序列在时间上不连续。它对应以下真实观测现象：

```text
遮挡或视野离开              -> 短时位置不可见
检测漏检或帧丢失            -> 离散时间步缺失
跟踪中断或重新关联          -> 连续历史片段断裂
定位质量下降                -> 后续可扩展为噪声与缺失共存
```

第一版以**历史帧缺失与连续断裂**为可控研究对象。随机缺失、连续缺失、不同缺失比例和不同缺口位置是构造任务难度与模拟观测中断的实验条件，而不是彼此割裂的研究主题。若后续加入坐标噪声、误检或身份切换，应将其作为扩展的观测退化模型，而不是提前并入当前结论。

### 3. 未来轨迹的结构化条件分布

普通多模态预测通常直接从历史上下文产生 `K` 条候选未来。结构化未来建模则进一步规定未来分布的组织方式：未来不是若干条彼此独立的完整轨迹，而是由“候选未来之间的差异”和“单条候选内部的时序演化”两类关系共同决定。前者负责区分不同的未来分支，后者负责组织每条轨迹随时间的变化。

这里的“结构化”指：

```text
不是一个隐藏向量直接对应一条完整轨迹；
而是先表示未来候选之间的差异结构，
再表示单条未来沿时间轴的演化结构，
最后对两类结构进行联合参数化。
```

记：

```text
D_k       : 第 k 个候选未来的跨候选差异表征
S_1:T_f   : 沿预测时间演化的轨迹内时序表征
Q_k,1:T_f : D_k 与 S_1:T_f 的联合未来表征
```

则可将未来轨迹分布理解为：

> **公式：** `p_theta(Y | H^miss, C) = sum_k pi_k p_theta(Y | Q_k,1:T_f, H^miss, C)`

其中：

> **公式：** `D_1:K = f_cross(H^miss, C)`

> **公式：** `S_1:T_f = f_time(H^miss, C)`

> **公式：** `Q_k,t = Phi(D_k, S_t, H^miss, C)`

因此，结构化未来建模可以写成：

```text
历史条件 H
    -> 跨候选差异表征 D_1:K
    -> 轨迹内时序演化表征 S_1:T_f
    -> 联合未来表征 Q_1:K,1:T_f
    -> 多模态未来轨迹分布
```

这是一种对未来轨迹分布的**分解表示与联合参数化**。它不要求 `D_k` 或 `S_t` 对应某个可以直接观测的心理或物理变量。DeMo 原文中的 `Mode Query` 可对应跨候选差异表征，`State Query` 可对应轨迹内时序演化表征，`Hybrid Coupling` 则对应二者的联合参数化[^1]。

### 4. 核心术语

| 术语 | 本选题中的含义 |
| --- | --- |
| 缺失历史轨迹 | 具有缺失时间步或时间断裂的行人历史观测序列 |
| 缺失结构 | 掩码、缺失位置、连续缺口长度、观测间隔等观测过程信息 |
| 缺失感知历史表征 | 同时编码可见轨迹片段及其缺失结构的预测上下文，不将缺失值当作真实运动值 |
| 跨候选差异表征 | 描述多个合理未来分支之间的差异结构，对应 DeMo 的 Mode 维度 |
| 轨迹内时序演化表征 | 描述单条未来轨迹沿时间轴的变化结构，对应 DeMo 的 State 维度 |
| 联合未来表征 | 将跨候选差异与轨迹内演化联合起来，参数化具体未来轨迹 |
| 多模态未来预测 | 对同一历史观测给出多个可能未来分支及其概率或尺度 |
| 时空上下文编码器 | 对带缺失结构的历史轨迹、有效运动关系和行人交互进行联合编码 |

## 三、问题背景与研究动机

### 1. 完整历史假设与真实观测条件之间存在差距

现有行人轨迹预测通常在完整、连续且等间隔的历史轨迹上训练和评测。该设定有利于模型从位置差分中获得速度、方向和转向趋势，但与检测跟踪系统的实际输出存在差距：一旦历史中出现缺口，部分运动变化不再可直接计算，最近观测状态与预测起点之间也可能发生时间脱节。

因此，缺失历史不是单纯少了若干坐标，而是改变了模型可使用的历史时序证据及其时间组织方式。

### 2. 缺失值不能被视为普通轨迹值

对缺失位置进行零填充、前向填充或直接插补后再输入普通预测器，容易混淆以下信息：

```text
真实静止                != 位置缺失后的零位移
低速或减速              != 长时间没有新观测
连续转向趋势            != 被缺口切断后的局部片段
最近状态可见            != 最近状态距离预测起点较远
```

因而，历史编码需要显式区分“观察到的运动几何”和“观察过程本身”，使模型能够根据缺失位置与时间间隔判断哪些历史关系可用、哪些关系不能被当作确定事实。

### 3. 缺失历史会放大未来分布建模难度

行人未来本身具有多模态性：继续前行、转向、减速、停走与避让等运动结果可以共享相似的局部历史。历史发生缺失后，多条未来之间的区分证据进一步减少，普通的一轨迹一查询式预测容易出现两类问题：

```text
多条候选轨迹趋同，无法覆盖合理未来分支；
单条候选轨迹缺少时间连贯性，速度或转向变化不稳定。
```

因此，需要同时解决两个问题：一是从不完整历史中建立有效条件上下文，二是用适合多模态未来的结构化方式表示未来分布。

### 4. DeMo 为缺失历史预测提供的结构化基础

DeMo 将多模态未来轨迹的跨分支差异与轨迹内时间演化分开表示，再通过联合表征形成具体轨迹[^1]。这一思想适合被重新放置到缺失历史任务中：当历史证据存在断裂时，模型不应只依赖单一隐藏向量直接输出未来，而应在缺失条件下分别保持候选未来的差异性和单条轨迹的时间组织。

本研究的主张不是重新定义 DeMo 的原始 Mode/State 创新，而是提出：

> **缺失历史行人预测需要观测过程条件化的历史表征，并需要将该条件上下文贯穿到结构化多模态未来分布的构造中。**

## 四、核心科研问题与研究假设

### 1. 总问题

> **如何在缺失历史轨迹条件下，将可见轨迹片段、缺失结构和行人交互上下文转化为有效的预测条件，并以跨候选差异与轨迹内时序演化相结合的结构化方式建模未来轨迹分布？**

### 2. 子问题

1. **缺失感知历史表征**

   如何使历史编码器同时识别可见运动片段、缺失位置和观测间隔，避免将缺失误认为静止、低速或确定性运动？

2. **缺失条件下的跨候选未来建模**

   当历史证据不完整时，如何维持候选未来之间的有效差异，使模型能够覆盖多个合理的行人未来分支？

3. **缺失条件下的轨迹内时序建模**

   如何根据不连续历史建立单条未来轨迹的时间演化表征，保持未来速度、方向和转向过程的合理连续性？

4. **缺失结构与联合未来分布的适配**

   缺失位置、连续缺口和观测间隔应如何作用于跨候选差异表征、时序演化表征及其联合建模，使未来分布与历史观测条件相匹配？

5. **任务层有效性**

   相比直接填补缺失值、只拼接掩码或直接复用完整历史预测器，缺失感知的结构化未来分布建模能否在 ETH/UCY 与 SDD 上稳定提高缺失历史条件下的多模态预测质量？

### 3. 可检验假设

| 假设 | 内容 | 需要的证据 |
| --- | --- | --- |
| H1 | 将缺失掩码、观测间隔和有效运动片段共同编码，比将缺失值作为普通坐标或只做零填充更能构造有效历史上下文 | 与零填充、前向填充、简单掩码输入的对照 |
| H2 | 缺失历史下，未来分布的跨候选差异与轨迹内时序演化需要分别建模，才能同时维持模态覆盖与轨迹连续性 | 与一体化预测头、未适配 DeMo 的对照 |
| H3 | 将缺失结构作为结构化未来分布的条件变量，能够减少候选轨迹塌缩并改善连续缺口场景中的预测 | 对比只在输入侧处理缺失与贯穿式条件化 |
| H4 | 方法收益不应局限于轻度随机缺失，而应在不同缺失比例、连续缺口和跨数据集条件下保持一致趋势 | ETH/UCY、SDD 与多种缺失协议的验证 |

## 五、研究内容与方法框架

### 1. 总体方法假设

本研究将历史观测过程和未来运动过程统一为一个条件预测问题：

```text
不完整历史观测
    + 缺失结构
    + 行人交互上下文
    -> 缺失感知历史运动上下文
    -> 跨候选未来差异表征
       + 轨迹内时序演化表征
    -> 联合未来表征
    -> 多模态未来轨迹分布
```

其中，前半部分解决“历史信息如何在缺失下被表示”，后半部分解决“未来分布如何在该条件下被组织”。两者缺一不可：仅做缺失编码但仍使用无结构的未来预测，难以充分利用多模态信息；只复用结构化解码而不处理缺失结构，也难以保证历史上下文有效。

### 2. 缺失感知的历史运动上下文

缺失感知时空上下文表征的目标是从不完整序列中形成对未来预测充分、且不混淆观测缺口与运动变化的上下文：

> **公式：** `H^miss = E_theta(X^obs_1:T_h, M_1:T_h, Delta_1:T_h, E_1:T_h, C)`

其中，`E_1:T_h` 表示仅由有效观测片段计算得到的运动证据。它可以包含位移、速度、航向变化或局部曲率等，但只有在所需观测点均有效时才具有明确含义。

该表征应具备四项性质：

```text
保留有效片段中的时间顺序和局部运动几何；
显式表示何处缺失、缺失持续多久以及最近有效观测距离预测起点多远；
不将填充值、无效差分或缺口本身误解释为真实运动状态；
为后续多分支未来预测提供与观测条件一致的上下文。
```

整体编码器在这里承担**不规则可用历史证据与场景交互关系的联合建模**角色。其输出的是观测过程条件化的时空上下文，而非可以被直接命名为“运动意图”“动态状态”或“运动模式”的可解释变量。

围绕该部分可形成三条可比较的方法路线：

| 路线 | 科学含义 | 要检验的问题 |
| --- | --- | --- |
| 掩码条件化编码 | 将观测可用性作为历史序列的一部分 | 仅知道“是否缺失”能否避免错误解释缺失值 |
| 时间间隔条件化编码 | 将非连续观测之间的时间距离纳入历史上下文 | 缺口长度是否影响可迁移的运动证据 |
| 有效运动片段编码 | 只对可由有效点计算的位移、速度等关系赋予运动学含义 | 显式区分有效运动关系能否提升长缺口预测 |

第一版模型不必同时堆叠三种复杂机制。研究推进应从掩码条件化基线出发，逐步验证时间间隔和有效运动片段是否提供独立收益。

### 3. 推荐的现成方法拼接

本选题第一版可以采用“缺失感知历史编码 + 缺失条件化查询 + 缺失条件化联合预测”的最小路线，不重新设计 DeMo 的 Mode/State 结构：

```text
缺失历史 X^obs
    + 掩码 M
    + 时间间隔 Delta
    -> 缺失观测感知的时空上下文表征 H^miss
    -> 缺失条件摘要 r_h
    -> 条件化 Mode Query / State Query
    -> 缺失条件化 Hybrid Coupling
    -> 模态概率、轨迹尺度与未来轨迹
```

第一步借鉴 GC-VRNN 对缺失模式和时间衰减的处理，以及 MS-TIP 对不完整轨迹的掩码感知建模。具体到当前模型，可以将每个历史时间步编码为：

> **公式：** `e_t = Embed(x^obs_t, m_t, Delta_t, e^valid_t)`

再由历史时序编码与场景交互编码共同聚合：

> **公式：** `H^miss = E_spatiotemporal(e_1:T_h, C)`

其中 `e^valid_t` 表示由足够有效观测计算出的位移、速度等运动关系是否可用。编码器可以由历史时序建模、观测缺失建模和行人交互建模共同构成；具体时序算子只是实现选择。BRITS 的双向递归插补可以作为插补式基线或辅助分支，但不作为当前编码器的定义。

第二步将缺失结构汇总为历史级条件：

> **公式：** `r_h = Pool(M_1:T_h, Delta_1:T_h, e^valid_1:T_h)`

最小实现是把 `r_h` 作为一个缺失条件 token 加入 DeMo 编码记忆，使原有 Mode Query 和 State Query 通过 Cross-Attention 读取该条件。若需要显式条件化，可进一步写为：

> **公式：** `q^mode_k = q^mode_k + W_m r_h`

> **公式：** `q^state_t = q^state_t + W_s r_h`

这一做法借鉴 MTR 的查询式多模态预测思想，但保留 DeMo 已有的跨候选差异和轨迹内时序演化结构，不叠加 MTR 的完整解码器。

第三步让缺失条件进入 Hybrid Coupling 和最终未来分布：

> **公式：** `q^hyb_{k,t} = Phi(q^mode_k, q^state_t, H^miss, C, r_h)`

最小门控形式为：

> **公式：** `g_h = sigmoid(MLP(r_h))`

> **公式：** `q^hyb_{k,t} = q^mode_k + g_h ⊙ q^state_t`

随后由 DeMo 预测头输出：

> **公式：** `(Y_hat_k, pi_k, Sigma_k) = G(q^hyb_{k,1:T_f}, r_h)`

因此，缺失带来的不确定性不是通过手工规定“缺失越多方差越大”来表达，而是通过缺失条件对候选未来概率、轨迹尺度和 Mode/State 联合表征的调制来体现。

第一版的推荐组合为：

| 研究环节 | 直接借鉴 | 在 DeMo 中的使用 |
| --- | --- | --- |
| 历史缺失建模 | GC-VRNN、MS-TIP | 掩码、时间间隔和有效运动关系参与时空上下文编码 |
| 多模态查询条件化 | MTR | 仅借鉴条件化查询思想，不替换 DeMo Query |
| 联合未来不确定性 | DeMo 自身的混合概率与尺度预测 | 让 `r_h` 参与 Hybrid Coupling 和预测头 |
| 插补式对照 | BRITS、MS-TIP | 作为对照或辅助分支，不作为第一版主干 |

这条路线对应的核心方法名称为：

> **缺失观测条件化的结构化多模态未来分布建模**

### 4. 结构化未来分布的具体参数化

在获得 `H^miss` 后，未来预测不是由一个整体隐藏向量直接映射为一条完整轨迹，而是先对未来分布中的两类关系进行分别表示，再对它们进行联合参数化：

```text
跨候选差异表征 D_1:K
    -> 描述不同合理未来分支之间的整体差异

轨迹内时序演化表征 S_1:T_f
    -> 描述单条未来沿预测时间轴的动态组织

联合未来表征 Q_k,1:T_f
    -> 将两类结构组合为第 k 条候选未来的条件分布参数
```

因此，“结构化”描述的是未来轨迹分布的组织方式，而不是编码器、注意力或 Mamba 等网络组件的简单串联。它要求模型显式区分：

```text
不同候选未来之间如何不同；
每条候选未来如何沿时间演化；
两类关系如何共同决定具体未来轨迹。
```

在方法层面：

> **公式：** `D_1:K = f_cross(H^miss, C, r_h)`

> **公式：** `S_1:T_f = f_time(H^miss, C, r_h)`

> **公式：** `Q_k,t = Phi(D_k, S_t, H^miss, C, r_h)`

> **公式：** `(Y_hat_k, pi_k, Sigma_k) = G(Q_k,1:T_f, r_h)`

其中，`D_k` 对应 DeMo 的 Mode Query，`S_t` 对应 State Query，`Phi` 对应 Hybrid Coupling。论文叙事中应优先使用“跨候选差异表征”“轨迹内时序演化表征”和“联合未来表征”；在介绍与 DeMo 的关系时再标注对应模块名称。

### 5. 缺失条件对结构化未来分布的适配

缺失结构不能只在历史输入端出现一次，然后在未来建模阶段被遗忘。它应作为未来分布的条件信息，至少在以下三个层面发挥作用：

| 层面 | 学术作用 | 对应方法问题 |
| --- | --- | --- |
| 历史上下文 | 区分可见运动片段与观测缺口，形成 `H^miss` | 缺失如何改变可用历史关系 |
| 跨候选差异表征 | 根据历史证据的完整程度构造多个合理未来分支 | 缺失下如何保持模态覆盖 |
| 时序演化与联合表征 | 使单轨迹演化和分支组合与观测间隔相适配 | 缺失下如何保持时间连续并避免错误收缩 |

可将缺失结构提炼为历史级条件描述 `R_h`：

> **公式：** `R_h = r(M_1:T_h, Delta_1:T_h, E_1:T_h)`

然后令其参与结构化未来表征：

> **公式：** `Q_k,t = Phi(D_k, S_t, H^miss, C, R_h)`

这一表述不预设具体网络操作。后续模型可通过条件化查询、上下文调制、自适应耦合或分布尺度建模等方式实现；实验的关键是检验 `R_h` 是否应当只影响历史编码，还是还应影响候选未来的构造与联合参数化。

### 6. 最小可行研究路线

第一版应形成一条可验证、可消融的主链，而不是同时引入插补器、生成模型和多个辅助任务：

```text
缺失历史轨迹 X^obs
    + 掩码 M / 时间间隔 Delta
    -> 缺失观测感知的时空上下文表征 H^miss
    -> 行人交互上下文 C
    -> DeMo 式跨候选差异表征 D_1:K
       + 轨迹内时序演化表征 S_1:T_f
    -> 缺失条件化的联合未来表征 Q_1:K,1:T_f
    -> 多模态未来轨迹预测
```

建议按以下顺序形成模型 idea：

1. 建立“缺失历史直接预测”基线，确认模型不会把缺失填充值当作真实轨迹。
2. 增加观测掩码和时间间隔，验证观测过程条件化历史表征的必要性。
3. 将缺失条件从历史编码扩展至 DeMo 的跨候选差异、时序演化或联合表征，寻找最小有效适配位置。
4. 仅在上述主线有效后，再考虑插补辅助、完整历史教师、显式运动学约束或更复杂不确定性建模。

### 7. DeMo 与本研究的关系

| DeMo 原始设计 | 本研究中的科学作用 | 本研究的新增问题 |
| --- | --- | --- |
| Mode Queries | 表示不同候选未来之间的结构差异 | 缺失历史下如何生成足够分散且合理的候选未来 |
| State Queries | 表示未来轨迹沿时间轴的演化结构 | 不连续历史如何支持时间连贯的未来演化 |
| Mode Localization | 从历史与上下文中定位候选未来差异 | 缺失结构应如何进入候选未来的条件构造 |
| State Consistency | 组织单条未来内部的时序关系 | 观测间隔是否需要调节未来演化的条件信息 |
| Hybrid Coupling | 联合参数化跨候选差异与时序演化 | 缺失条件应如何参与联合未来表征 |
| Attention + Mamba | 聚合交互关系与时序证据 | 如何编码不连续历史中的有效片段与缺口结构 |

DeMo 是结构化未来预测的基础骨架；本研究的核心工作是使该骨架能够面向缺失历史观测构造有效的条件未来分布。

> **针对缺失历史行人轨迹，如何将观测缺失结构显式引入历史上下文与结构化未来分布建模，使模型在不完整输入下同时保持候选未来的覆盖性和单条轨迹的时间连贯性？**

```text
    ->

```

## 七、论文叙事与拟形成贡献

### 1. 论文主叙事

本文面向遮挡、漏检和跟踪中断导致的行人历史轨迹缺失问题。不同于假设完整历史可用的传统预测方法，本文将历史观测缺失视为条件预测中的观测过程变量：模型从可见轨迹片段、缺失掩码和时间间隔中构造缺失感知历史上下文，并基于结构化多模态未来分布建模，分别表示候选未来之间的差异和单条未来轨迹内部的时序演化，最终生成与不完整历史观测相匹配的多模态行人未来轨迹。

### 2. 拟形成的贡献

1. **任务建模贡献**

   将行人轨迹预测从“完整历史到未来”的标准设定扩展为“缺失历史观测到未来”的条件预测问题，以掩码、观测间隔和有效轨迹片段共同描述历史输入。

2. **历史表征贡献**

   提出观测缺失感知的历史运动上下文建模思路，使模型区分真实轨迹变化与观测缺口，并在不连续历史下保留可用于未来预测的时序关系。

3. **结构化未来分布贡献**

   将缺失条件引入 DeMo 式跨候选差异表征、轨迹内时序演化表征及其联合参数化过程，使多模态未来生成与历史观测完整程度相适配。

4. **实证与诊断贡献**

   在 ETH/UCY 和 SDD 上构建受控缺失历史协议，系统比较直接预测、掩码感知、插补式处理和结构化未来分布建模，并分析不同缺失类型下的准确性、覆盖性、时间连续性和泛化能力。

### 3. 题目与方法名称

当前推荐题目：

> **缺失历史轨迹条件下行人未来运动的结构化多模态预测**

可选的更方法化表述：

> **基于观测缺失感知历史表征与结构化未来分布建模的行人轨迹预测**

推荐的方法总称：

> **观测过程条件化的结构化多模态轨迹预测**

## 八、验证框架与实验推进

### 1. 已有基础

已有 ETH/UCY 留出实验在相同数据协议和评测口径下比较了单向与双向 Mamba。8 帧观测、12 帧预测、`K = 20` 的结果如下：

| 结构 | 平均 minADE20 | 平均 minFDE20 |
| --- | ---: | ---: |
| DeMo 单向 Mamba | 0.232 | 0.389 |
| DeMo 双向 Mamba | 0.244 | 0.416 |

当前结果支持采用单向历史时序建模作为缺失历史研究的优先基础配置。具体时序算子不构成论文的独立创新，而是作为整体时空上下文编码器的一部分。详细记录见 [ETHUCY结果对照表](/home/lbh/DeMo/docs/results/ETHUCY结果对照表.md)。

### 2. 实验任务协议

实验以完整未来轨迹为监督目标，在历史窗口中构造不同形式的缺失观测：

```text
完整历史            -> 检验基础行人多模态预测能力
轻度随机缺失        -> 检验方法对离散漏检的适应性
高比例随机缺失      -> 检验有限可见片段下的条件预测能力
连续缺失            -> 模拟遮挡、跟踪中断和时间断裂
不同缺口位置        -> 区分早期历史丢失与接近预测起点的历史丢失
```

初始实验可以保持历史窗口末帧有效，以保证局部坐标锚点与预测起点定义稳定。若扩展到末帧缺失，应将“最后一次有效观测到预测起点的时间间隔”作为任务变量，并重新定义参考位置、参考朝向与预测起始条件。

ETH/UCY 与 SDD 用于检验方法在不同场景、坐标尺度与行人运动模式下的稳定性。无地图设置不作为论文主叙事，只作为当前行人轨迹输入条件。

| 维度 | 评价内容 |
| --- | --- |
| 预测准确性 | ADE、FDE、minADE、minFDE、Miss Rate |
| 缺失鲁棒性 | 不同缺失比例、连续长度、缺口位置下的性能曲线 |
| 多模态覆盖 | 最优候选命中、终点/方向多样性、合理未来分支覆盖 |
| 时间连续性 | 速度、加速度、曲率、转向变化的合理性与稳定性 |
| 概率与不确定性 | 模态概率、尺度、覆盖率、Energy Score 或校准指标 |
| 跨场景泛化 | ETH/UCY 不同场景与 SDD 上的趋势一致性 |
| 定性案例 | 转弯、减速、停走、避让、长连续遮挡后的未来预测 |

内部表示诊断可以辅助解释模型行为，但不应替代未来轨迹上的任务评价。论文结论应以缺失历史条件下的未来预测、覆盖性和连续性证据为主。

### 6. Go / No-Go 判断标准

**Go 条件**

- 缺失感知历史表征相对于零填充、简单掩码或未适配编码带来稳定收益；
- 缺失条件进入结构化未来分布后，除误差外还能改善模态覆盖或时间连续性中的至少一项；
- 收益在连续缺失或较高缺失条件下仍可观察到，而非只存在于轻度随机缺失；
- 主结果能够在 ETH/UCY 和 SDD 的至少部分核心场景中复现一致趋势；
- 完整历史性能不发生不可接受的退化。

**No-Go 信号**

- 简单填充或单纯拼接掩码已解释全部收益；
- 缺失感知历史编码无效，而复杂未来结构只增加参数量；
- 方法仅改善内部表征诊断，不改善真实未来预测、覆盖性或连续性；
- 收益只出现于单一轻度缺失协议或单一数据场景；
- 未适配 DeMo 在所有缺失条件下已达到相同效果。

若出现 No-Go 信号，应据证据收缩论文主张：可能转向“缺失历史下 DeMo 的系统性评估与失败边界”，或重新定位新增方法的有效作用位置。

## 九、研究范围与待确定事项

### 1. 当前范围

```text
任务对象      : 行人历史轨迹缺失条件下的多模态未来预测
研究数据      : ETH/UCY、SDD
基础框架      : DeMo 的结构化多模态未来建模
历史编码      : 缺失观测感知的行人时空上下文编码器
核心新增方向  : 缺失感知历史表征 + 缺失条件化结构化未来分布
主要评价      : 预测准确性、模态覆盖、时间连续性、缺失鲁棒性
```

### 2. 暂不作为第一版主线的内容

```text
完整轨迹插补作为最终目标
直接解释隐藏向量为真实心理意图或物理状态
地图信息建模
定位噪声、误检、身份切换的联合退化建模
同时复现多个完整外部模型
```

这些方向可作为对照、扩展或后续工作，但不应稀释当前“缺失历史条件下的结构化多模态行人轨迹预测”主线。

### 3. 后续需要通过实验确定的事项

- 缺失条件最有效的表示是掩码、时间间隔、有效运动片段，还是三者的组合；
- 缺失条件应只影响历史编码，还是还应作用于 Mode/State Query 与 Hybrid Coupling；
- 是否需要显式插补分支、完整历史教师或运动学辅助约束；
- 不同缺失类型的训练测试分布应如何组织，才能同时反映适应性与泛化性；
- 最终采用的模态数量、缺失难度、概率评价指标和统计检验口径。

第二轮高缺失实验的正式条件、命名、掩码规则、审计要求和训练/零样本评估边界见[ETH/UCY 与 SDD 第二轮高缺失历史实验方案](ETHUCY与SDD第二轮高缺失历史实验方案.md)。该文档应随 P1--P5 的结果更新研究假设、模型路线和论文结论边界，而不是将尚未验证的机制写成既定结论。
