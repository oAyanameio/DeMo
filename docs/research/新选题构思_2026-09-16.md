# 缺失历史轨迹预测选题：推倒重来方案

**生成时间**：2026-09-16  
**背景**：当前"缺失历史直接预测"主线连续判负（B1 +2.4%、M1' +4.0%），需要评估是否继续投入，或转向全新方向。

---

## 第一部分：当前选题的致命问题（诚实诊断）

### 1.1 撞车风险 —— 已被占领的赛道

**TrajImpute (NeurIPS 2024)** 已经系统性占据"缺失历史直接预测"方向：
- 定义了官方协议（Easy/Hard）
- 提供了6个插补基线的direct对比
- MoFlow本身就支持direct预测（你的M0基线）
- **核心结论**：direct预测在Hard场景下显著优于插补（0.265 vs 1.448 FDE）

**2025-2026后续工作蜂拥而至**：
- **ARP-STGCN** (Springer 2025)：Gated Convolution Imputation + 吸引排斥势场
- **RMP-YOLO** (arXiv 2024)：场景token化 + recovery模块重建缺失历史
- **TSD** (arXiv 2025)：Target-driven自蒸馏 + 完整/部分观测双分支
- **CVPR 2025论文**：Adapting to Observation Length via Contrastive Learning

**判定**：这条赛道的"first-mover advantage"已被TrajImpute拿走，你现在进入是**追赶者**，而非**开创者**。

### 1.2 方法创新性不足 —— 工程改进 vs 科学贡献

当前"证据中心"框架的四层改进：
- ① 掩码拼输入 → **M0已有，非创新**
- ② 证据时钟（forecast_gap调制时间嵌入）→ **已判负+3.97%**，且概念上类似时间位置编码
- ③ 证据校准（模态熵正则）→ 常规正则化技巧
- ④ 社会证据补偿（邻居观测注意力）→ 与Scene Transformer的交叉注意力**概念重复**

**核心问题**：这些都是**工程性调参**（add feature、add loss term），不是**范式创新**（new problem formulation、new model family）。

顶会论文需要的是：
- 定义新问题 / 发现新现象 / 提出新范式 / 打破旧瓶颈
- 而不是："我在已有模型上加了4个开关，平均提升2%"

### 1.3 实验信号 —— 连续判负说明什么？

- B1运动特征：+2.40% 恶化（宏平均）
- M1'证据时钟：+3.97% 恶化
- v3特征工程全线：+7.8%/+3.0% 恶化

**可能的根因**：
1. **任务本身的天花板**：TrajImpute已经证明direct预测在Hard场景优于插补，你的改进空间本质上只剩下"微调DeMo架构"
2. **过拟合到ETH/UCY小数据集**：5场景LOO，每个测试集只有几百样本，统计不稳定
3. **DeMo本身的结构局限**：Mode/State解耦可能不适合缺失历史（缺失改变的是历史编码，不是未来解耦结构）

### 1.4 数据集困境 —— ETH/UCY的致命局限

- **样本量**：5个场景，总共~1500个行人轨迹（训练集）
- **多样性**：都是鸟瞰视角、低密度人群、无复杂交互
- **泛化性**：ETH/UCY SOTA已经卷到0.20 ADE（MoFlow 0.202），再降0.01都困难

**对比**：
- Waymo Open Motion：103k场景，570万条轨迹
- nuScenes：1000场景，140万个标注
- Argoverse 2：250k场景

**结论**：在ETH/UCY上做"微调DeMo"的故事，**很难撑起顶会论文的体量和泛化性论证**。

## 方向1：物理可行性引导的Flow Matching轨迹预测

### 核心创新

**问题**：Flow matching生成的轨迹多样性高，但物理可行性差（穿墙、超速、急转弯）。现有flow模型只优化数据拟合，不显式建模物理约束。

**方法**：**Physical-Guided Flow Matching (PGFM)**
1. **推理时梯度引导**：在ODE积分步骤中注入物理代价梯度（借鉴ARFlow，但用于行人场景）
   - 碰撞代价：基于场景SDF（Signed Distance Field）的穿透惩罚
   - 动力学代价：速度/加速度上下界、转向率约束
   - 社会力代价：舒适距离、相对速度场
2. **训练时物理正则**：设计Physics-Informed Loss，让flow场天然尊重约束
3. **可行性-准确性帕累托前沿**：不是单一指标，而是trade-off曲线

**与现有工作的差异**：
- **ARFlow** (arXiv 2503)：人体反应生成，body penetration约束
- **TIGFlow-GRPO** (arXiv 2603)：后训练+强化学习对齐，计算成本高
- **本方向**：推理时zero-shot物理引导，无需重训练，通用于任何flow-based模型

**技术路线**：
1. 为ETH/UCY场景构建SDF（墙壁、障碍物边界）
2. 定义行人物理约束：
   - 速度：0.5-2.0 m/s（步行）
   - 加速度：±1.5 m/s²
   - 转向率：±60°/s
3. 在DeMo的TimeDecoder ODE采样中插入梯度引导步骤
4. 新评测指标：Collision Rate、Physics Violation Rate、Pareto Efficiency

**实验设计**：
- 基线：DeMo原始flow、MoFlow、LED
- 消融：不同约束组合、引导强度λ扫描
- 泛化：ETH/UCY → SDD跨场景测试

**预期成果**：
- 碰撞率降低60-80%（参考EgoFlow在6DoF任务的79%降低）
- ADE/FDE略微trade-off（±2%可接受）
- **卖点**：**首个将推理时物理引导应用于行人flow matching的工作**

**时间估算**：
- SDF构建：1周
- 梯度引导实现：2周
- 主实验：4周
- 写作：3周
- **总计：10周**

**风险**：
- 🟡 中等：物理约束定义需要领域知识（可参考Social Force Model文献）
- 🟢 低：技术路线清晰（ARFlow已验证可行性）

## 方向2：测试时在线适应的轨迹预测（Test-Time Adaptation）

### 核心创新

**问题**：轨迹预测模型在训练场景表现好，但部署到新场景（不同摄像机视角、人群密度、行为模式）时性能大幅下降。现有方法需要重新训练，无法实时适应。

**观察**：
- 2025年TTA（Test-Time Adaptation）在CV各领域爆发（NeurIPS 2025收录10+篇）
- **但轨迹预测方向几乎空白**（web search只找到1篇VLN相关工作）

**方法**：**AdapTraj: Online Test-Time Adaptation for Trajectory Prediction**
1. **场景特征提取器**：从测试batch中提取环境特征（人群密度、平均速度、交互强度）
2. **自监督适应目标**：
   - 时序一致性：前后帧预测的轨迹连续性
   - 社会合理性：预测轨迹间的互信息（避免碰撞）
   - 模态一致性：K个候选的熵稳定性
3. **参数高效更新**：只更新Adapter层（1%参数），主干冻结
4. **持续学习策略**：记忆重放防止灾难性遗忘

**与现有工作的差异**：
- **TTA综述** (arXiv 2609)：覆盖分类、分割、检测，**未涉及轨迹预测**
- **CUQDS** (AAAI 2025)：轨迹预测的不确定性量化，但用conformal prediction，不是TTA
- **本方向**：**首个将TTA引入多模态轨迹预测的工作**

**技术路线**：
1. 在DeMo的Scene Context Transformer后插入Adapter模块（LoRA风格）
2. 定义测试时loss：
   ```
   L_tta = λ1·L_temporal_smooth + λ2·L_social_mutual + λ3·L_modal_entropy
   ```
3. 每个测试batch做1-5步梯度更新后再预测
4. 跨场景实验：ETH→UCY，ETH→SDD（domain shift）

**实验设计**：
- **Domain Shift设置**：
  - 训练：ETH
  - 测试：HOTEL（低密度）、ZARA（高密度）、SDD（鸟瞰→俯视）
- **对比方法**：
  - Source-only（无适应）
  - Fine-tune（需标注）
  - AdapTraj（无标注在线适应）
- **消融**：不同自监督目标、更新步数、Adapter位置

**预期成果**：
- 跨场景ADE降低15-25%（参考TTA在分类任务的典型提升）
- 推理延迟增加<20%（Adapter参数少）
- **卖点**：**首次证明TTA在轨迹预测的有效性，开辟新子方向**

**时间估算**：
- Adapter设计：1周
- 自监督loss实现：2周
- 跨场景实验：5周
- 写作：3周
- **总计：11周**

**风险**：
- 🟡 中等：自监督信号的设计需要多轮调试
- 🟢 低：TTA范式已在其他任务验证，移植风险小

## 方向3：安全关键场景的Conformal Prediction不确定性量化

### 核心创新

**问题**：自动驾驶等安全关键场景需要**可靠的不确定性估计**，而不仅仅是准确的轨迹预测。现有flow matching模型只输出K个样本，无法提供**统计保证的置信区域**。

**方法**：**ConformalFlow: Conformal Prediction for Flow-Based Trajectory Forecasting**
1. **非参数校准**：用calibration set构造nonconformity score分布
2. **时序分解**：逐时间步构造prediction interval（而非整条轨迹）
3. **场景条件化**：不同场景（直行、转弯、交互）的校准分布不同
4. **风险感知决策**：将不确定性传递给下游规划模块

**与现有工作的差异**：
- **CUQDS** (AAAI 2025)：GP回归+conformal P control，用于分布漂移，**未结合flow matching**
- **Scenario-aware UQ** (arXiv 2512)：场景感知不确定性，但用于nuPlan自动驾驶，**未开源、未用flow matching**
- **本方向**：**首个将conformal prediction与flow matching结合用于行人轨迹**

**技术路线**：
1. 在DeMo训练后，冻结模型
2. 用calibration set（20%的训练数据）计算nonconformity score：
   ```
   R_i,t = ||Y_pred_i,t - Y_true_i,t||
   ```
3. 为每个时间步t和场景类型s构造校准分布
4. 推理时：给定置信水平α（如95%），输出prediction band

**实验设计**：
- **核心指标**：
  - Coverage：真实轨迹落在预测区间内的比例（应≥1-α）
  - Efficiency：预测区间的平均宽度（越窄越好）
  - Calibration：不同场景下的coverage一致性
- **对比方法**：
  - Naive ensemble（K个样本的min-max包络）
  - MC Dropout
  - Deep ensemble
  - ConformalFlow（本文）
- **下游应用**：将不确定性接入collision avoidance规划器

**预期成果**：
- 提供统计保证的95% coverage（现有方法可能只有60-70%）
- 预测区间宽度减少30%（相比naive方法）
- **卖点**：**为safety-critical轨迹预测提供formal guarantee**

**时间估算**：
- Conformal框架实现：2周
- 场景分类器：1周
- 主实验：4周
- 下游集成：2周
- 写作：3周
- **总计：12周**

**风险**：
- 🟢 低：Conformal prediction理论成熟，工程实现直接
- 🟡 中等：需要carefully设计场景分类（否则coverage不稳定）

## 方向4：跨数据集泛化的多粒度时空表征学习

### 核心创新

**问题**：在ETH/UCY训练的模型迁移到SDD、Waymo时ADE飙升100-200%。现有模型严重过拟合到训练场景的视角、密度、尺度。

**方法**：**Multi-Granularity Spatiotemporal Learning (MGSL)**
1. **多尺度历史编码**：同时建模细粒度运动（0.4s步长）和粗粒度趋势（1.6s步长）
2. **场景无关表征**：对抗训练消除场景特定的虚假相关（如摄像机视角偏差）
3. **自监督预训练**：在多数据集联合预训练，学习通用时空特征
4. **Zero-shot迁移评测**：训练于A，直接测试于B

**与现有工作的差异**：
- 现有工作都是**单数据集内评测**（ETH/UCY 5-fold，或SDD内部split）
- **本方向**：系统性研究**跨数据集泛化**，这在轨迹预测领域几乎空白

**技术路线**：
1. 构建统一数据接口：ETH/UCY、SDD、nuScenes轨迹子集
2. 多粒度编码器：
   ```
   H_fine = Encoder(X[::1])      # 0.4s
   H_coarse = Encoder(X[::4])    # 1.6s
   H = Fusion(H_fine, H_coarse)
   ```
3. 场景判别器D：从H预测数据集来源
4. 对抗loss：max_θ min_φ L_pred - λ·L_disc

**实验设计**：
- **泛化协议**：
  - ETH → UCY
  - ETH+UCY → SDD
  - SDD → ETH+UCY
  - 联合训练 → 各自测试
- **核心指标**：泛化gap（目标域性能 vs 源域性能的差距）
- **对比**：
  - 无域适应（直接迁移）
  - Domain Randomization
  - Meta-learning
  - MGSL（本文）

**预期成果**：
- 泛化gap缩小40-60%
- 联合训练在所有数据集上达到接近单独训练的性能（unified model）
- **卖点**：**首个系统性研究轨迹预测跨数据集泛化的工作**

**时间估算**：
- 数据统一接口：2周
- 多粒度编码器：2周
- 对抗训练：2周
- 跨数据集实验（5个迁移对）：6周
- 写作：3周
- **总计：15周**

**风险**：
- 🟡 中等：需要准备3个数据集（SDD未在仓库内）
- 🟡 中等：对抗训练可能不稳定

## 方向5：Flow Matching的模态覆盖诊断与修正

### 核心创新

**问题**：Flow matching模型声称生成多样化轨迹，但实际存在**mode collapse隐患**——K个样本可能聚集在少数几个模态，遗漏真实分布的其他模式。现有评测只看minADE/FDE，无法检测mode coverage问题。

**观察**：
- Diffusion和Flow Matching在图像生成中已知存在mode dropping
- **轨迹预测领域缺乏mode coverage的定量诊断工具**

**方法**：**ModeProbe: Diagnostic and Correction Framework for Mode Coverage**
1. **Mode Discovery**：从ground truth中聚类得到真实模态（基于终点+路径曲率）
2. **Coverage Metric**：计算模型生成K个样本覆盖真实模态的比例
3. **Diversity-Accuracy Tradeoff曲线**：绘制帕累托前沿（类似precision-recall）
4. **Mode-Balanced Training**：针对性采样被遗漏的模态，重训练

**与现有工作的差异**：
- **MoFlow论文**：提到diversity，但只用了MASD（平均距离），未诊断mode coverage
- **GAN评测文献**：有mode coverage metric（如FID、IS），但**未用于flow-based轨迹预测**
- **本方向**：**首次系统性诊断flow matching在轨迹预测的mode coverage**

**技术路线**：
1. 在ETH/UCY测试集上，对每个历史输入聚类GT未来（K-means，K=3-5）
2. 对DeMo/MoFlow/LED生成的K=20样本，计算：
   - **Recall**: 被覆盖的真实模态比例
   - **Precision**: 生成的有效模态（非冗余）比例
   - **F1-score**: 调和平均
3. 发现哪些场景/交互类型存在严重mode dropping
4. 设计mode-balanced loss：
   ```
   L = L_base + λ·L_modal_reweight
   ```

**实验设计**：
- **诊断阶段**：分析5个模型在ETH/UCY上的mode coverage
- **修正阶段**：用mode-balanced loss重训练DeMo
- **对比指标**：
  - 传统：minADE/FDE（可能略下降）
  - 新指标：Mode Recall、Mode F1（应大幅提升）

**预期成果**：
- 揭示现有SOTA模型在30-40%的测试case上存在mode dropping
- Mode-balanced训练使Recall从60%提升到85%
- **卖点**：**首次暴露并解决flow-based轨迹预测的mode collapse问题**

**时间估算**：
- Mode discovery实现：2周
- Coverage metric：1周
- 诊断实验：3周
- Mode-balanced训练：4周
- 写作：3周
- **总计：13周**

**风险**：
- 🟡 中等：Mode定义需要领域验证（是用终点、路径形状还是速度profile？）
- 🟢 低：纯诊断部分风险很低，即使修正失败也能发paper（diagnostic contribution足够）
