# 缺失历史预测实验方案

_实验方案记录 · 更新时间：2026-10-08 · 适用任务：TrajGap-Bench Mixed-direct · 基础模型：DeMo actor-only_

> **文档性质**：本文件是后续实验的实施方案，不代表其中任何候选已经验证有效。正式结果统一写入《实验总汇总》，并遵守该文件中的结果归档与主协议约束。

> **当前状态**：M0 是唯一滚动基线。后续实验按 M1 → M2 → M3 → M4 的顺序单变量推进；每一阶段只有在前一阶段通过门禁后才启动。

## 1. 目标与边界

### 1.1 实验目标

本轮不再改造历史 Mamba 的内部状态转移，也不重复已经判负的历史状态读取和共享编码器重复注入。实验重点转移到 3 个尚未充分验证的层面：

1. **训练缺失分布**：训练时主动增加合理的历史观测缺失，检验模型是否能从更宽的缺失分布中学习鲁棒性。
2. **历史运动证据表示**：使用训练期的 masked-motion reconstruction 辅助任务，要求历史编码器保留局部运动证据，但不将重建结果送入未来预测路径。
3. **未来分布可靠性**：根据缺失证据条件化最终 mode 概率和轨迹尺度，直接针对高缺失样本的 mode 排序与不确定性表达。

M4 的关系级动态交互模块属于后续可选路线，只有 M1–M3 中至少一项形成稳定收益后才启动。

### 1.2 明确不做的事项

本方案不包含以下改动：

- 不修改历史 Mamba 的 selective state transition、kernel 或 `dt` 计算；
- 不使用“最后有效 hidden state”替换现有 readout；该路线已有历史 screening 判负记录；
- 不把 `mask`、`gap`、`valid rate` 或 evidence summary 再次简单拼接到 actor token 或 Mode Query；
- 不在推理阶段先生成一条确定性历史插补轨迹，再把插补结果送入预测器；
- 不一次性替换全部历史 Mamba 或全部 Scene Transformer；
- 不改变未来监督、K=20、损失评估口径和 TrajGap-Bench Mixed-direct 协议；
- 不把单个高缺失子组的改善写成整体方法有效。

## 4. 实验顺序总览

| 阶段 | 模型标签 | 主要改动 | 训练期 | 推理期 | 进入条件 |
|---|---|---|---|---|---|
| 基线 | M0 | 当前 DeMo，不增加新模块 | 无额外任务 | 原路径 | 已有正式基线 |
| 1 | M1 | Stochastic Waypoint Dropping | 额外随机删去原本有效帧 | 不删点 | M0 配对复验完成 |
| 2 | M2 | M1 + masked-motion reconstruction | 增加历史运动重建损失 | 删除重建头或忽略其输出 | M1 通过缺失鲁棒性门禁 |
| 3 | M3 | M2 + missingness-aware output calibration | 用现有预测损失训练校准头 | 校准最终概率和尺度 | M2 不损害主指标与完整组 |

每个阶段先做单场景 smoke，再做 5 场景 Mixed 确认；不要在单场景阶段同时改变多个超参数。

## 5. M1：Stochastic Waypoint Dropping

### 5.1 假设

当前训练数据的缺失模式可能不足以覆盖测试中的长连续缺口、末端缺失和低 `valid_count`。若仅在训练时从原本有效的历史中随机删除 waypoint，模型可能提高对缺失模式变化的鲁棒性。

M1 的增量是**训练分布增强**，不是新编码器模块。

### 5.2 具体数据处理

在 `src/datamodule/trajimpute_dataset.py` 的训练样本构造路径中增加人工删点步骤：

1. 读取官方 `obs_traj`、`missing_mask` 和未来 `pred_traj`。
2. 计算原始历史有效帧：`frame_valid = ~missing_mask.any(-1)`。
3. 只从原本有效的历史帧中采样人工删除位置；官方原本缺失的位置不能作为人工删除目标。
4. 得到输入有效性：

   ```text
   valid_aug = frame_valid & ~drop_mask
   ```

5. 通过 `valid_aug` 重新执行现有的 gap-aware 样本构造，而不是只把输入坐标置零。至少重新计算：

   - `x_positions_diff`；
   - `x_velocity`、`x_velocity_diff`；
   - `x_valid_mask`、`x_key_valid_mask`；
   - `x_gap_steps`；
   - `x_centers`；
   - `x_last_valid_angle`；
   - `x_last_valid_idx`、`x_anchor_lag_steps`、`x_forecast_gap_steps`；
   - `target_diff` 的起点相关字段。

   坐标系重建顺序必须固定：先在世界坐标的原始有效性上采样 `drop_mask`，再用 `valid_aug` 重新确定 focal 的最后有效历史位置和朝向，最后用这个**只由增强后历史决定**的刚体变换同时转换历史与未来。人工删掉的历史坐标在模型输入视图中必须变为不可见（例如置为 `NaN` 后按现有规则变成 0 占位），不能把已知坐标留在任何输入字段中。不得用未来轨迹参与删点采样、坐标系确定或派生字段计算。

6. 原始世界坐标中的 `pred_traj` 和 `target_mask` 不做任何修改；`target`、`target_diff` 等局部坐标字段允许因增强后历史锚点/朝向变化而重新计算，但只能由未修改的未来坐标和历史-only 坐标变换得到。测试必须同时核对：原始未来标签逐位不变，局部 target 的变化仅来自坐标系/起点重算。
7. 若某个 actor 人工删除后没有有效历史帧，则拒绝该次采样并重新采样；不得静默制造全缺失 actor。
8. 训练集才启用人工删点；验证集、测试集和 zero-missing 诊断保持原始输入。
9. 当前 `TrajImputeDataset` 对样本有跨 epoch 缓存；启用随机删点后不能缓存已经增强的样本。实现时应缓存未增强的基础样本，再对每次训练访问生成增强副本，或在增强模式下关闭 `_sample_cache`。

### 5.3 首轮参数

建议先只运行以下两个设置：

```yaml
waypoint_drop:
  enabled: true
  probability: 0.10
  train_only: true
  preserve_at_least_one_valid_frame: true
  seed: 2024
```

若 `p=0.10` 通过初筛，再运行 `p=0.20`。首轮不测试 `p>0.20`，避免训练分布脱离 TrajGap-Bench 的实际缺失范围。

建议新增配置字段，而不是在脚本中硬编码：

- `waypoint_drop_enabled`；
- `waypoint_drop_probability`；
- `waypoint_drop_seed`；
- `waypoint_drop_train_only`。

| 文件 | 实施措施 |

### 5.5 M1 门禁

M1 只有同时满足以下条件，才进入 M2：

- `E2/E3` 或低 `valid_count` 子组在至少 2 个主指标上改善；
- all-valid / `E0` 子组相对 M0 不出现系统性退化；
- Mixed-test 总体 `minFDE20`、`MR` 不比配对 M0 差超过 1%；
- 不能只改善 `minADE20`，而 `ADE@1`、`MR` 或 `b-minFDE20` 明显恶化；
- 三个随机种子中至少两个保持相同方向；
- 人工删点不会改变未来标签、场景 actor 顺序和评测样本数量。

若 M1 只在人工增强训练分布上改善，而原始 Mixed-test 不改善，则判定为训练增强没有形成有效泛化，不进入 M2。

## 6. M2：Masked-Motion Reconstruction

### 6.1 假设

M1 只能改变训练分布，不能直接约束历史 Mamba 的隐状态保留局部运动证据。M2 在 M1 的输入增强基础上，增加训练期 masked-motion reconstruction：对原本有效的历史帧再次人工遮挡，并要求历史编码器恢复这些帧的运动特征。

该分支是**训练辅助任务**，不是推理插补模块。

### 6.2 主路径与辅助路径

历史 Mamba 输出记为：

```text
H = [h_1, ..., h_8], H ∈ R^(B×N×L×D)
```

主路径保持不变：

```text
H → 末端历史表征 → Scene Context → DeMo Future Decoder
```

新增辅助路径：

```text
H → Reconstruction Head → [Δx, Δy, speed]
```

第一版只重建 3 维 gap-aware 运动特征：

```text
recon_target = [x_positions_diff[..., 0],
                x_positions_diff[..., 1],
                x_velocity[..., None]]
```

建议首轮使用 `[Δx, Δy, speed]`，不要重建 absolute position。这里的 `speed` 对应现有 `x_velocity`，不是 `x_velocity_diff`；局部坐标原点和 forecast gap 会使绝对位置目标混入额外因素。

### 6.3 重建 mask 与监督规则

M2 必须保存 M1 人工删点前的有效历史信息，并复用同一张 `drop_mask` 作为第一版重建监督 mask。为避免坐标系错配，不能直接复用“删点前样本”在其原始坐标系中计算的 `x_positions_diff`：

1. 先按 M1 规则得到 `drop_mask` 和 `valid_aug`；
2. 用 `valid_aug` 确定增强样本的 focal 原点与朝向；
3. 将人工删点前仍已知的历史坐标转换到该增强样本坐标系；
4. 在这个统一坐标系中、使用删点前的 `frame_valid` 计算 gap-aware 运动特征；
5. 只取 `drop_mask` 覆盖的位置作为 `recon_target`，并将 `drop_mask` 与 actor/frame 有效性相与得到 `recon_mask`。

这样重建目标可以使用“人工删掉但原本已知”的历史值，却不会读取未来，也不会把删点前坐标系中的标签错误地监督给增强后的输入。

```text
recon_target: [B, N, L, 3]
recon_mask:   [B, N, L]
```

监督规则：

1. 只监督“原本有效、这次被 M1 人工删掉”的历史帧；`recon_mask` 必须满足 `drop_mask & frame_valid & x_key_valid_mask[..., None]`；
2. 官方原本缺失的帧不参与重建损失；
3. padding actor 和 padding frame 不参与重建损失；
4. 不使用未来轨迹生成重建标签；
5. 不把 `recon_pred` 回填到 `x_positions_diff` 或 `x_velocity_diff`；
6. 推理和测试时不依赖 `recon_pred`；
7. 第一版不再额外采样第二张重建 mask，避免把“输入缺失增强”和“辅助任务遮挡”混成两个变量；没有人工删点的位置，重建损失为 0。

推荐损失：

```text
L_rec = masked_SmoothL1(recon_pred, recon_target, recon_mask)
L_total = L_M0 + λ_rec · L_rec
```

第一轮只测试：

```yaml
reconstruction:
  enabled: true
  target: motion_3d
  mask_source: waypoint_drop_mask
  lambda: 0.05
  warmup_epochs: 5
  train_only: true
```

`mask_source=waypoint_drop_mask` 表示重建监督与 M1 的人工删点严格配对；若某样本没有人工删点，则该样本的重建损失为 0。若 `λ=0.05` 的重建损失下降但主指标无改善，再测试 `λ=0.10`。第一轮不引入动态损失平衡，以便判断辅助任务本身是否有增量。

### 6.4 模型接线

在 `src/model/trajectory_forecaster.py` 中，重建头接在历史 Mamba 的逐时间步输出之后、历史摘要读取之前：

```text
for history_block:
    actor_feat = history_block(actor_feat)

recon_pred = reconstruction_head(actor_feat)

actor_feat = actor_feat[:, -1]
```

重建头建议为：

```text
Linear(128 → 64) → GELU → Linear(64 → 3)
```

重建头的输出只放入 `ret_dict`，不得改变 `actor_feat` 的主路径。对应输出键建议命名为 `recon_pred`，避免覆盖已有 `y_hat`、`pi`、`scal` 和 `new_*` 字段。

在 `src/model/forecasting_module.py` 的 `cal_loss()` 中：

1. 读取 `out["recon_pred"]`、`data["recon_target"]`、`data["recon_mask"]`；
2. 计算按 mask 归一化的 `SmoothL1`；
3. 将 `lambda_rec * recon_loss` 加到现有总损失；
4. 记录 `train/recon_loss`、`val/recon_loss`，但 checkpoint 仍只看 `val_minFDE20`；
5. 验证和测试可以计算重建损失用于诊断，但不能将其作为模型选择指标。

### 6.5 M2 门禁

- M2 必须在 M1 的最佳 `waypoint_drop_probability` 上运行，不重新同时搜索 M1 参数；
- `recon_loss` 应在训练中下降并保持有限值，但“重建损失下降”不是通过条件；
- 总体 `minADE20`、`minFDE20`、`MR` 不得相对 M1 系统性恶化；
- 高缺失组至少有一个 top-1 指标（`ADE@1`、`FDE@1`、`MR`）改善，或 `b-minFDE20` 有稳定改善；
- 完整历史组不应因为辅助任务出现明显漂移；
- 必须通过未来不泄漏审计：重建标签只能来自人工遮挡前的历史有效特征。

若 M2 只改善 reconstruction loss，而预测指标不改善，则将其记录为表示学习负结果，不进入 M3。

## 7. M3：缺失证据条件化的输出校准

### 7.1 动机

现有诊断显示，高缺失样本中可能存在接近 GT 的候选轨迹，但最高概率 mode 排序不可靠。因此 M3 不再改历史共享表示，而是直接作用于 DeMo 最终输出的概率和尺度。

### 7.2 evidence 特征

只使用历史 mask 派生的 focal actor 证据，不使用位置、未来或 scene 标签。建议形成：

```text
e = [
    valid_ratio,
    missing_ratio,
    anchor_lag / obs_len,
    forecast_gap / obs_len,
    max_missing_run / obs_len
]
```

其中：

- `valid_ratio`：focal 历史有效帧比例；
- `missing_ratio`：`1 - valid_ratio`；
- `anchor_lag`：最后有效观测距观测窗口末端的间隔；
- `forecast_gap`：从最后有效观测到未来第一步的时间间隔；
- `max_missing_run`：focal 历史最长连续缺失长度。

`max_missing_run` 若当前 batch 尚未提供，应在 `trajimpute_dataset.py` 和 collate 中补充为诊断字段；它不应通过重新读取原始文件或访问未来计算。

### 7.3 校准形式

第一版只校准最终输出 `new_pi` 和 `scal_new`，同时保留未校准的 `pi`、`scal` 和原始 `new_*` 作为诊断。

建议使用样本级标量校准，避免第一轮引入过多自由度：

```text
log_tau   = missing_ratio · f_tau(e)
log_scale = missing_ratio · f_scale(e)

new_pi_cal  = new_pi / exp(log_tau)
scal_cal    = scal_new · exp(log_scale)
```

其中：

- `tau` 越大，mode logits 越平，表示低证据下减少过度自信；
- `scale` 越大，Laplace 尺度越宽，表示低证据下提高预测不确定性；
- `missing_ratio` 作为门控，保证 all-valid 样本恒有 `log_tau=0`、`log_scale=0`；
- `f_tau` 和 `f_scale` 的最后一层零初始化，保证训练初始时与 M0 等价；
- `scal_cal` 的形状先使用 `[B, 1, 1, 1]` 广播，不第一轮学习逐 mode、逐时间、逐坐标校准。

校准头建议为：

```text
Linear(5 → 32) → GELU → Linear(32 → 1)
```

在 `src/model/trajectory_forecaster.py` 或 `src/model/layers/structured_future_decoder.py` 中实现均可，但必须满足：校准头参数进入 checkpoint，输出 raw/calibrated 两套字段，且不改变候选轨迹均值 `new_y_hat`。

### 7.4 损失与评估

第一版不新增独立 calibration loss，直接将校准后的 `new_pi_cal`、`scal_cal` 用于最终分支已有的分类损失和 Laplace NLL：

```text
L_final = CE(new_pi_cal, best_mode_new)
          + LaplaceNLL(new_y_hat, scal_cal, new_pi_cal)
```

保留 raw 分支的原有损失，避免校准头单独承担全部训练信号。验证时同时报告：

- raw `new_pi` 的 `MR`、`ADE@1`、`FDE@1`；
- calibrated `new_pi_cal` 的同一组指标；
- `b-minFDE20`；
- 各 evidence bin 的 mode entropy；
- 高缺失组的平均预测尺度。

如果校准后只改善 `minADE20/minFDE20`，但 `MR`、top-1 或 `b-minFDE20` 恶化，则判定为候选覆盖改善但概率排序失败。

### 7.5 M3 门禁

- all-valid 样本 raw/calibrated 输出必须逐位一致或在明确的浮点误差范围内一致；
- 高缺失组的 `MR` 或 `b-minFDE20` 至少一项稳定改善；
- 不能以整体 best-of-20 改善掩盖 top-1 退化；
- `scal_cal` 必须为有限正数，不得出现 NaN、Inf 或异常爆炸；
- 三个随机种子至少两个方向一致；
- raw 与 calibrated 输出都必须保存，禁止只保留校准后的结果。

## 8. M4：关系级动态多尺度交互（可选）

### 8.1 启动条件

M4 不是默认必做。只有满足以下条件才启动：

- M1–M3 至少一个版本在高缺失组和总体指标上均有稳定收益；
- 诊断仍显示 focal–neighbor 关系在缺失条件下是主要误差来源；
- 现有方案已经排除单纯训练分布和概率排序不足；
- 能够通过 actor permutation、padding 隔离和关系打乱测试。

### 8.2 模块形式

不要新增完整一套社会网络，先将 5 层 Scene Context Transformer 中的 1 层替换为关系级模块：

```text
2 层 Scene Transformer
    ↓
1 层 Dynamic Multi-scale Relation Block
    ↓
2 层 Scene Transformer
```

关系级输入建议包含：

```text
relative_position
relative_velocity
distance
relative_heading
focal-neighbor temporal overlap
focal-neighbor missing evidence
```

构造 3 类关系尺度：

1. 近邻 pairwise relation；
2. 中距离 group relation；
3. 场景级 group summary。

缺失可靠性只能调节具体 focal–neighbor 消息，不能直接按邻居 valid rate 给所有 focal 统一加权。actor token 是无序集合，禁止沿文件顺序使用 actor-axis Mamba 或其他顺序扫描。

### 8.3 M4 门禁

- actor permutation 后输出保持一致；
- padding actor 不改变有效 focal 的输出；
- 随机打乱 reliability feature 后性能应下降或至少改变，证明模块真正使用关系级可靠性；
- 相比 M3，不能只增加参数量后得到收益；
- 若只改善某一场景或某一缺失等级，停止扩展关系模块。

建议统一使用以下输出目录，避免与历史 screening 混淆：

```text
outputs/trajgap_plan/

```

## 10. 测试与审计清单

### 10.1 数据级

- 人工删点不改变未来坐标和未来 mask；
- 人工删点先作用于世界坐标历史有效性，再由增强后历史重新确定局部原点/朝向；不得使用未来确定坐标系；
- 局部 `target` 可以因历史锚点变化而重算，但其逆变换必须回到未修改的原始未来坐标；
- 官方缺失与人工缺失可区分；
- `x_valid_mask`、`x_gap_steps`、`x_last_valid_idx` 一致；
- 至少保留一个有效历史帧；
- actor 顺序和 scene 分组不变；
- train-only 增强不会污染 val/test。

### 10.2 重建级

- `recon_mask` 只覆盖人工遮挡的原本有效帧；
- `recon_target` 与增强输入处于同一局部坐标系；
- 官方原本缺失帧、padding 帧不计入 loss；
- 重建头不改变主预测张量；
- 重建标签只来自人工删点前的历史有效坐标/运动特征，不读取未来；
- `lambda=0` 时应退化为 M1 的主预测损失。

### 10.3 校准级

- all-valid 时 `new_pi_cal == new_pi`、`scal_cal == scal_new`；
- temperature 和 scale 始终有限；
- raw/calibrated 输出同时保存；
- 只使用 focal 历史 mask 派生字段；
- 不以 test 指标选择校准超参数。

### 10.4 关系模块级

- actor permutation 不改变输出；
- padding actor 隔离；
- 关系特征随机打乱对照；
- 相对位置和相对速度为主，可靠性不能单独决定消息；
- 不使用 actor 文件顺序作为时序顺序。

## 12. 推荐执行顺序

最终执行顺序固定为：

```text
M0 配对复验
    ↓
M1：p=0.10 waypoint dropping
    ↓ 通过后
M1：p=0.20 waypoint dropping
    ↓ 选择单一最佳 p
M2：masked-motion reconstruction，λ=0.05
    ↓ 若仅重建有效但预测无增益，再试 λ=0.10

    ↓ 若仍确认关系误差是主因
M4：只替换 1 层动态多尺度关系模块
```

任何阶段未通过门禁，都停止向后叠加，不把多个未验证模块缝合成一个无法归因的最终模型。
