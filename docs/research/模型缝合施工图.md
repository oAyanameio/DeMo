# 模型缝合施工图（M0 基座）

> **文档性质**：模型改造施工方案（缝合/borrowing 路线图），不是实验结果。
>
> **基座**：M0（本模型）＝当前 DeMo actor-only 实现 + TrajImpute direct 数据路径。
>
> **协议**：所有正式比较统一 **TrajGap-Bench mixed-direct**——TrajGap（Easy/Hard 同 split 合并的 Mixed）训练/验证/测试，单一 Mixed-val 按 `val_minFDE20` 选点，五场景 `ETH-M/HOTEL-M/UNIV-M/ZARA1-M/ZARA2-M`，K=20。
>
> **指标口径**：主榜只报 minFDE20 / minADE20 / MR 三指标（macro + micro + worst-scene，综合分 S_m 用冻结归一化）；top-1、概率质量/校准、连续性等五指标齐看仅作**内部晋级纪律**，不进总榜。
>
> **当前裁定状态（2026-10-03）**：C1-A 保留为 control；C3 未胜 C1-A；**C4 已判负关闭**（MR 宏平均 +14.7%）。ECDC 设计文档已废弃；本文档是 C 线之后唯一的模块施工依据。

## 1. 通用施工规范（所有位点必须遵守）

1. **三处同步**：新增任何模型开关，必须同时改三处——
   - runner 变体表：`scripts/训练与评估/run_trajimpute_experiments.py` 的 `VARIANTS`；
   - 评估器重建：`scripts/结果分析/evaluate_trajimpute_direct.py` 的 `VARIANTS` + `build_model`；
   - manifest：两脚本写出的 `model_switches` 字段。
   漏改评估器 = 用基线语义给变体权重打分，整臂作废。
2. **RNG 保护**：可选模块一律在 `initialize_weights()` 之后、`torch.random.get_rng_state()/set_rng_state()` 保护块内创建（参照 `model_forecast.py` 中 C2/C3/C4 的现有写法），保证配对 M0 权重 bitwise 一致。
3. **恒等启动**：新模块对主链必须是加性零初始化残差或 `alpha=exp(-MLP(·))`（末层零初始化 ⇒ alpha≡1 启动且梯度活）。禁止用 ReLU/softplus 压范围——零初始化下梯度死锁。
4. **单变量**：一次只动一个位点；对照臂 = 同代码态同预算的 M0 重训。
5. **不动的部分**：decoder 结构、loss、数据协议、优化器在诊断机制期间保持冻结（F3 等训练侧独立臂例外，但必须独立成臂）。
6. **必测不变量**：全有效输入 ≡ M0；无效坐标扰动不改输出；padding actor 隔离（同 batch 内扰动验证）；`gate×scale` 双零机制分别单测（一个强制为 1 测另一个）。

## 2. 位点 A：输入嵌入层

### A1 连续时间嵌入（mTAN 式 Δt embedding）

- **出处**：mTAN（Shukla & Marlin, ICLR 2021）——连续时间值嵌入 + 注意力插值。
- **缝合点**：`hist_embed_mlp` 输出后（`model_forecast.py` forward，actor_tokens 处）。
- **改法**：

```python
# 新增模块（RNG 保护块内创建）：
self.delta_embed = nn.Sequential(Linear(1, 32), GELU(), Linear(32, embed_dim))
nn.init.zeros_(self.delta_embed[-1].weight)   # 恒等启动
# forward：
dt_real = actor_gaps * self.dt                # x_gap_steps 已有 [A,L]
actor_tokens = actor_tokens + self.delta_embed(dt_real[..., None])
```

- **开关**：`time_embedding_mode: 'none' | 'delta'`，进三处同步表。
- **包装动机**：同一位移跨越 1 帧与 4 帧缺口，时间语义不同；把离散 `gap_steps` 换算成真实秒数连续嵌入，让 Mamba 的时间传播有显式时钟。论文表述为 *continuous-time observation embedding*。
- **必做对照**：与 C2（gap_control）对比——若 C2 已解释收益，A1 不再单独主张。
- **Go/No-Go**：Mixed-test 内部五指标至少 3 项不劣、minADE/minFDE 有一项显著优于 C2，否则并入 C2 叙事。

### A2 缺失模式 prompt（MMP 式）

- **出处**：MMP（Lee et al., CVPR 2023）；DCP（NeurIPS 2024）为深化版。
- **缝合点**：Mamba 各层之间 + Scene Transformer 首层前。
- **改法**：按证据特征分桶，每桶一套可学习 prompt 向量 `[n_bucket, Lp, D]`，按样本桶索引在每层 Mamba 输出上加性拼接/相加；**冻结主干，只训 prompt**。
- **开关**：`missing_prompt: false | true`（冻结主干由 runner 的 freeze 列表控制）。
- **包装动机**：缺失模式 = 输入分布偏移，用 pattern-conditioned prompt 校正；<1% 参数可单独讲 efficiency 故事（冻结 M0 主干 + prompt 恢复缺失性能）。
- **必做对照**：同预算全参数微调 M0（证明 prompt 不是靠"少训"占便宜）；桶随机化消融。
- **桶定义**：借 *Uncovering the Missing Pattern*（arXiv 2303.16005）的缺失模式分类（point / segment / prefix），比手工 valid_count 分桶有依据。
- **Go/No-Go**：恢复 ≥70% 的 M0 高缺失诊断分层（valid_count≤2）相对低缺失分层的性能跌幅，且参数 <2%。

### A3 可学习缺失嵌入（GRU-D trainable missing representation）

- 与 A1 同位点、互斥开关。缺失帧 token 不与有效帧共享输入空间，替换 `actor_tokens * actor_valid`（integrated 现有硬置零）为 `+ missing_embedding`。仅当 A1/C2 都不能解释失败时启用。

## 3. 位点 B：时序状态层

### B1（=C2）gap-conditioned feature control —— 已实现

`evidence_state.py: GapConditionedFeatureControl`，Mamba 前加性残差。**当前任务**：在 Mixed 协议下跑正式五场景判定，作为 B3/E 位点的前置 control。

### B2（=C3）observed-write / gap-propagation —— 已实现

`evidence_state.py: ObservedWriteGapState`。Hard screening 未胜 C1-A；Mixed 重判前不改。

### B3 scan 内隐状态衰减（C3-ii：把衰减写进 scan 语义）

- **出处**：GRU-D hidden state decay 的正统形式 `h_t = decay(Δt) ⊙ h_{t-1}`；UniTraj BTS 同族。
- **缝合点**：不改 selective scan kernel；在 4 层 Mamba 的**层间**加逐帧衰减：

```python
# 每层 Mamba block 输出后（或仅第 1 层，单变量起见先只加第 1 层）：
alpha = torch.exp(-self.gap_decay_mlp(actor_gaps[..., None]))   # [A,L,1]∈(0,1)
actor_feat = alpha * actor_feat + (1 - alpha) * actor_feat_shifted_prev_valid
```

  实现上等价于"缺失帧的层间输出向最近有效状态回缩"；`gap_decay_mlp` 末层零初始化 ⇒ alpha≡1 启动。
- **开关**：`evidence_state_mode` 扩展 `'scan_decay'`。
- **与 C3 的关系**：C3 在 Mamba **前**控写入；B3 在 Mamba **链路中**控传播。二者是"写入语义 vs 传播语义"的可分离消融，正好构成论文的机制分解表。
- **包装动机**：*gap-aware state propagation*——缺失区间内状态不接收新证据，只按经过时间衰减，对应 SSM 的 `h_t = A(Δt) h_{t-1}` 离散化。
- **必做对照**：C3（前控）、A1（输入嵌入）、B1（gap_control）；三者任一解释收益即不单独主张 B3。
- **Go/No-Go**：高缺失分层（valid_count≤2 / max_run≥3）改善且完整层不回归。
- **诚实预期**：UniTraj 自己的消融显示单向 BTS 收益≈0.01 且数据集依赖；与 C3 未胜出一致——B3 是消融表的一行，不是翻盘指望。

### B4（=C6）evidence–motion 双流 SSM

- **出处**：S4M（2025）dual-stream S4。
- **缝合点**：`hist_embed_mamba` 复制为两条 2 层流：motion 流吃现有 4 维特征；evidence 流吃 `[valid, gap_steps, gap_steps×dt]`（3 维投影到 D）。汇合处学习门控 `g = σ(MLP(evidence_state))`，`fused = motion + g ⊙ evidence`，门控零初始化。
- **包装动机**：运动内容与观测可靠性语义不同；拼接让模型自己学关系，双流显式分离 *what happened* 与 *how reliable*。
- **前置**：C2/C3 机制成立后才做。

## 5. 位点 D：Scene Transformer 社会层

**结构性优势**：本任务设定里 focal 缺失、邻居恒完整——缺失观测可由邻居证据补偿，这是别人（全场景缺失）没有的设定。

### D1 agent-aware attention（AgentFormer 式）

- **出处**：AgentFormer（Yuan et al., ICCV 2021）——self/other agent 两套 Q/K 投影。
- **缝合点**：`transformer_blocks.Block`（Scene Transformer 5 层）中的 attention；focal（index 0）与其余 actor 用不同投影矩阵，agent 身份由位置即可判定（[:,0] 是 focal）。
- **改法**：Block 内加 `W_q_self/W_k_self/W_q_other/W_k_other`，mask `M_ij = 1(i 为 focal ↔ j 为 focal)`；零初始化差分投影保证启动等价。
- **包装动机**：*evidence-role-aware interaction*——自身证据与邻居证据在注意力里角色不同，为 D2 的补偿门控做铺垫。
- **Go/No-Go**：独立臂先过 Mixed；无收益则直接并入 D2 做消融行。

### D2（=C7）证据自适应社会补偿（Raindrop 式 + goal 条件化）

- **出处**：Raindrop（Zhang et al., ICLR 2022）——异步到达的观测在传感器图上消息传递，缺失传感器由邻居观测更新；goal 加权借 Social-Mamba（ECCV 2026）的 goal-centric scan。
- **缝合点**：Scene Transformer 之后、TimeDecoder 之前。
- **证据特征**：C4 判负后改由**独立小 MLP 从 mask/gap 重算**，不经过 mode query 注入路径。

```python
g = σ(MLP(evidence_real))                     # [A,1] focal 证据越缺 g 越大
goal_others = y_hat_others[:, :, -1]          # 邻居预测端点 [B,N-1,2]（dense_predictor 已有）
goal_focal  = self.dense_predictor(x_encoder[:, :1]).view(B, 1, -1, 2)[:, 0, -1]
w = softmax(cosine(goal_focal[:,None,:], goal_others), dim=1)   # 方向感知邻居加权
social_ctx = (w.unsqueeze(-1) * x_encoder[:, 1:N]).sum(1)
x_encoder_focal = x_encoder[:,0] + g * W_s(social_ctx)
```

- **增效逻辑**：邻居恒完整时，哪个邻居值得借取决于 focal 要去哪；均值补偿只给背景上下文，goal 加权才给方向证据。
- **关键消融**（不做不能主张"补偿"）：
  - 时间打乱邻居（shuffle 邻居时间轴）——真正的时间对齐贡献应消失；
  - 随机替换邻居——补偿应退化为噪声；
  - goal 端点打乱——方向感知贡献应消失；
  - 完整历史 focal 上 g 应自动趋小（完整层不回归即旁证）。
- **包装动机**：*evidence-adaptive social compensation*——focal 证据不足时按可靠性动态加大社会上下文写入，证据充足时防止邻居覆盖自身运动。
- **Go/No-Go**：高缺失分层改善 + 全部负对照按预期退化 + 完整层不劣。

## 6. 位点 E：输出分布层 —— C4 判负，E 位点关闭

### E1（=C4）mode query 证据条件化 —— 已判负，关闭

- **裁定**：minADE 劣化、minFDE 噪声带内、MR 显著劣化且 ZARA2 +46%——"evidence→mode query 加性注入"该位点判负，**不做变体重试**（换注入形式/换特征子集不再排期）。
- **机制解读（写论文时用）**：4 维证据向量注入 mode query 后，mode 检索空间被系统性偏移，best-of-K 几乎不动（min 指标天然抗扰动），但 mode 排序被破坏——这正是"best-of-K 不动、top-1/MR 崩"的分布可靠性退化模式的实证，可引作 motivation 而非贡献。
- **代码保留**：`evidence_state_mode='integrated'` 路径与 `evidence_query` 保留作负结果对照，默认关闭。

### E2（=C5）scale 证据条件化 —— 搁置

前提位点 E1 已判负；scale 条件化与 E1 共享"证据→分布参数"假设。除非后续 F2 温度校准显示分层校准存在**大额**可收割空间（否则后处理即可收割，无须改模型），不再启动。若重启：缝合点 `GMMPredictor.scale`/`GMMPredictor_dense.scale`，开关 `evidence_conditioning: 'off'|'query'|'query_scale'`，零初始化乘性注入；必测校准指标单独报告，Go/No-Go 为 top-1/MR 或校准至少一项显著改善且 MR 不劣化。

### E3 evidential（Dirichlet）mode 概率 —— 低优先

- **出处**：Sensoy et al.（NIPS 2018）EDL。
- **改法**：`pi`（mode logits）→ Dirichlet 浓度参数，训练加 KL 正则；输出"分布本身的不确定性"。
- **定位**：仅当 E2 的校准收益不足时启用；E1 判负后与 E2 同属低优先，实现重且改 loss（违反"loss 冻结"纪律），排最后。

## 7. 位点 F：训练与校准

### F1 CSDI 式自监督掩码训练

- **出处**：CSDI（Tashiro et al., NeurIPS 2021）的 target/condition 自监督切分。
- **缝合点**：不改模型，改数据增强——Mixed 训练批内随机再 mask 已观测帧（保持前缀约定），模型在更稀疏条件下直接预测未来。
- **开关**：`extra_mask_rate: 0.0 | 0.2`（runner 侧）。
- **包装动机**：*evidence-coverage curriculum*——把手工 severity 分层换成有原则的掩码自监督，覆盖未见缺失程度。
- **必做对照**：同预算（epoch 数 × 样本量对齐）不加掩码的 Mixed。
- **Go/No-Go**：Mixed-test 三指标不劣 + 高缺失诊断分层（valid_count≤2 / max_run≥3）改善。

### F2 分证据层温度校准（后处理）

- 按 `valid_count` 分层（如 1-2/3-4/5-7/8），每层在 Mixed-val 上拟合温度 T 缩放 mode logits，测试期按层应用。零训练成本，一个下午出结果。
- **双重角色**：① 直接收割校准收益（安全区主张之一）；② 探针——若分层校准空间大，才考虑重启 E 系；若后处理即可收平，E 位点永久关闭。

### F3 辅助缺失历史重建损失（Sports-Traj 统一任务 / TIMBA 重建头）

- **出处**：Sports-Traj 的统一补全+预测任务、TIMBA 的双向重建——借其"被 mask 帧真值当监督"的思想，但**推理侧保持 imputation-free**。
- **缝合点**：不改结构；encoder Mamba 输出上挂一个小回归头（`Linear(D, 2)`），只在被 mask 的历史帧位置预测真实位移，`λ≈0.1` 加权进总 loss。

```python
# trainer loss 内：
recon = self.recon_head(actor_feat_seq)               # [A,L,2]，仅诊断用，不进推理
recon_loss = F.smooth_l1_loss(recon[~valid], gt_disp[~valid]) * lambda_recon
```

- **数据侧前提**：dataloader 需把被 mask 帧的**真实位移**带出来（TrajImpute 原始完整轨迹现成，插补基线训练用的就是它，只需新增一个 target 字段）。
- **诚实边界**：模型训练中见过缺失位置的真值——论文叙事必须落在"推理侧 imputation-free"（测试输入无插补），消融单列，且不得与 C 线同臂混训；这是 loss 变更，违反"loss 冻结"纪律，必须独立臂。
- **增效逻辑**：高缺失层正是监督最稀的地方，辅助监督直接加密高缺失层的梯度信号；Sports-Traj/TrajImpute 系插补基线全量用完整轨迹训练，这个头是把同样的标签捡回来给 direct 模型用，信息量对齐。**全表性价比最高的独立臂。**
- **Go/No-Go**：高缺失分层（valid_count≤2）minADE/minFDE 显著改善，完整层不回归；若与 C 线叠加有增益，需单独报告"F3 only / C+F3"两行。

### F4 多尺度观测蒸馏（TOTP/TAMLD Temporal-Aware Distillation）

- **出处**：TOTP/TAMLD（ICCV 2025）——变长观测下的 temporal sparsity imbalance 蒸馏。
- **缝合点**：不改结构；训练时同一样本双前向——teacher=完整历史（`no_grad`，可用 EMA 或以 `missing_mask` 全真重前向的 M0 自身充当），student=缺失输入；损失 = encoder 状态 MSE + mode 分布 KL。

```python
with torch.no_grad():
    t_dense, t_y, t_pi, *_ = model(clean_batch)
s_dense, s_y, s_pi, *_ = model(missing_batch)
distill_loss = F.mse_loss(s_dense, t_dense) + kl_div(s_pi, t_pi)
```

- **成本**：每步 ≈1.3× 前向；零结构改动，最容易先跑。
- **增效逻辑**：本任务缺失=有效观测时长缩短，正是 TOTP 定义的 temporal imbalance；teacher 给完整证据下的状态/分布做锚，直接约束缺失条件下状态不漂移。
- **必做对照**：teacher 用"训练中也见缺失的 M0" vs "missing_mask 全真重前向的 M0"——若后者更好，说明蒸馏的是完整证据知识而非任务知识。
- **Go/No-Go**：Mixed-test 三指标不劣 + 高缺失诊断分层（长 gap）改善；若与 F3 叠加，同 F3 规则分两行报告。

## 8. C8：潜空间运动原型（EigenTrajectory 式）

- **出处**：EigenTrajectory（Bae et al., ICCV 2023）SVD 低秩 ET 空间 + anchor 检索。
- **改法**：训练集未来轨迹 SVD 取 top-k 基 → 未来分布回归到 ET 系数空间；focal 证据不足时用历史系数检索最近 anchor 作为 mode query 初始化先验。
- **铁律**：基与 anchor 只能由训练集构造，测试集轨迹不得进 SVD——否则数据泄漏。
- **定位**：高风险高回报，全部 C 线判定后最后做。
