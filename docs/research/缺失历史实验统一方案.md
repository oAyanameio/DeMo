# 缺失历史实验统一方案

_ETH/UCY 与 SDD · DeMo actor-only · 历史自定义协议精简版 · 2026-09-07_

> **定位：历史预实验归档。** 本文把 v1、v2、v3 三轮方案合并为一份关键协议速查，不再定义当前论文的正式 benchmark。当前正式主协议为：`Clean-direct` 使用原始完整 ETH/UCY，`Easy-direct / Hard-direct` 使用 TrajImpute release，见《选题》§八.0。三轮详版保留在 `docs/research/archive/`，用于复现实验历史。

## 1. 统一任务定义

- 输入：8 帧历史轨迹，可对历史帧施加缺失；未来 12 帧始终完整，作为监督目标。
- 时间：0.4 秒/帧，2.5 Hz；ETH/UCY 指标单位为米，SDD 指标单位为像素。
- 模型：DeMo actor-only，无地图；ETH/UCY 保留多行人上下文，SDD 按既有协议作为单行人外部验证。
- 缺失处理：缺失位置不得使用未来信息插补；由掩码重新计算 DeMo 输入特征。
- 数据切分、掩码和随机种子在数据制作阶段固定，并写入 manifest。

## 2. 三轮协议

| 轮次 | 数据版本 | 缺失条件 | 关键约束 | 主要问题 |
|---|---|---|---|---|
| v1 轻度缺失 | `missing_history_v1` | `complete`、`random_single`（12.5%）、`random_block2`（25%） | 帧 6、7 强制可见，缺失只发生在帧 0–5 | 完整历史到轻度缺失的自然退化 |
| v2 高缺失 | `missing_history_v2_high` | `random_fixed3/4`（37.5%/50%）、`random_block3/4/6`（37.5%/50%/75%） | 延续帧 6、7 强制可见 | 缺失数量和连续性对误差、模态命中及稳定性的影响 |
| v3 无保护 | `missing_history_v3_noguard` | `random_fixed3_ng`、`random_fixed4_ng`、`random_block3_ng`、`random_block4_ng`、`random_block6_ng`、`uniform_hard_ng` | 帧 0–7 均可缺失；锚点回退到最后有效观测 | 末端缺失和观测间隔变化下的退化与适应 |

共同规则：二维坐标按整帧缺失；未来不缺失；ETH/UCY 与 SDD 不混合训练；所有条件使用独立输出目录；已有 v1/v2/v3 数据和结果不覆盖、不重写。

## 3. 实验阶段

### A. 零样本基线

- 用 `complete` 训练/验证选出的 checkpoint，直接测试各缺失条件。
- 比较 DeMo 单向与双向历史编码。
- 目的：测量普通 DeMo 面对分布外缺失的自然鲁棒性。

### B. 训练适应基线

- 每个缺失条件独立使用对应 train/val 训练，并在同条件 test 评估。
- v1 覆盖轻度条件；v2/v3 优先覆盖 `fixed4`、`block6` 和混合困难条件。
- 目的：区分零样本退化与已知缺失分布下的适应能力。

### C. 缺失感知消融

| 模型 | 增量 | 研究问题 |
|---|---|---|
| `M0_base` | 当前 DeMo 输入 | 缺失历史基线 |
| `M1_obs` | 时间步缺失特征、有效运动和观测间隔 | 局部观测过程信息是否有效 |
| `M2_history` | 历史级缺失摘要 | 全局缺失结构是否提供额外信息 |
| `M3/M4` | Query / Hybrid 条件化 | 缺失条件是否应进入结构化未来分布 |

实验顺序固定为 `M0 → M1 → M2`；只有 M1/M2 在代表性连续高缺失条件下形成稳定收益，才启动 M3/M4。v3 的首筛仅覆盖 `M0/M1/M2 × random_fixed4_ng`，不包含 M3/M4。

### D. 混合条件泛化

- 训练条件固定为多个已知缺失条件的混合集合，不在线随机改变协议。
- 已见条件和未见困难条件分别报告，不能合并成一个平均数。
- 目的：判断模型学习的是缺失处理规律，而不是记忆单一掩码分布。

## 4. 评价与统计

- ETH/UCY：`minADE6`、`minFDE6`、`MR`、`b-minFDE6`。
- SDD：按既有像素制 `minADE20`、`minFDE20`、`MR`、`b-minFDE20` 报告。
- 主终点优先使用 `minFDE`；同时报告样本数、均值、标准差、最佳/最差 seed 和逐条件差值。
- 分层分析：缺失帧数、随机/连续缺失、`anchor_lag_steps`；`uniform_hard_ng` 另按实际缺失数分层。
- 训练适应、零样本和混合条件泛化分开统计；不得把历史协议结果与 TrajImpute direct 结果混排。
- 结论不得来自单一场景、单一 seed、单个案例或测试集调参。

## 5. 验收与停止规则

- 数据：历史只缺失、未来完整、掩码与坐标一致、无未来泄漏、manifest 完整。
- 工程：训练、checkpoint 加载和评估可重复；出现 NaN、Inf、缺 checkpoint 或重复评估不一致时先修工程问题。
- 方法：M1/M2 必须相对配对的 `M0_base` 报告；稳定收益至少应跨多数场景/seed 或在代表性缺失机制上复现。
- 若只有零样本改善，只能主张分布偏移鲁棒性；若只有单一条件改善，只能限定为该缺失结构有效。
- 若复杂模块无真实未来预测、覆盖性或连续性收益，停止堆叠并收缩为退化建模与失败边界研究。

## 6. 与当前正式主线的关系

三轮协议及结果统一标记为：

> 历史自定义 v1/v2/v3 缺失协议、训练适应、零样本和缺失感知首筛结果；用于研究路线演化、工程问题定位和失败边界分析，不构成 TrajImpute 官方结果，也不构成当前 direct 主结果。

当前正式执行顺序为：

```text
原始完整 ETH/UCY
→ Clean-direct 上复现 M0-current、筛选 B0/B1/B2
→ 固定 M0-strong
→ TrajImpute Easy-direct 上复验 M1/M2
→ 通过确认性门槛后再考虑 M3/M4
→ TrajImpute Hard-direct 做高缺失鲁棒性分析
```
