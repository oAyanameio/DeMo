# 证据覆盖感知的无插补轨迹预测：研究线索整理

> **文档性质**：独立研究构思与实验设计文档，不等同于最终论文方案。
>
> **研究对象**：部分观测历史（partially observed history）条件下的无插补行人轨迹预测（imputation-free trajectory forecasting）。
>
> **当前基础**：DeMo 的 M0 模型与 TrajImpute Easy/Hard direct 协议。
>
> **当前判断**：研究问题已经有实验依据；方法创新尚未完成验证，不能提前宣称原创性或有效性。

---

## 1. 核心研究问题

给定存在缺失、时间断裂或观测中断的历史轨迹，不使用独立插补器，直接预测未来多模态轨迹分布：

```text
可见历史观测 + 缺失位置 + 观测时间结构 + 社会上下文
    -> 未来轨迹分布
```

核心问题不是简单地恢复一条完整历史，而是：

> **当可用历史证据的数量、时效性和连续性发生变化时，如何让时序状态传播、未来多模态分布和预测可靠性随之自适应？**

建议的总方向名称：

- 中文：**部分观测历史下的证据覆盖感知无插补轨迹预测**
- English：**Evidence-Coverage-Aware Imputation-Free Trajectory Forecasting under Partially Observed Histories**

---

## 2. 已有实验给出的事实基础

### 2.1 M0 的高缺失失效不是单纯平均位置误差

D0 诊断显示，Hard 中缺失 4 帧到缺失 7 帧时：

| 指标 | Hard m=4 | Hard m=7 | 变化 |
|---|---:|---:|---:|
| minADE20 | 0.254 | 0.886 | +249.0% |
| minFDE20 | 0.406 | 1.271 | +213.3% |
| ADE@1 | 0.597 | 3.138 | +425.9% |
| FDE@1 | 1.168 | 4.752 | +306.7% |
| MR | 0.030 | 0.187 | +520.7% |

Hard m=7 平均只剩 1 个有效历史观测，`anchor_lag` 约 3.48，`forecast_gap` 约 4.48。

解释是：20 个候选中仍可能存在接近 GT 的轨迹，但最高概率 mode 经常选错，说明未来分布的可靠性和概率排序发生了明显退化。

### 2.2 缺失帧数不是充分的难度变量

需要同时考虑：

- `valid_count`：有效历史观测数；
- `anchor_lag`：最后有效历史距离窗口末端的距离；
- `forecast_gap`：最后有效观测到预测起点的间隔；
- `max_missing_run`：最长连续缺口；
- 缺失模式：随机散点、连续 block、末端缺失、前缀缺失、多段缺口；
- `heading_degenerate`：方向/速度是否已不可辨识；
- actor 间的观测异步性（asynchrony）。

因此，未来的数据协议不能只用 Easy/Hard 或 missing count 描述难度。

### 2.3 训练分布失配已被确认

P2-A 的 Easy train → Hard test zero-shot 与 Hard train-adapt 对比：

| 口径 | minADE20 | minFDE20 | ADE@1 | FDE@1 | MR |
|---|---:|---:|---:|---:|---:|
| Easy→Hard zero-shot | 0.890 | 1.285 | 1.383 | 2.253 | 0.182 |
| Hard train-adapt | 0.432 | 0.640 | 1.277 | 2.107 | 0.074 |
| zero-shot 相对增量 | +105.8% | +100.7% | +8.3% | +6.9% | +146.4% |

因此必须区分两类问题：

```text
训练没有见过对应缺失分布
vs
模型即使见过，也不能处理证据不足和时间锚点漂移
```

P2-B Mixed 训练已完成，当前结果已收口于《缺失分布交叉泛化结果》：naive Easy+Hard 混合训练与 Hard-specific training 整体接近，但未形成稳定优势；Clean→Easy/Hard 显著退化，高缺失尾部仍未解决。

## 3. 两条可延伸的研究线索

## 3.1 线索 A：多维缺失场景基准（benchmark/resource）

### 基本想法

制作覆盖不同缺失程度和缺失结构的完整数据协议，而不是只提供 Clean、Easy、Hard 三个粗粒度集合。

### 缺失空间设计

| 维度 | 示例分层 |
|---|---|
| 缺失程度 severity | 0%、轻度、中度、重度；或 valid_count=8…1 |
| 缺失位置 position | 随机、前缀、中间、末端 |
| 连续性 continuity | 散点、单段 block、多段 block |
| 时间新鲜度 freshness | anchor_lag、forecast_gap |
| 运动可辨识性 | 正常 heading、heading degenerate |
| 行人异步性 | 同步缺失、actor-specific 异步缺失 |
| 组合模式 | 末端 block + 长 forecast gap 等 |

### 能解决什么

- 现有协议不能区分“缺了多少”和“在哪里缺”；
- 无法测试未见缺失模式上的泛化；
- 不同模型的鲁棒性比较缺少统一分层；
- 单一 overall 指标掩盖高缺失尾部和概率可靠性退化。

### 数据集方案的必要约束

1. 按原始轨迹或场景主体切分，不能让同一原始轨迹的不同 mask 跨 train/test；
2. 未来轨迹保持完整，只作为监督和评估目标；
3. 所有 mask 的生成规则、随机种子和 metadata 可复现；
4. 提供 seen-pattern 与 unseen-pattern 测试；
5. 明确 Clean、官方 Easy/Hard 和新增合成模式的口径差异；
6. 报告 macro、micro、场景明细和缺失分层结果。

### 风险

如果只是把 Clean、Easy、Hard 重新打包，贡献更像数据整理；只有引入新的多维缺失空间、严格的泄漏隔离和未见模式测试，才可能形成有价值的 benchmark contribution。

---

## 3.2 线索 B：证据覆盖感知训练策略（training strategy）

### 基本想法

不按原始样本比例自然训练，而是让训练过程覆盖不同质量的历史证据：

```text
Clean / light missing / severe missing
短 gap / 长 gap
散点 / 连续 block
同步 / 异步
```

目标是提升模型对未见缺失程度和未见缺失模式的泛化，而不只是提升同分布测试分数。

### 不是简单 concat

普通做法：

```text
Clean + Easy + Hard -> ConcatDataset -> train
```

这只能作为 naive mixture baseline。因为 Clean 样本数量可能压制 Hard 样本，模型也可能主要优化完整历史条件。

候选策略应比较：

1. **Natural concat**：按原始样本比例采样；
2. **Difficulty-balanced**：Clean/Easy/Hard 等比例；
3. **Severity-balanced**：按 missing count 或 valid_count 均衡；
4. **Evidence-balanced**：按 valid_count、anchor_lag、forecast_gap、max gap、pattern 联合分层；
5. **Curriculum**：从 Clean 逐步过渡到严重缺失；
6. **Domain randomization**：在训练阶段随机生成预注册缺失模式。

### 更有价值的核心定义

训练样本不再只按数据集名称分类，而按“证据状态（evidence state）”分类：

```text
c(x) = [valid_count, anchor_lag, forecast_gap,
        max_missing_run, pattern, heading_degenerate]
```

训练目标是使训练采样分布覆盖 `c(x)` 的有效区域，而不是简单增加样本数量。

### 可以提出的训练策略

建议的主策略名称：

> **Evidence-Coverage-Aware Sampling/Training**
>
> **证据覆盖感知采样/训练**

第一版可采用：

1. 预先根据训练 mask 计算证据状态分层；
2. 将样本划分为若干 evidence bins；
3. 对稀有、高风险 bin 使用受控 oversampling；
4. 每个 batch 约束证据状态覆盖；
5. 采样比例在查看测试结果前预注册；
6. 使用 unseen-pattern test 检验是否真正泛化。

暂不需要同时加入复杂模型结构，这样可以隔离训练策略的作用。

## 4. 两种方案的比较与推荐

| 方案 | 主要贡献类型 | 当前契合度 | 风险 | 推荐定位 |
|---|---|---:|---:|---|
| 完整缺失场景数据集 | benchmark/resource | 高 | 做成简单重打包则创新弱 | 支撑协议与泛化评测 |
| Clean+Easy+Hard 直接混合 | baseline | 高 | 容易被认为 concat | 必须做的强对照 |
| Difficulty-balanced | training trick | 中 | 与常规 balanced sampling 相近 | 对照方法 |
| Evidence-balanced training | training strategy | 高 | 需证明不是样本量效应 | 候选主创新 |
| Curriculum | training strategy | 中 | 顺序依赖、稳定性风险 | 次要对照 |
| 未见模式 domain randomization | robustness training | 高 | 需严格定义测试分布 | 可作为增强项 |

### 推荐结论

如果只能选一个主创新，优先选择：

> **证据覆盖感知训练策略，而不是“制作一个数据集”本身。**

原因：

- 它直接对应已经确认的 Easy→Hard training distribution shift；
- 与现有 M0/P2-B 连续；
- 能在多个模型上验证；
- 更容易形成“问题—机制—泛化结果”的完整链条；
- 不需要把整篇论文完全转成数据集论文。

如果允许组合，建议采用：

```text
多维缺失场景基准/评测协议
        +
证据覆盖感知训练策略
        +
证据感知状态传播与可靠性条件化解码
```

其中：

- 数据协议负责定义和测量问题；
- 训练策略负责覆盖证据空间、提升泛化；
- 模型机制负责处理状态传播和未来分布可靠性。

三者不是三个平行创新，而是一个递进链条。

## 5. 推荐的实验矩阵

### 5.1 Clean 是否有帮助

| 训练协议 | 测试集合 | 目的 |
|---|---|---|
| Clean only | Clean/Easy/Hard | 完整历史基线与 zero-shot |
| Easy+Hard | Easy/Hard | 当前 P2-B |
| Clean+Easy+Hard naive | Clean/Easy/Hard | 普通混合对照 |
| Clean+Easy+Hard balanced | Clean/Easy/Hard | 均衡混合效果 |

必须观察 Clean 性能是否回归，避免用 Hard 收益换取完整数据性能下降。

### 5.2 混合方式是否重要

| 策略 | 关键问题 |
|---|---|
| Natural concat | 样本量比例是否造成 Clean 主导 |
| Difficulty-balanced | 只按数据集难度均衡是否足够 |
| Severity-balanced | 只按 missing count 是否足够 |
| Evidence-balanced | 加入 freshness 和 continuity 后是否更好 |
| Curriculum | 难度顺序是否优于静态均衡 |

### 5.3 未见缺失模式泛化

训练使用官方 Clean/Easy/Hard，测试额外使用未见：

- 连续 block 缺失；
- 末端缺失；
- 多段缺口；
- 异步 actor 缺失；
- 长 forecast gap；
- 组合缺失模式。

只有在 unseen-pattern test 上也有收益，才能声称提升了缺失泛化，而不是仅仅适应官方测试分布。

### 5.4 必须报告的指标

- minADE20、minFDE20；
- ADE@1、FDE@1；
- MR；
- b-minFDE20；
- macro 与 micro；
- 五场景明细；
- valid_count 分组；
- anchor_lag / forecast_gap 分组；
- max_missing_run 和缺失模式分组；
- Clean regression；
- seen-pattern 与 unseen-pattern gap。

## 6. 可能形成的论文创新点

### 创新点 1：多维缺失证据基准

> 构建多维缺失历史轨迹评测协议，从缺失程度、缺失模式、观测新鲜度、连续缺口和 actor 异步性描述无插补预测条件，而不是仅按 missing count 划分。

英文表述：

> We establish a multidimensional missing-history benchmark that characterizes incomplete trajectories by severity, temporal pattern, observation freshness, and inter-agent asynchrony.

定位：benchmark contribution。需要严格 split 隔离和 unseen-pattern test 支撑。

### 创新点 2：证据覆盖感知训练

> 提出根据历史证据数量、时效性和连续性进行分层采样的训练策略，使模型在训练阶段覆盖不同质量的预测条件，提升对未见缺失程度和缺失模式的泛化。

英文表述：

> We propose an evidence-coverage-aware training strategy that balances exposure across different levels and types of historical evidence, improving generalization to unseen missingness conditions.

定位：最推荐的主训练创新。必须证明优于 naive mixture，并排除单纯增加样本量的解释。

### 创新点 3：证据感知模型机制（后续条件性）

如果 P2-B 后高缺失尾部仍然存在，再发展：

- evidence-gated temporal state propagation；
- reliability-conditioned multimodal decoder；
- 可选的 reliability-synchronized social context。

英文表述：

> We further introduce evidence-aware state propagation and reliability-conditioned multimodal decoding to adapt temporal state evolution and predictive uncertainty to available historical evidence.

定位：真正的模型创新。当前尚未通过实验验证，不能提前写成已成立贡献。

### 6.4 UniTraj 借鉴：方向特异性时间衰减（borrowed control）

UniTraj/Sports-Traj 中最适合接入当前主线的不是整个 encoder 或 CVAE decoder，而是 **direction-specific temporal decay（方向特异性时间衰减）**：正向和反向时序分支分别根据自己一侧距离最近有效观测的步数，对进入 Mamba 的证据进行通道级衰减。

在当前 M0 中应按以下边界融入：

```text
M0 hist_embed_mlp
    -> 正向 gap decay -> M0 单向 temporal Mamba
    -> M0 actor-level readout
    -> 原 Scene Transformer
    -> 原 TimeDecoder
```

第一版只验证 decay，不同时引入双向 Mamba。数据适配器已经提供 `x_valid_mask` 与 `x_gap_steps`；反向距离必须从翻转后的 mask 重新计算，不能把正向 gap 简单翻转后直接当作反向证据距离。有效观测的 decay 应为中性，缺失帧才随 gap 增大而衰减。

实现约束：采用 `gamma = exp(-ReLU(phi(delta)))` 的 UniTraj-style 形式，但必须通过结构或初始化明确保证 `phi(0)=0`，不能仅凭“最后线性层无 bias”作此推论；有效观测的 `delta=0` 才能严格得到 `gamma=1`。只用历史 mask 派生 `delta`，禁止读取未来轨迹。U0 需要验证有效帧输入与 M0 完全一致；U1 需要分别验证正向/反向分支在各自全有效方向上保持中性。若为数值稳定性增加 clamp，必须固定上下界并在结果中记录，不能悄悄改成无界的全局尺度门控。

建议把 UniTraj 借鉴拆成两个有明确归因的候选：

| 候选 | 新增机制 | 目的 | 定位 |
|---|---|---|---|
| `U0` M0-UniDecay | 保持 M0 单向 temporal Mamba；只使用正向 `x_gap_steps` 做通道级 decay | 先判断 decay 本身是否有用，排除额外双向容量和特征拼接解释 | 首轮 borrowed control |
| `U1` M0-BTS-decay | 两个独立 temporal Mamba stack，正反向各用自己的 decay，输出翻回后相加 | 判断 UniTraj 式双栈与方向特异性 decay 是否在 U0 之外提供收益 | 仅在 U0/cheap decay 留下高缺失证据后执行 |

由于当前 M0 主链是单向 Mamba，U0 只是 UniTraj decay 的单向隔离对照，不应称为完整的 direction-specific bidirectional method；只有 U1 才同时检验正/反两侧证据。另设 `M0-bimamba` 只能作为 DeMo/Vim 层内双向结构对照，不能当作 UniTraj 方法的等价实现。

这条借鉴线不引入：

- UniTraj 的 Future Encoder、CVAE latent 和 decoder；
- GSM/mask head token；
- 全局 State Query 时间基底替换；
- 额外的辅助重建目标。

这些部件会分别改变 decoder、空间 token 语义或训练目标，不能与 temporal decay 同轮加入。若 U1 增益只来自参数量，应增加参数量匹配的 M0 control；所有 U0/U1 结果必须与 M0 使用同一 backbone 初始 state。

实验解释边界：U0/U1 只能证明或否定 UniTraj-inspired decay/双栈 control 是否有用，不能直接作为本文原创点。只有在其基础上进一步证明“观测更新（observed update）与缺口传播（gap propagation）分离”或“可靠性条件化未来分布”带来独立收益，才进入本文模型机制的创新候选。

借鉴来源与术语边界：Sports-Traj/UniTraj 论文将相关设计称为 **Bidirectional Temporal Mamba（BTM）** 与 **Bidirectional Temporal Scaled（BTS）**；本文只把 BTM/BTS 作为外部 borrowed control，不把其双向 Mamba、mask scaling 或 GSM 重新包装为原创。当前 U0 是对 BTS-style decay 的单向隔离，U1 才是对 BTM+BTS 组合的近似复现实验，二者都应在结果表和论文中单独标注 borrowed。

参考：Yi Xu and Yun Fu, *Sports-Traj: A Unified Trajectory Generation Model for Multi-Agent Movement in Sports*, ICLR 2025, arXiv:2405.17680, OpenReview: 9aTZf71D。

## 7. 不能直接包装成创新的内容

以下内容只能作为对照或实现基础：

- 简单 Clean+Easy+Hard `ConcatDataset`；
- 普通 Easy+Hard 混合训练；
- 仅按 missing count 做 oversampling；
- 直接加入 `valid_mask`；
- Mamba 或双向 Mamba 本身；
- DeMo 原有 Mode/State 解耦；
- 简单拼接 gap feature；
- 普通 mask-aware pooling；
- 只报告 minADE/minFDE 的整体平均。

创新必须来自：

```text
新的问题定义
或
新的证据空间覆盖机制
或
对状态传播/预测可靠性的机制性建模
```

## 8. 推荐执行顺序

```text
Step 1  完成当前 P2-B：Easy+Hard Mixed baseline（已完成）
        ↓
Step 2  补齐 Clean/Easy/Hard 交叉 zero-shot（已完成）
        ↓
Step 3  severity-balanced 与 evidence-balanced training screening（已完成；2026-09-24 裁定不采用为主线，保留为 Benchmark 候选）
        ↓
Step 4  尾部诊断审计：基于已有 artifacts 分层 missing=6/7、valid_count=1、长 gap
        ↓
Step 5  做 P3-A：GRU-D-style decay control（最便宜的时间衰减对照）
        ↓
Step 6  做 U0：M0-UniDecay（UniTraj borrowed control，保持 M0 单向主链）
        ├─ U0 无高缺失信号：跳过 U1，进入 evidence-gated state
        └─ U0 留下稳定高缺失信号：做 U1 M0-BTS-decay（只作结构敏感性对照）
        ↓
Step 7  若上述 cheap/borrowed controls 仍不能解释高缺失失败，进入 evidence-gated state
        ↓
Step 8  再进入 reliability-conditioned decoder
        ↓
Step 9  最后考虑 reliability-synchronized social context
```

### 8.1 UniTraj 借鉴线的独立实验接口

U0/U1 不作为连续叠加的“累计版本”，而是从同一个 M0 初始 state 分别启动的配对候选：

| 版本 | 历史 temporal encoder | M0 Scene Transformer / TimeDecoder | 实验问题 |
|---|---|---|---|
| M0 | 单向 Mamba | 保持 | 当前基线 |
| P3-A | 单向 Mamba + generic decay | 保持 | 时间衰减本身能否解释收益 |
| U0 | 单向 Mamba + UniTraj-inspired `x_gap_steps` decay | 保持 | UniTraj 的 decay 是否优于 generic decay |
| U1 | forward/backward 独立 Mamba + 各自 gap decay | 保持 | 双侧证据是否在 U0 之外提供收益 |
| P3-B | observed-update / gap-propagation state gate | 保持 | 是否需要改变缺失帧的状态写入规则 |

U0/U1 首轮只在 TrajImpute direct 上验证；Clean/完整历史评估时由全有效 mask 派生零 gap，使 decay 分支严格保持中性。U1 的反向 gap 从翻转后的历史 mask 重新计算，不读取未来轨迹。U1 必须同时报告参数量/吞吐，并加入参数量匹配的 M0 control；不能把容量增加解释成缺失机制收益。

U1 若执行，比较至少包括 `M0`、`U0`、`U1`；若需要区分 DeMo/Vim 层内双向结构，再另列 `M0-bimamba`，不与 U1 合并为一个“UniTraj”版本。所有候选固定 M0 的 decoder、loss、K、checkpoint monitor、数据协议和训练预算；每个候选从配对的 M0 backbone state 启动，不从 U0 checkpoint 继续训练。

每一步只改变一个主要因素。数据协议、采样策略和模型结构不能在同一轮同时变化，否则无法判断收益来源。

## 9. 当前 Go / Conditional Go / No-Go 判断

### Conditional Go（暂缓，Benchmark 候选）：证据覆盖感知训练

2026-09-24 裁定：severity-balanced 与 evidence-balanced 的五场景 screening 已完成，两者相对 natural Mixed 的收益处于单种子波动带内，不采用为主线；该线索暂缓，与「独立 seed + 高缺失尾部 + unseen-pattern 验证」晋级门槛一起保留，待后续 Benchmark 优化时重新评估。

进入条件（重新启用时）：

- P2-B 已完成；
- naive Mixed 的结果已量化：与 Hard-specific training 整体接近，但尚未形成稳定优势；
- Clean/Easy/Hard 交叉 zero-shot 已补齐；
- 能构造不泄漏的 evidence bins；
- 有 unseen-pattern 测试方案。

晋级条件：

- 优于 natural concat 和 difficulty-balanced；
- 不牺牲 Clean；
- 多场景方向一致；
- 高缺失 MR/FDE@1 有改善；
- unseen-pattern 仍有收益。

### Conditional Go（screening only）：UniTraj borrowed temporal controls

进入条件：

- P3-A generic decay control 已按相同预算完成，或已明确其首轮结果不会与 U0 混淆；
- U0/U1 与 M0 使用同一 backbone 初始 state、decoder、loss、checkpoint rule 和 direct 数据协议；
- `x_gap_steps` 的有效帧中性、缺失帧单调增加和反向 gap 语义已通过单元测试；
- 结果至少按 `valid_count`、`anchor_lag`、`forecast_gap`、`max_missing_run` 和缺失模式分层。

U0/U1 的判胜条件：

- 高缺失尾部（至少 `valid_count<=2` 或官方 Hard `missing=6/7`）的 MR、FDE@1 或 b-minFDE20 有稳定改善；
- minADE20/minFDE20 的改善不以 ADE@1/FDE@1、MR 或 coverage 明显恶化为代价；
- Clean/all-valid 组保持预注册容忍度内的等价或不回归；
- 五场景宏平均与微平均方向不出现未解释的冲突；
- U1 相对 U0 的收益在参数量匹配 control 后仍存在，才可解释为双侧证据，而不是容量增加。

任何以下情况都停止 U1 或不把该线晋级为模型创新：

- U0 不超过 generic decay 或只改善单一场景；
- 只改善 best-of-K 而 top-1/MR 明显恶化；
- all-valid/m=0 发生回归；
- U1 的增益在参数量匹配 control 后消失；
- U1 只验证了双向扫描有效，未显示方向性 decay 的独立作用。

当前定位：**Conditional Go，且仅作为 borrowed control 线**。UniTraj/Sports-Traj 的双向衰减机制必须引用并明确标注借鉴；U0/U1 的正结果不能直接写成本文原创贡献。若该线通过，后续论文主张仍应转向“观测更新—缺口传播分离”或“可靠性条件化未来分布”的独立机制。


### Conditional Go：多维缺失基准

进入条件：

- 能明确新增缺失模式与官方 Easy/Hard 的差异；
- 完成原始轨迹级 split 隔离；
- 提供可复现 mask metadata。

如果只是重新打包 Clean/Easy/Hard，则降级为实验协议，不作为数据集创新。

### Watch：curriculum learning

需要先证明静态 evidence-balanced 不足，否则 curriculum 只是额外复杂度。

### No-Go：单纯 Clean+Easy+Hard concat 作为论文主创新

它是必要 baseline，但不足以支撑强创新声明。

## 10. 当前论文定位的最稳妥表述

> 现有无插补轨迹预测方法通常将缺失处理为输入扰动，或仅按缺失帧数量进行训练和评测，未充分考虑历史证据的数量、时效性、连续性及其组合模式。本文首先建立多维缺失证据空间，并提出证据覆盖感知训练策略，使模型在训练阶段系统暴露于不同质量的历史条件，从而提升对未见缺失程度和缺失模式的泛化能力。进一步地，针对证据不足时的状态过时和预测过度自信问题，设计证据感知状态传播与可靠性条件化多模态解码。

这段表述中：

- “多维缺失证据空间”是问题与评测基础；
- “证据覆盖感知训练”是训练层主创新；
- “状态传播 + 可靠性解码”是待验证的模型层核心创新；
- 不把 DeMo 原有结构或普通混合训练冒充原创。

## 11. 仍需补充的证据

在正式定稿或投稿前，还需要：

1. 构造至少一种 unseen missingness pattern test（Benchmark 阶段执行）；
2. 明确 evidence bins 和采样比例，并在看测试结果前冻结；
3. 与近期 missing-history、irregular-observation、robust trajectory forecasting 和 curriculum/robust training 工作做撞车检查；
4. 对候选模型执行 Clean、Easy、Hard 三环境与高缺失尾部联合验收；
5. 完成 UniTraj borrowed control 的实现审计与 screening：验证 U0/U1 的 mask-only gap 语义、有效帧中性、invalid-coordinate perturbation 不变性、配对初始化、参数量/吞吐和五指标分层结果；U1 仅在 U0/cheap decay 留下稳定高缺失信号后执行；
6. 对 BTM/BTS 与近期 bidirectional/time-decay missing-history 方法做撞车检查，明确论文中“借鉴机制”和“本文可主张机制”的边界；
7. 至少增加多种子确认，避免单种子或单场景结论（Clean 已有 2024/2025 双种子，见实验总汇总 §1.1）。

在这些证据完成前，最准确的说法是：

> **该方向具有清晰的问题依据和可验证的创新假设，但创新有效性仍处于 Conditional Go，而不是已经证明成立。**
