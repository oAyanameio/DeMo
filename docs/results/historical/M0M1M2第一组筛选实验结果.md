## 5. 结论

1. **M1（逐时间步缺失特征）无效且有害**：五折中 4 折恶化（ETH +0.18、UNIV +0.09 最重），b-minFDE6 显著变差；选点普遍偏早（best_ep 22/25/30/47/79 vs M0 的 42/58/63/88/88），训练不稳。
2. **M2（历史摘要）能部分救回 M1 的损失，但回不到 M0 水平**：M2−M1 四指标全改善（−3.5% ~ −14.5%）但均不显著；M2−M0 仍 +3.0%。
3. **首筛结论（random_fixed4_ng）**：浅层"加输入通道"式缺失感知（M1/M2）不产生增益。M3/M4（State/Mode Query 条件化解码器）未参与本轮，不在此结论范围。
4. 零样本→训练适应对比：fixed4_ng 零样本 bi 1.6700 → M0 训练适应 0.7178（恢复 57%）；v3 无保护训练适应 0.7178 vs v2 有保护 0.6189 仍差 16%——无保护协议约有 0.10 minFDE6 的不可适应损失。
5. M0 best_ep 分散（42–88）无早停异常；M1 的恶化与选点偏早同现，提示 4 个新输入通道在 50% 散布缺失下是噪声源。
6. 对照参考（统一 K=6，见[缺失历史实验总汇总](缺失历史实验总汇总.md)）：MoFlow K=6 零样本 complete 0.6656 / block4 1.3249 / rate50 1.3739；DeMo bi 零样本 fixed4_ng 1.6700。同条件下 DeMo 训练适应 0.7178 领先零样本对照约 46%（协议优势，论文需分开表述）。
