## M2'：社会证据补偿的当前设计决策

本节只记录后续有效设计规则，不保留已放弃运行的过程记录或结果。

**实现状态（2026-09-15）**：M2-v1 门控版已落地并通过全部验证（单测 10/10 + 全仓回归 103/103 + 单场景 1-epoch smoke 全链）：

- 门控公式：`gate = focal_missing_ratio × neighbor_reliability`（样本级；无真实邻居记 0），残差 `focal + gate·social_scale·proj(attn_out)`，`social_scale` 零初始化并在 `initialize_weights()` 末尾重申
- 无效帧占位坐标乘 token_valid 置零后才进 token 构造
- 提交：51279fe（门控修正）+ 2ca534a（官方口径恢复）
- **正式轮在跑**：`outputs/trajimpute_retrain_m2v2/`，Easy 五场景→Hard 五场景（GPU3 串行，seed 2024、K=20、EP100、官方口径选点/评估），2026-09-15 16:14 启动；Clean 五折待空卡插入。三环境齐后按门槛裁定。

### 科学假设边界

- 目标：当 focal 历史证据缺失时，利用时间对齐的邻居观测提供补充上下文；不做历史轨迹插补，不输出重建历史。
- 数据事实：TrajImpute Easy/Hard 中邻居也可能缺失，不能假设邻居恒完整；邻居有效性必须成为社会证据的显式条件。
- M2' 从 **M0-uni** 单独出发，不叠加 B1 运动特征、M1' evidence clock、新损失或 decoder 改造。

### 推荐的最小实现

```text
M2-v1 = M0-uni
       + 邻居相对位置/时间/有效位 token
       + focal_missing_ratio × neighbor_reliability 门控残差
```

残差形式固定为：

```text
focal_new = focal_old + gate × social_scale × social_proj(attn_out)
gate = focal_missing_ratio × neighbor_reliability
```

其中 `social_scale` 零初始化；focal 无缺失或邻居无有效 token 时，社会残差必须严格为零。padding actor 和无效邻居帧不得参与 attention。

### 必须先通过的验证

1. 同一实例的零初始化等价性：M2-v1 与 M0 输出 `max_abs_diff < 1e-5`。
2. 完整 focal 历史：社会残差严格为零，不能扰动 Clean 或 Easy `missing=0`。
3. 邻居全无效/全 padding：社会残差严格为零且无 NaN/Inf。
4. focal 缺失且存在有效邻居：社会分支可获得非零梯度。
5. 选点/评估口径（2026-09-15 终裁）：**沿用 DeMo 官方组合**——`val_minFDE20`（基础分支）选点，测试输出优先 refine 分支 `new_y_hat/new_pi`（Hybrid Coupling 为论文最终输出）。曾短暂改为基础分支全链路（方案 A）后撤销：官方 test_step 即为此组合，全部既有基线与对比表均按此口径，不再变更。
6. 先做单场景完整 smoke，再做 Clean、Easy、Hard 三环境正式矩阵；所有表同时报告 ADE/FDE，并按缺失等级和邻居可靠性分组。

### 后续扩展顺序

只有 M2-v1 通过完整历史安全门槛并在高缺失组显示机制信号后，才允许增加邻居速度、相对速度或接近速度；禁止在第一版同时加入运动特征、损失变化和 decoder 改造。

## 迭代与基线铁律（2026-09-13 起适用所有迭代模型）

- **三环境强制**：每个迭代模型（B1/M2'/M3'/M4'/A 系列等）必须完整跑 Clean（原始 ETH/UCY、MoFlow 官方 LOO 数据）+ Easy-direct + Hard-direct 三环境，缺一不裁定
- **滚动基线**：任一迭代在主指标上成为最优后，基线即刻更新为该模型，后续所有迭代从新基线出发、对照表以新基线为零点
- 当前基线：M0（Clean 0.232/0.389 ｜ Easy 0.245/0.399 ｜ Hard 0.432/0.640）
