## P0：主基线三环境汇总（2026-09-13）

- Clean = 原始 ETH/UCY 零篡改直接训练+测试（经典完整历史预测，MoFlow 官方 LOO 数据、Social-GAN 划分）；Easy/Hard-direct = TrajImpute 官方 release 五场景
- **本文 Clean 基线 = M0 0.232/0.389**（K=20、val_minFDE20 选点，2026-08-28 轮，见[完整数据基线对比](完整数据基线对比.md)）；外部参照 MoFlow (CVPR'25) 0.202/0.322、TrajImpute (NeurIPS'24) Table 3 Clean 行六基线

| 环境 | M0（本文） | 口径 | 外部参照 |
|---|---|---|---|
| Clean | **0.232/0.389** | 原始 ETH/UCY 零篡改，MoFlow 官方 LOO 数据（8/28 轮） | MoFlow 0.202/0.322；TrajImpute Tab.3 六基线 0.21~0.24/0.34~0.38 |
| Easy-direct | **0.245/0.399** | TrajImpute 官方 release，五场景宏平均 | MoFlow-direct 0.265/0.406；impute 最优 LBEBM-ET 0.232/0.376 |
| Hard-direct | **0.432/0.640** | 同上 | MoFlow-direct 0.475/0.679；impute 仅 EQmotion 0.446/0.612 更优 |

Easy：direct 口径内 FDE/ADE 双第一，超 5/6 impute 基线；Hard：FDE direct 第一、ADE 全场最优（含 impute）；impute 基线在 Hard 上 5/6 崩溃（LBEBM 0.376→1.448）而 direct 退化平缓（0.399→0.640，×1.61 vs MoFlow ×1.67）。

> 注：Clean 基线（8/28 轮）与现主链存在两处代码差（others_reg_loss padding 修复、选点指标 val_new_minFDE20 vs val_minFDE20——分别对应 refine/mode 分支输出），结构同构、结论可用；如需绝对同代码可重跑五场景（~8h）。

## 迭代与基线铁律（2026-09-13 起适用所有迭代模型）

- **三环境强制**：每个迭代模型（E1 及后续系列）必须完整跑 Clean（原始 ETH/UCY、MoFlow 官方 LOO 数据）+ Easy-direct + Hard-direct 三环境，缺一不裁定
- **滚动基线**：任一迭代在主指标上成为最优后，基线即刻更新为该模型，后续所有迭代从新基线出发、对照表以新基线为零点
- 当前基线：M0（Clean 0.232/0.389 ｜ Easy 0.245/0.399 ｜ Hard 0.432/0.640）
