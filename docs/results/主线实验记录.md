- **本文 Clean 基线 = M0 0.232/0.389**（K=20、val_minFDE20 选点，2026-08-28 轮，见[完整数据基线](完整数据基线对比.md)）。

| 环境 | M0（本模型） | 口径 | 外部参照 |

## 迭代与基线铁律（2026-09-13 起适用所有迭代模型）

- **三环境强制**：每个迭代模型（E1 及后续系列）必须完整跑 Clean（原始 ETH/UCY）+ Easy-direct + Hard-direct 三环境，缺一不裁定
- **滚动基线**：任一迭代在主指标上成为最优后，基线即刻更新为该模型，后续所有迭代从新基线出发、对照表以新基线为零点
- 当前基线：M0（Clean 0.232/0.389 ｜ Easy 0.245/0.399 ｜ Hard 0.432/0.640）

## 口径约束（全阶段适用）

- **表格铁律（2026-09-13）：所有实验表必须同时列出 minADE 与 minFDE**
- direct 与 impute 口径不并表；train_adapt 与 zero-shot 分开报告
- 每版本单变量增量，共享 M0-uni 骨干与优化配置；主指标族 minFDE20 + b-minFDE20 + MR
- 阶段定义与验收门槛见《[选题](../research/选题.md)》§八
- **配对初始化纪律（2026-09-17 起）**：迭代模型与基线的对照必须共享同一初始 backbone state（生成 init ckpt 双方显式加载），杜绝构造分支导致的 RNG 流分叉；单种子对比尤其如此
- **取数陷阱**：同场景 Easy/Hard 的 M0 结果目录同名仅难度段不同，跨难度误取会伪造大幅提升/劣化；引用前核对 difficulty 字段
- **指标分裂检查（2026-09-17 起）**：top-1（ADE@1/FDE@1）与 best-of-K（minADE/minFDE）可能反向分裂——mode 集中度提升会推高 MR；迭代判负/判胜必须五指标齐看，MR 明显牺牲构成否决

## C1-A：last-valid readout 对照（2026-09-25）

本轮结果见《[C1-A 与 M0 对照结果](C1-A与M0对照结果.md)》。C1-A 仅将历史摘要读取从固定末帧改为每个 actor 的最后有效帧；Easy/Hard 各自五场景 train-adapt，seed=2024、K=20、100 epochs、`val_minFDE20` 选点，共 20/20 个评估产物完整。

| 训练 → 测试 | M0 minADE20/minFDE20/MR | C1-A minADE20/minFDE20/MR | 裁定 |
|---|---|---|---|
| Easy → Easy | 0.2361 / 0.3829 / 0.0250 | 0.2538 / 0.4204 / 0.0397 | 回归 |
| Hard → Hard | 0.4664 / 0.6968 / 0.0879 | **0.4355 / 0.6538 / 0.0755** | 正向 control |

**一句话结论**：C1-A 只在 Hard train-adapt 上呈现五指标正向，Easy 上出现回归；分组归因显示 Hard 收益不集中于末端缺失或 valid_count=1，因此保留 C1-A 为 control，转向 observed-write / gap-propagation。

## C3：observed-write / gap-propagation（2026-09-25）

- 状态：首版实现、机制测试与 Hard 五场景 screening 已完成，结果见《[C3 与 M0、C1-A 对照结果](C3与M0_C1-A对照结果.md)》。
- 唯一新增机制：历史 token 先经过显式 evidence state；无效帧只执行 gap-conditioned propagation，有效帧才执行 observation write。
- 原 4 层单向 Mamba、Scene Transformer、decoder、loss、K=20 和 `val_minFDE20` 选点保持不变。
- C3 使用固定末端 readout 读取传播到预测起点的最终状态；C1-A 的 last-valid readout 作为独立 control 保留，不与 C3 混合。
- 新状态通过 zero-initialized residual 接入，初始化时与 M0 输出位级一致；共享 backbone 参数及构造后的 RNG 状态也与 M0 位级一致。
- 已验证：invalid frame observation write 为零、占位 token 扰动不影响状态、gap 按真实 elapsed time 传播且不重复累计、状态内部各分支可获得梯度。

- Hard screening 结果：C3 相对 M0 的五场景宏平均 minADE20/minFDE20/ADE@1/FDE@1/MR 分别改善 5.16%/6.23%/1.19%/0.84%/11.11%，但相对当前最强 control C1-A 未形成稳定优势；`missing=7`/`valid_count=1` 区间仍出现 top-1 和 MR 回归。

**结论边界**：C3 已证明相对 M0 存在正向 screening 信号，但尚未证明 observed-write 具有独立增量，也不能写成已验证论文创新。下一步先完成 C2 gap-only control，再决定是否进入 C4 reliability-conditioned mode。

## 后续模块候选（2026-09-26）

当前不继续堆叠模块，按以下顺序推进：

1. **C2：Freshness-aware gap decay**：作为 borrowed control，验证 `x_gap_steps` 的时间衰减是否已经解释 C3 的主要收益；不单独包装为原创。
2. **C3：Observation-Selective Mamba**：在现有 wrapper 基础上继续核对 Mamba 内部 write path；只有缺失帧真正不能写入时序状态，才能把它称为 evidence-gated state，而不是 feature residual。
3. **C4：Evidence-conditioned mode**：将 `valid_count`、`anchor_lag`、`forecast_gap`、最长缺口和 heading degeneracy 等输入证据条件化到 mode query/logit，重点看 high-missing 的 ADE@1/FDE@1/MR 与 b-minFDE20。
4. **C5：Evidence-conditioned scale**：在 C4 通过后再调节 `scal/scal_new`，增加 coverage、calibration、Energy Score 和连续性诊断。
5. **C6/C7/C8**：仅在单流状态—分布主线通过后，依次考虑 evidence–motion dual-stream SSM、证据自适应社会补偿和潜空间运动原型先验。

统一包装动机：**可用观测证据的数量、时效性和连续性变化，应同时改变历史状态传播与未来多模态分布，而不是只改变输入 token。**

这些模块均属于候选路线；在 C2 对照、配对初始化、五指标与分组结果、多种子和 unseen-pattern 验证完成前，不写入论文已验证贡献。
