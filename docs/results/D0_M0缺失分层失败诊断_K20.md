# D0/P0：M0 缺失分层失败诊断

> **执行状态**：完成
>
> **数据范围**：TrajImpute 官方 release，M0-current，Easy/Hard direct，五场景，K=20，seed=2024。
>
> **输入产物**：`outputs/trajimpute_retrain_uni/**/eval/**/results.json` 与官方 test pkl。
>
> **本轮性质**：只读分组分析；不重训、不修改模型、不修改原始结果 JSON。

---

## 1. 任务与口径

本轮回答四个问题：

1. M0 的退化是否随缺失帧数单调增加；
2. 性能是否与最后有效观测位置（`anchor_lag` / `forecast_gap`）相关；
3. 连续缺口是否比同等缺失数量的散点缺失更危险；
4. 高缺失时退化主要出现在 best-of-K、top-1 mode，还是 MR/概率质量。

结果按五场景分别训练的 M0 产物进行分组。Easy 与 Hard 是不同 difficulty 的 train-adapt 模型，不能把 Easy m=4 与 Hard m=4 解释为同一 checkpoint 的严格 paired degradation；它们用于描述两套训练分布下的分层行为。zero-shot 与同一原始轨迹的严格配对比较仍需单独实验。

指标定义：

- `minADE20/minFDE20`：20 个 mode 的 best-of-K 误差；
- `ADE@1/FDE@1`：最高概率 mode 的误差；
- `MR`：20 个 mode 的终点误差全部超过 2.0 米；
- 宏平均：五场景等权；
- 微平均：所有 focal sample 等权。

`max gap` 是每条历史 mask 的最长连续缺失长度；它不是模型输入字段，而是本轮从官方 test mask 派生的诊断变量。

### 3.1 关键变化

Easy train-adapt 内部，m=0→m=4：

- minADE20：0.227→0.268，约 **+18.2%**；
- minFDE20：0.378→0.420，约 **+11.1%**；
- MR：0.024→0.037，约 **+55.5%**。

Hard train-adapt 内部，m=4→m=7：

- minADE20：0.254→0.886，约 **+249.0%**；
- minFDE20：0.406→1.271，约 **+213.3%**；
- ADE@1：0.597→3.138，约 **+425.9%**；
- FDE@1：1.168→4.752，约 **+306.7%**；
- MR：0.030→0.187，约 **+520.7%**。

Hard m=7 是明确的失效尾部：只剩 1 个有效历史观测，平均 `anchor_lag=3.48`，平均 `forecast_gap=4.48`，最高概率 mode 的误差远高于 best-of-K 误差。

## 4. 关键诊断一：高缺失时首先是 top-1/可靠性崩溃

Hard m=7 的结果：

```text
minFDE20 = 1.271
FDE@1    = 4.752
MR       = 0.187
```

这说明模型并非完全无法生成接近 GT 的候选；20 个候选中仍可能有一条相对接近，但最高概率 mode 常常选错。换句话说，主要问题不是只有候选轨迹几何误差，而是：

```text
历史证据不足
    -> 多个未来分支难以区分
    -> mode probability 仍然过度确定
    -> top-1 和 MR 退化远快于 best-of-K
```

因此后续方法不能只追求 minFDE20。P3/P4 必须把以下指标作为共同门槛：

- minADE20/minFDE20；
- ADE@1/FDE@1；
- MR；
- b-minFDE20；
- 高缺失分组表现。

---

## 5. 关键诊断二：anchor lag 与 valid count 是比 missing count 更直接的机制变量

从 Easy m=0→m=4，平均 anchor lag 从 0 增加到 0.814；Hard m=4→m=7，平均 anchor lag 从 0.810 增加到 3.480。

同时，Hard 的有效历史观测数从：

```text
m=4: 4 个
m=5: 3 个
m=6: 2 个
m=7: 1 个
```

这表明“缺失 4 帧”不是统一难度：

- 有些样本最后有效帧仍接近历史末端；
- 有些样本最后有效观测很早，预测实际上变成长距离外推。

后续模型和实验应把以下变量作为一等诊断变量：

```text
valid_count
last_valid_idx
anchor_lag
forecast_gap
max_missing_run
```

而不是只按 `missing_count` 汇总。

---

## 6. 关键诊断三：Easy/Hard 不能直接当作同一模型退化曲线

Easy 与 Hard 的 m=4 结果如下：

| difficulty | minADE20 | minFDE20 | ADE@1 | FDE@1 | MR |
|---|---:|---:|---:|---:|---:|
| Easy m=4 | 0.268 | 0.420 | 0.613 | 1.165 | 0.037 |
| Hard m=4 | 0.254 | 0.406 | 0.597 | 1.168 | 0.030 |

两套结果接近但并非相同。原因是 Easy 和 Hard 使用不同的训练/验证分布和不同 checkpoint，因此不能直接写成“Hard 比 Easy 更难”或“同一模型从 Easy m=4 退化到 Hard m=4”。

后续必须增加：

```text
Easy train -> Easy test
Easy train -> Hard test
Hard train -> Hard test
Mixed train -> Easy test
Mixed train -> Hard test
```

只有这样才能分离：

- 测试缺失程度效应；
- 训练分布适应效应；
- checkpoint/训练动力学差异。

## 7. 关键诊断四：当前 release 的 test 块适合分层，但不等于独立样本

每个 difficulty 的 test 由相同底层测试轨迹按不同 missing count 扩展而来。不同缺失块共享原始未来轨迹；actor-centric focal 样本还共享场景上下文。

因此：

- 当前分组均值适合做退化曲线；
- 不应把所有 focal sample 当作完全独立样本做显著性结论；
- 需要对同一原始轨迹的不同缺失块做 paired comparison；
- 置信区间和统计检验应至少按 scene / original track 聚类。

本轮完成的是整体分组诊断，严格 paired degradation 需要在评估器中保留官方 test block 的 source track identity 后另行生成。

## 8. P0/D0 裁定

### 已确认

1. M0 退化确实随高缺失和有效观测减少而加剧；
2. m=7/valid_count=1 是最明确的失败尾部；
3. top-1/MR 概率质量退化远快于 best-of-K；
4. anchor lag/forecast gap 是必须显式分层的机制变量；
5. Easy/Hard train-adapt 结果不能替代 zero-shot 泛化实验；
6. 不能再用简单输入特征拼接作为默认改进假设。

### 尚未确认

- 直接把 gap 输入模型是否比 M0 更好；
- GRU-D-style decay 是否能解释高缺失改善；
- evidence-gated temporal state 是否优于简单 decay；
- reliability-conditioned decoder 是否能降低 top-1/MR 退化；
- 同一原始轨迹的 paired degradation 是否支持单调失败曲线。

### 下一步固定顺序

```text
P2：Easy/Hard/Mixed 训练分布矩阵
  ↓
P3-A：GRU-D-style decay control
  ↓
P3-B：single-state evidence-gated temporal state
  ↓
P4：reliability-conditioned decoder
```

不重复执行已判负的 S2 pooling，不重复执行 M1' 全局 evidence-clock 重参数化。
