## 评估协议

- 数据：TrajImpute 官方 release（ETH/UCY 五场景）。划分实测为经典 LOO 结构：每场景 train=其余四场景聚合，test=经典 LOO 测试集×5 按缺失等级复制；Easy = 8 帧历史缺 0~4 帧，Hard = 缺 4~7 帧
- **直接预测（direct）**：缺失 NaN 不插补，掩码+有效间隔直接输入模型
- **DeMo-direct（本文）**：M0-current（掩码拼输入内置，无缺失感知模块），每场景独立重训（EP100、K=20、seed 2024）
- **MoFlow-direct（外部基线重训）**：官方划分重训（EP150、K=20、seed 42），缺失步用训练集逐通道均值占位，锚点=最后可见帧；easy/hard 各训一臂
- **论文基线**（NeurIPS 2024 D&B Table 3：LBEBM-ET / SGCN-ET / GPGraph / GraphTern / EQmotion / TUTR）：impute 口径（SAITS 插补后训练+测试），与 direct 混合排名（口径列区分），数字引用 †
- 指标：minADE20 / minFDE20，米制，12 帧全程

## 读法边界

- 排名规则（2026-09-13 裁定）：TrajImpute 数据集下所有对比表统一混合排序，direct 与 impute 不分区；口径差异以"口径"列与 † 标注保留（†=引用 TrajImpute 论文 Table 3 数字；impute 输入经 SAITS 插补，信息量高于 direct）
- 混排下本文位置：**Easy 第 2（0.399，仅次于 LBEBM-ET 0.376，超其余 5 impute + MoFlow-direct）；Hard 第 2（0.640，仅次于 EQmotion 0.612），ADE 均值 0.432 全场最佳**
- direct 同口径内：Easy/Hard DeMo 均优于 MoFlow-direct（0.399 vs 0.406；0.640 vs 0.679）
- DeMo 为单种子 M0-current 裸基线，是后续所有方法增量的参照零点；确认性种子未跑
- Clean：本文基线 = M0 原始干净 ETH/UCY 重训 0.232/0.389（8/28 轮，见[完整数据基线对比](完整数据基线对比.md)）；MoFlow 0.202/0.322、TrajImpute Table 3 Clean 行为外部参照，单列不混写
- 按缺失帧数分组明细见各场景 eval 目录 results.json 的 by_group 字段
- CSV 中的 clean 行来源注意：MoFlow clean 列是 easy-ckpt 在 Easy release 零缺失块上的测试结果（非 clean 训练模型），不可当完整历史真实水平引用
