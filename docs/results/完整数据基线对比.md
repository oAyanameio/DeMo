## 评估协议

- 数据：MoFlow 官方 LOO pkl（同源同划分）。ETH/UCY 五折留一（LOO），8 帧历史 → 12 帧未来，米制；SDD 用 sdd_train/sdd_test.pkl（train/val = 90/10，seed 2024），像素制
- 指标：minADE20 / minFDE20；选点用 val_minFDE20 最优 epoch，test 不参与训练与选点
- 协议对齐已逐项核查：数据划分、时域 8/12、K=20 独立取 min、单位、坐标参考（刚性变换不改 L2）与 MoFlow 官方一致；无数据泄漏（审查记录见 git 历史版附录）
