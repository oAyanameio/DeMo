## 评估协议

- 数据：MoFlow 官方 LOO pkl（同源同划分）。ETH/UCY 五折留一（LOO），8 帧历史 → 12 帧未来，米制；SDD 用 sdd_train/sdd_test.pkl（train/val = 90/10，seed 2024），像素制
- 指标：minADE20 / minFDE20；选点用 val_minFDE20 最优 epoch，test 不参与训练与选点
- 协议对齐已逐项核查：数据划分、时域 8/12、K=20 独立取 min、单位、坐标参考（刚性变换不改 L2）与 MoFlow 官方一致；无数据泄漏（审查记录见 git 历史版附录）
- 单/双向两臂唯一变量为 encoder Mamba 单双向（decoder state Mamba 原版即双向，不受旗标影响）

## 结论

1. **单向稳定优于双向**：ETH/UCY 双向平均差 +5.5%/+6.9%，SDD 差 +18.4%/+28.5%；双向失败模式是泛化（val 打平、test 崩开）。主链编码器已固定单向（2026-09-12 裁定）。
2. **DeMo 距 MoFlow 教师未超越**：ETH/UCY +14.7%/+20.7%，SDD +10.8%/+14.2%。
3. ETH 为最大短板（0.486/0.767 vs 论文 0.40/0.57）；zara2/univ 已贴近论文。
