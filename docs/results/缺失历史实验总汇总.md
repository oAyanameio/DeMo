> 唯一权威汇总，随实验追加。约定（9/3 起）：每组实验完成后，先在会话中做单次汇报，再回填本文档。

## 0. 协议速查

- 模型：DeMo，单向（uni）/ 双向（bi，bimamba），其余超参一致
- 数据：ETH/UCY（每条件 18 万样本）+ SDD（1.2 万），5 折留一法（LOO），种子 2024
- 缺失条件（v1/v2）：帧 0–5 随机遮挡，**帧 6/7 恒可见**（控制变量：隔离缺失效应与锚点重定义）；v1 轻度（12.5%~25%）、v2 高缺失（37.5%~75%）
- 缺失条件（v3_noguard）：候选帧放开到 0–7、每行人 ≥1 可见帧、锚点回退最后可见帧——对齐 TrajImpute/MoFlow 无保护语境。数据已建成并通过验收审计（9/5），训练臂未实施
- 两类口径勿混：**训练适应**（每条件独立训练+同条件测试）、**留出对照**（8 月基线）

验证与解读：
- **管线自检**：Clean-direct 五场景（0.117~0.436 / 0.182~0.605）全部落在官方 Clean 区间（0.11~0.43 / 0.18~0.63）内甚至略优——数据转换、旋转、归一化、模型前向、K=20 聚合全链正确。

## 4. 当前结论（9/5 更新）

1. **完整数据**：双向 = 单向（K=6 口径 s2024 −1.1%；多种子配对 t=+1.17 不显著；K=20 与 SDD 口径单向反优 5%~28%）——双向在完整数据不亏也不赚，且方向因数据集而异
2. **ETH/UCY 训练适应**：8/8 组双向无增益——多种子实测种子噪声 ±5%，§2 全部组间差异（±2% 级）淹没其中
3. **SDD 训练适应**：高缺失下双向占优（−19%~−45%），单向在散布缺失/重缺失崩溃（ep5 早停）
4. **诊断学结论**：单种子数字的组间差异 <±5% 时一律视为噪声（block6 伪象与 uni_s2020 基线波动双重实证）；论文报告必须多种子或明确标注
