SDD 训练适配补充观察：单向在散布缺失（fixed3/fixed4）和重缺失（block6）下崩溃或大幅退化，best_epoch=5 即早停；双向全程平稳（14.4~16.5）。与 ETH/UCY 不同——SDD 上训练适应口径下双向即已占优，可能与 SDD 长观测（20 帧）+小数据量有关。

## 5. 当前结论

1. 完整数据：双向 = 单向（ETH/UCY +2.4%，噪声内）
2. ETH/UCY 训练适应：8/8 组双向无增益（±2% 噪声内）
3. 零样本 + SDD 训练适应：双向单调占优，零样本差距最大（−22%~−44%），缺失越重优势越大
4. 故事线：双向扫描的价值在信息缺失时兑现，完整数据不亏——"免费期权"论证成立
