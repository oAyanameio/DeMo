## 5. 结果 JSON 语义检查

10/10 结果均包含：

- `minADE_K`：20 个 mode 的 best-of-K ADE；
- `minFDE_K`：20 个 mode 的 best-of-K FDE；
- `ADE@1/FDE@1`：最高概率 mode；
- `MR`：20 个 mode 的终点误差均超过 2.0 米才计 miss；
- `by_group`：按 `missing_count` 分组；
- `overall`：focal sample micro-average；
- `n`：测试 focal sample 数量；
- `aggregation`：`micro-average over all focal samples`。

P0A 未发现结果文件把 `minFDE`、top-1 FDE 和 MR 混为同一指标，也未发现 missing count 分组缺失。
