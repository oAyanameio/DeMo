# 采样策略逐场景对照

> M0、K=20、seed=2024；TrajImpute 官方 release；direct prediction，不经过外部插补。两条策略均为五场景独立训练，100 epochs，按 `val_minFDE20` 选点。

## 1. 训练协议

- 场景：`ETH-M / HOTEL-M / UNIV-M / ZARA1-M / ZARA2-M`。
- 测试：Easy（缺失 0–4 帧）与 Hard（缺失 4–7 帧）。
- `severity-balanced`：按 focal `missing_count m=0…7` 做逆频率加权采样。
- `evidence-balanced`：按 evidence bin `E0/E1/E2/E3` 做逆频率加权采样；高等级覆盖低 valid count、长 forecast gap、长缺失连续段和较大 anchor lag。
- 指标：`minADE20`、`minFDE20`、`ADE@1`、`FDE@1`、`MR`。
- 结果口径：宏平均为五场景等权平均；微平均按测试样本数加权。共 20 个评估 JSON，均正常生成。

## 5. 裁定（2026-09-24）

1. 五场景宏平均上 severity-balanced 优于 evidence-balanced：Easy `minFDE20 −5.6%`，Hard `−2.0%`；Hard 的 MR 下降 `6.1%`。
2. 场景层面，severity-balanced 在 Easy 的 minFDE20 赢 4/5 个场景，在 Hard 赢 4/5 个场景；evidence-balanced 仅在 Easy 的 ZARA1-M、Hard 的 HOTEL-M 占优。
3. 相对 natural Mixed，severity-balanced 的 Hard 收益幅度（minFDE20 −0.1%、FDE@1 −0.7%）处于单种子波动带内，且 MR 略差，不支持作为主线训练策略。
4. **裁定**：两种采样策略均不采用为主线，主线回归 M0 / natural Mixed；两者连同「独立 seed + 高缺失尾部 + unseen-pattern 验证」的晋级门槛一起保留，供后续 Benchmark 优化时启用。
