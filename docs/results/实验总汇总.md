# 实验总汇总（2026-09-21）

> 唯一权威总汇总，覆盖 2026-08-27 起已完成实验。每节：协议 → 结果表 → 裁定。
> 当前滚动基线仍为 M0；P2 交叉泛化矩阵已补齐，结果详见《[缺失分布交叉泛化结果](缺失分布交叉泛化结果.md)》。

## 0. 协议速查

- **Clean**：原始 ETH/UCY 完整历史 benchmark，8 帧历史 → 12 帧未来，K=20，五折 LOO，seed 2024。
- **Easy/Hard-direct**：TrajImpute 官方 release，缺失历史直接输入、不经外部插补；Easy=缺失 0–4 帧，Hard=缺失 4–7 帧。
- **Mixed**：Easy+Hard 数据集级 1:1 拼接；训练和验证均使用 Easy+Hard；不是 `missing=0…7` 严格均衡。
- 训练默认：M0、单向 Mamba（`bimamba=false`）、100 epochs、batch size 64、K=20、seed 2024、`val_minFDE20` 选点。
- direct 指标：`minADE20`、`minFDE20`、`ADE@1`、`FDE@1`、`MR`；结果同时保留宏平均、微平均、场景和缺失等级明细。
- direct 与 impute 不混写；train-adapt 与 zero-shot 分开报告。Clean→Easy/Hard 和 Hard→Clean 涉及跨数据协议，单独标注。

## 4. Mixed 结果裁定

1. Easy→Hard zero-shot 明显退化，说明训练分布失配是真实问题；将 Hard 样本纳入训练后，Mixed→Hard 恢复到 Hard→Hard 同一量级。
2. Mixed 与 Hard-specific training 的差距较小：Hard 上几何误差略差、MR 略好；Easy 上指标基本接近，不支持稳定优于 Hard-specific 的结论。
3. 当前 Mixed 应保留为有效的通用训练 baseline/control，不判负；但它只是 Easy+Hard 的 naive dataset-level mixture，不能包装成 evidence-coverage-aware training。
4. `missing=7` / `valid_count=1` 高缺失尾部仍明显退化，简单拼接不能解决低证据和长时间外推问题。
5. Clean→Easy/Hard 显著劣于对应 train-adapt：完整数据训练不能自然获得缺失历史鲁棒性。

## 5. 当前路线

- **已完成**：P0/P0A 产物与失败机制审计、P2-A Easy→Hard、P2-B Mixed→Easy/Hard、Clean→Easy/Hard、Hard→Easy、Hard→Clean。
- **P2 当前裁定**：Mixed 保留为 baseline/control；不直接将其作为创新点。
- **下一步**：先做固定 optimizer budget 与统一 validation selection 的公平 Mixed 对照，再比较 severity-balanced 与 evidence-balanced training；若高缺失尾部仍存在，再进入 P3 evidence-gated temporal state。
- **尚未开始**：P3 正式训练、多种子确认、unseen-pattern test、Clean+Easy+Hard 混合训练。

以上结果为单种子 `2024`；论文主结果仍需统一预算/选点协议并进行多种子确认。
