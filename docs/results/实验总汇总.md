## 8. M2' 当前设计决策（未形成正式结果）

M2' 当前不采用旧的无条件社会残差方案；正式实现前先固定为单变量诊断版本：

```text
M2-v1 = M0-uni
       + 邻居相对位置/时间/有效位 token
       + focal_missing_ratio × neighbor_reliability 门控残差
```

- 从 M0-uni 直接出发，不叠加 B1 运动特征、M1' evidence clock、新损失或 decoder 改造。
- `focal_missing_ratio = focal 缺失帧数 / 8`；`neighbor_reliability = 有效邻居帧 token 数 / 全部邻居帧 token 数`。
- 完整 focal 历史或无有效邻居时，社会残差必须严格为零；padding actor 和无效邻居帧不得参与 attention。
- 训练、选点、评估必须使用同一输出分支；诊断阶段优先统一使用基础 `y_hat/pi` 与 `val_minFDE20`。
- 先做同实例等价性、极端 mask、单场景完整 smoke，再跑 Clean/Easy/Hard；所有结果表同时报告 ADE/FDE，并按缺失等级和邻居可靠性分组。
- 当前没有可用于裁定的 M2 正式结果；M0 继续是滚动基线。
