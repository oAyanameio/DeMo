# 缺失历史证据自适应实验说明

## 实验目的

验证 C4 在 TrajGap-Bench 不完整历史上的综合机制是否优于原始基线 M0：

- observed-write：有效观测写入状态；
- gap propagation：缺失区间按时间间隔传播状态，不把占位值当作观测；
- adaptive anchor：根据历史证据融合末端传播状态与最后有效状态；
- evidence-conditioned decoder：根据证据特征调节未来 mode 查询。

C4 的新增分支保持零初始化，M0 默认路径不变。

## 训练协议

- 数据集：TrajGap（底层读取 TrajImpute 官方 Easy/Hard 文件）
- 训练条件：TrajGap Mixed-train
- 验证条件：TrajGap Mixed-val，单一 `val_minFDE20` 选点
- 采样：`natural`，即 Mixed 数据集自然 shuffle
- 测试条件：TrajGap Mixed-test，单一主结果
- 输入：direct，不做轨迹插补
- 场景：ETH-M、HOTEL-M、UNIV-M、ZARA1-M、ZARA2-M
- seed：2024
- K：20
- batch size：64
- epochs：100
- monitor：`val_minFDE20`
- optimizer 参数：`lr=1e-3`，`weight_decay=1e-4`
- encoder：`bimamba=false`

## 模型设置

C4 使用：

```text
readout_mode=last
evidence_state_mode=integrated
```

M0 对照使用已有 Mixed 训练结果：

```text
readout_mode=last
evidence_state_mode=none
```

M0 不再重复训练，直接复用此前已经完成的 M0 Mixed 结果。五个场景的对照产物分别为：

```text
outputs/p2_mixed_train_seed2024_v3/                  # ETH-M
outputs/p2_mixed_train_seed2024_gpu0_hotel/          # HOTEL-M
outputs/p2_mixed_train_seed2024_gpu3/                # UNIV-M
outputs/p2_mixed_train_seed2024_gpu3_zara1/          # ZARA1-M
outputs/p2_mixed_train_seed2024_gpu0_zara2/          # ZARA2-M
```

已有 M0 结果与当前 C4 使用不同 git revision，但训练/评估协议一致；本实验按既定计划作为已有 Mixed 结果对照，不重新训练 M0，也不将其表述为同一代码状态下的严格 bitwise paired retraining。

## 执行布局

C4 按场景拆分为 5 个独立 runner 并行训练：

| 场景 | GPU | 输出目录 |
|---|---:|---|
| ETH-M | 3 | `outputs/mixed_pair_seed2024_c4_parallel/ETH-M` |
| HOTEL-M | 1 | `outputs/mixed_pair_seed2024_c4_parallel/HOTEL-M` |
| UNIV-M | 2 | `outputs/mixed_pair_seed2024_c4_parallel/UNIV-M` |
| ZARA1-M | 3 | `outputs/mixed_pair_seed2024_c4_parallel/ZARA1-M` |
| ZARA2-M | 1 | `outputs/mixed_pair_seed2024_c4_parallel/ZARA2-M` |

每个场景使用独立 output root，避免并行 runner 之间覆盖 checkpoint、日志或汇总文件。

## 当前状态

C4 的历史 Easy/Hard 分开评估已完成，但不再作为 TrajGap-Bench 主结果。后续正式实验统一使用 TrajGap Mixed-train、Mixed-val 和 Mixed-test；旧 Easy/Hard 结果仅保留为历史诊断，不用于新的主榜比较。
