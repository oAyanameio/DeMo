# TrajImpute 缺失历史直接预测实验路线

> **文档性质**：实验方案，不记录未执行结果。
>
> **研究对象**：M0（原始 DeMo + 有效性掩码拼接）在 TrajImpute 上的缺失历史直接预测，以及围绕其失败机制设计的分阶段改进实验。
>
> **当前原则**：先修正时间锚点与证据读取，再验证缺失状态传播，最后才研究未来分布可靠性与同步社会证据。每一阶段都保留最便宜的强对照，不因复杂模块本身具有解释力就自动推进。

---

## 1. 研究问题与路线边界

### 1.1 研究问题

给定含有缺失历史观测的多行人轨迹，模型不经过独立插补器，直接建模：

```text
可见历史观测 + 缺失掩码 + 观测时间结构 + 社会上下文
    -> 未来 12 帧的多模态轨迹分布
```

重点不是恢复一条唯一的完整历史，而是回答：

1. 缺失帧期间应该如何传播历史状态；
2. 不同行人的观测新鲜度不同，社会信息如何时间对齐；
3. 历史证据减少时，未来多模态分布如何表达可靠性下降；
4. 模型在缺失程度和缺失模式变化时是否稳定。

### 1.2 不在当前主线中的内容

- 不把 DeMo 已有的 Mode/State/Hybrid 解耦重新包装为本文创新；
- 不把 Mamba、双向扫描、普通 mask 拼接本身作为创新；
- 不以完整历史插补质量替代未来预测质量；
- 不同时改变历史编码器、decoder、损失和缺失训练分布后再归因；
- 不把 TrajImpute 论文中的 impute 结果与 direct 结果当作同口径 SOTA；
- 不在未经验证的前一模块上继续叠加后续模块。

最终可主张的方向应当是：**evidence-aware multimodal forecasting（证据感知多模态预测）**，而不是“又一个缺失感知 Mamba”。

## 2. 当前 M0 与已知问题

### 2.1 M0 定义

当前 M0 使用：

- 4 层历史 Mamba，encoder 主链固定单向（`bimamba=false`）；
- actor-level Scene Context Transformer；
- 当前 DeMo `TimeDecoder`，20 个 mode；
- 历史 token 输入：`x_positions_diff`、`x_velocity_diff`、`x_valid_mask`；
- 缺失历史坐标局部变换后用 0 占位，依赖 `x_valid_mask` 区分占位与真实观测；
- 固定从历史编码输出的最后时间位置取 actor 特征；
- 预测时间 query 固定为 `0.4, 0.8, ..., 4.8` 秒；
- 训练目标、decoder、K=20 评估口径保持原始 DeMo 路径。

代码锚点：

```text
src/model/model_forecast.py:140-179
src/model/model_forecast.py:186-213
src/model/layers/time_decoder.py:171-238
src/datamodule/trajimpute_dataset.py:222-268
```

数据适配器已经计算但 M0 历史输入没有显式消费的字段包括：

```text
x_gap_steps             距最近有效观测的间隔
x_anchor_lag_steps      最后有效历史距离窗口末端的距离
x_forecast_gap_steps    最后有效历史到预测起点的间隔
x_last_valid_idx        每个 actor 的最后有效帧
```

### 2.2 冻结的基线结果

当前滚动基线（单种子 `2024`，K=20）：

| 环境 | M0 minADE20 / minFDE20 | 口径 |
|---|---:|---|
| Clean | 0.232 / 0.389 | 原始 ETH/UCY 完整历史 |
| Easy-direct | 0.245 / 0.399 | TrajImpute 官方 Easy，直接预测 |
| Hard-direct | 0.432 / 0.640 | TrajImpute 官方 Hard，直接预测 |

现有五场景分组诊断的宏平均信号：

| 分组 | minADE20 | minFDE20 | MR |
|---|---:|---:|---:|
| Easy，缺失 0 帧 | 0.227 | 0.378 | 0.024 |
| Easy，缺失 4 帧 | 0.268 | 0.420 | 0.037 |
| Hard，缺失 4 帧 | 0.254 | 0.406 | 0.030 |
| Hard，缺失 7 帧 | 0.886 | 1.271 | 0.187 |

诊断含义：Easy 的 m=0→m=4 中，minFDE 约增加 11%，MR 约增加 56%；Hard 的 m=4→m=7 中，minFDE 约增加 213%，MR 约增加 521%。这提示主要失败不只是平均位置误差，而是高缺失下的**未来分布可靠性与时间锚点失配**。

上述分组结果是诊断证据，不是因果结论：当前 Easy、Hard 分别训练，不能把其整体差异直接解释为同一 checkpoint 的 zero-shot 退化。

### 2.3 M0 的主要失败机制

1. 缺失 token 仍参与 Mamba 状态更新；
2. 固定读取最后时间位置，末端缺失时可能读取缺失后的状态；
3. 位移跨缺口但没有把实际 gap 显式输入模型；
4. 最后有效观测不同的 actor 被压成 token 后，社会注意力可能混用不同时间的中心位置；
5. `x_forecast_gap_steps` 没有进入 decoder 的预测时间 query；
6. 缺失结构没有显式进入 mode probability、future scale 和 State Query；
7. 只有一个有效观测时，方向和速度不可辨识，但 M0 没有独立的 reliability 表达；
8. `minADE/minFDE` 的 best-of-K 评价可能掩盖最高概率轨迹和概率校准的退化；
9. Easy/Hard 单独训练，尚未回答训练缺失分布变化下的泛化问题；
10. 官方缺失主要是受控合成缺失，未覆盖完整遮挡、ID switch 和全历史不可见等现实情况。

## 3. 全阶段固定实验协议

### 3.1 数据与任务

- 数据：TrajImpute 官方 release；五场景 `ETH-M / HOTEL-M / UNIV-M / ZARA1-M / ZARA2-M`；
- 历史长度：8 帧；未来长度：12 帧；
- Easy：每条历史缺失 0–4 帧；
- Hard：每条历史缺失 4–7 帧；
- direct：缺失坐标不经外部插补，直接输入预测模型；
- 未来轨迹完整，只用于监督和评估；
- K=20；
- 默认训练：100 epochs、batch size 64、bf16、seed 2024、`val_minFDE20` 选点；
- 每个 scene/difficulty 从头训练，不从另一 difficulty 的 checkpoint 迁移。

当前 runner 的 direct 主线是按场景和 difficulty 分别训练：

```text
scene = 一个 TrajImpute 场景
train/val/test = 该场景对应的官方 pkl
```

因此在论文和结果文档中，在没有额外完成跨场景审计前，不把这条 direct runner 自动称为“经典四训一测 LOO”。如果要研究跨场景泛化，另设专门的 LOO 协议，不与当前 per-scene retrain 混用。

### 3.2 评估指标

**主指标**：

- `minFDE20`；
- `minADE20`。

**必须同时报告的保护指标**：

- `MR`（Miss Rate）；
- `ADE@1 / FDE@1`（最高概率 mode）；
- `b-minFDE20`；
- 五场景结果与最差场景结果。

**后续分布实验增加**：

- Energy Score；
- endpoint coverage / interval coverage；
- mode probability calibration；
- 未来速度、加速度、曲率或转向变化的连续性。

`minFDE20` 只衡量 20 条预测中最接近 GT 的一条，不能单独证明概率分布已校准。新增分布指标前必须固定实现、样本聚合和随机采样规则，不能在测试集上调阈值。

### 3.3 聚合与分组

每个结果同时提供：

1. 五场景宏平均（每个场景等权）；
2. focal sample 微平均（每个样本等权）；
3. 五个场景明细；
4. `missing_count` 分组；
5. `max_gap`、`anchor_lag`、`valid_count`、`heading_degenerate` 分组；
6. 缺失模式分组：随机散点、连续 block、末端缺失、前缀缺失、多段缺口。

TrajImpute test 的不同缺失块共享原始未来轨迹，且 actor-centric 样本之间也共享场景信息。因此显著性分析不能把所有 focal sample 当作完全独立样本；优先使用同一原始轨迹不同缺失块的配对差值，并在场景级别报告均值和方向一致性。

### 3.4 对照与初始化纪律

- 每个候选只改变一个主要因素；
- decoder、K、loss、checkpoint monitor、数据边界保持不变，除非该阶段明确研究它们；
- 新模型与对应 M0 必须共享同一初始 backbone state；
- 新增分支默认关闭，先做输出契约、finite、forward/backward 和 all-valid 等价测试；
- 不以两个独立随机初始化模型的差异作为模块收益；
- 目录名、manifest、resolved config、git revision、seed、difficulty、checkpoint 和结果 JSON 必须完整保留；
- 任何筛选轮都标为 `screening`，不能直接写入最终主表或更新滚动基线。

## 4. 阶段 P0：基线与失败机制审计

### 4.1 目标

不改模型，先确定 M0 的失败究竟来自：

```text
数据/评估口径
    还是
时间锚点
    还是
缺失程度导致的证据不足
    还是
未来分布概率质量退化
```

### 4.2 实验与分析任务

| 编号 | 任务 | 是否改模型 | 输出 |
|---|---|---:|---|
| P0-A | 复核 5 场景 Easy/Hard M0 manifest、resolved config、checkpoint | 否 | 协议审计表 |
| P0-B | 按 missing count 重算 minADE/minFDE/ADE@1/FDE@1/MR | 否 | 分组结果 JSON/CSV |
| P0-C | 按最后有效帧、最长缺口、有效观测数重算 | 否 | 机制分组表 |
| P0-D | 对同一原始轨迹的不同缺失块做配对比较 | 否 | paired degradation |
| P0-E | 检查 invalid-coordinate perturbation、padding isolation、all-valid 输入 | 否 | 单元/真实 batch 验证 |
| P0-F | Easy train→Hard test zero-shot 诊断 | 否 | 训练分布泛化基线 |

### 4.3 必须验证的语义

- 缺失坐标占位值变化但 mask 不变时，模型输出不能变化；
- padding actor 不能改变真实 actor 的输出；
- all-valid 输入必须与 Clean M0 的输入语义一致；
- 最后有效历史点与未来第一步的坐标变换没有泄漏未来；
- `target_diff` 只用于目标/诊断，不参与历史输入；
- test 的重复块与 `missing_count` 分组一致；
- `seq_start_end` 修复后每个 actor 仍属于正确场景组。

### 4.4 P0 晋级门槛

P0 只有在以下条件全部满足后结束：

1. 五场景 Easy/Hard 的结果目录和 manifest 可追溯；
2. 每个分组的样本数与官方 release 结构一致；
3. M0 的 direct evaluator 与训练/测试 checkpoint 口径一致；
4. 已区分宏平均、微平均、train-adapt 和 zero-shot；
5. 至少得到一条可靠的失败曲线：缺失数、anchor lag 或 valid count 与误差/MR 的关系。

若 P0 发现数据或评估口径错误，先修复并重新冻结 M0，不进入 P1。

## 5. 阶段 P1：低风险时间对齐与证据读取

P1 的目标是先修复 M0 最明确、最便宜的问题。P1 的候选不是最终论文创新，首先作为强 baseline 和必要的工程校正。

### 5.1 P1-A：mask-aware pooling

**问题**：M0 固定取最后一个时间位置；末帧缺失时可能读取缺失 token 后的状态。

**候选**：

```text
A0  M0：固定最后时间位置
A1  最后有效帧特征
A2  有效帧 mean pooling
A3  最后有效帧特征 + 有效帧 mean pooling
```

当前代码已有可选 `use_mask_pooling` 路径，但默认关闭；正式候选仍需按本路线完成完整协议。A3 的新增投影应零初始化并在全局初始化后再次确认，保证起步时与 M0 对齐。

**最低测试**：

- 末端缺失、前缀缺失、中间缺口、仅一帧有效；
- `last_idx` gather 无越界；
- padding actor 不进入 pooling；
- all-valid 时结果与 M0 的固定末帧语义可解释对齐。

### 5.2 P1-B：显式 gap feature

**问题**：跨缺口位移和速度变化没有显式附带实际时间间隔。

**新增输入候选**：

```text
per-frame:
    gap_steps / obs_len
    valid_mask

per-actor:
    valid_ratio
    max_gap / obs_len
    anchor_lag / obs_len
    forecast_gap / obs_len
    valid_count / obs_len
    heading_degenerate
```

第一轮只把 mask-derived features 加入历史 token 或 actor token，不改变 decoder 和 loss。

**强对照**：

- 只拼 `gap_steps`；
- 只拼窗口级 summary；
- 二者同时使用只能作为后续累计版本，不能把其收益归因给单一字段。

### 5.3 P1-C：forecast-gap-conditioned query

**问题**：数据适配器以最后有效位置为 actor 锚点，但 decoder 对所有样本使用同一组未来时间 query。

若最后有效历史帧为 `l`，预测第 `j` 个未来点相对该锚点的时间应使用：

\[
\tau_j = (T_h-l+j)\Delta t.
\]

因此 P1-C 让 State Query 使用 per-actor `forecast_gap_steps`，而不是固定从 `0.4s` 开始。

**对照**：

```text
C0  固定 query（M0）
C1  仅加入 forecast_gap
C2  forecast_gap + P1-A pooling
```

C1 是时间语义修复，不直接宣称“新缺失建模理论”。

### 5.4 P1 的训练与晋级

P1 每个候选按如下顺序：

```text
screening：代表场景，固定 seed，快速判断方向
confirmation：五场景 Clean + Easy-direct + Hard-direct
```

正式候选不能只跑 Easy。P1 候选进入下一阶段必须满足：

- Clean 主指标不超过预注册回归容忍度；
- Easy 或 Hard 至少一个缺失分组有稳定改善；
- `minFDE/minADE` 的改善不能以明显牺牲 MR、ADE@1/FDE@1 或 b-minFDE20 为代价；
- 改善不能只由一个场景驱动；
- paired initialization 和相同 checkpoint 规则已确认。

若 A1/A2/A3 或 gap feature 已解释大部分收益，后续复杂 encoder 不得直接跳过这些强 baseline。

## 6. 阶段 P2：缺失分布与训练泛化

P2 只改变训练缺失分布，不改变模型结构，用来区分“结构不能处理缺失”和“训练没有见过该缺失程度”。

### 6.1 训练—测试矩阵

| 训练协议 | Easy test | Hard test | 用途 |
|---|---:|---:|---|
| Easy train | ✓ | ✓ | zero-shot 高缺失泛化 |
| Hard train | ✓ | ✓ | Hard train-adapt 与 Hard→Easy 交叉泛化 |
| Mixed 0–7 train | ✓ | ✓ | 已完成：naive Easy+Hard mixture；与 Hard-specific 接近，保留为 baseline/control |
| Clean train | ✓ | ✓ | 已完成：Clean→Easy/Hard 跨协议 zero-shot |
| Pattern-mixed train | ✓ | ✓ | 尚未执行：随机/连续/末端模式泛化（Benchmark 阶段） |
| Severity/evidence-balanced train | ✓ | ✓ | screening 已完成（2026-09-24）：不采用为主线，保留为 Benchmark 候选 |

`Mixed` 训练中的缺失等级应均衡或按预注册采样概率组织，不能在看到测试结果后调整采样比例。

### 6.2 P2 结果回答的问题

- P1 的收益是否只是对 Easy/Hard 训练分布的适配；
- M0 是否在 Easy→Hard zero-shot 时出现概率过度自信；
- 连续缺失、末端缺失是否明显比随机散点缺失更难；
- 在不增加参数的情况下，训练分布调整能否解释大部分收益。

### 6.3 P2 晋级门槛

若 Mixed 或 pattern-mixed training 在不改变模型的情况下已经解释主要收益，则将其保留为正式训练策略或强 baseline，不继续堆叠复杂 encoder。

若 P2 只能改善 train-adapt、不能改善 Easy→Hard zero-shot，论文结论应写成“分布适应有效”，不能写成模型具备普适缺失鲁棒性。

## 7. 阶段 P3：evidence-gated temporal state

P3 是第一条真正的核心机制路线。其目标不是再加一个 mask，而是区分：

```text
观测更新（observed update）
vs
缺口传播（gap propagation）
```

### 7.1 结构定义

对 actor `i`、历史时刻 `t`：

\[
h_{i,t}^{-}=P(h_{i,t-1},\Delta_{i,t})
\]

\[
h_{i,t}=m_{i,t}U(h_{i,t}^{-},o_{i,t})+(1-m_{i,t})h_{i,t}^{-}
\]

其中：

- `m=1`：观测有效，允许写入位置/运动证据；
- `m=0`：无新坐标，只进行 gap propagation；
- `o`：只由有效端点计算的运动特征；
- `Δ`：真实离散间隔或观测年龄。

第一版优先使用现有 Mamba block 外包装，不修改 selective scan kernel，减少依赖和 checkpoint 风险。

### 7.2 P3-A：GRU-D-style decay control

先做已有方法风格的强对照：

\[
\gamma_t=\exp(-\operatorname{ReLU}(W_\Delta\Delta_t+b)),
\quad h_t^- = \gamma_t\odot h_{t-1}.
\]

轨迹任务中不把位置简单衰减到数据集均值，而是分别处理：

- 位置：保持最后有效位置或进入运动传播；
- 运动：按 gap 和可靠性衰减；
- 场景上下文：较慢衰减。

GRU-D 作为 borrowed baseline，不作为原创点。

### 7.3 P3-B：single-state evidence gate

在 Mamba 外增加最小门控 wrapper：

```text
valid frame     -> propagation + observation write
missing frame   -> propagation only
```

对照必须包括：

```text
B0 M0 mask concatenation
B1 explicit gap feature
B2 GRU-D-style decay
B3 evidence-gated temporal state
```

### 7.4 P3-C：dual motion/context state

只有 P3-B 同时超过 B1/B2 后才执行：

```text
motion state   快速衰减，只消费 focal 运动证据
context state  慢速保留，可接收有效社会上下文
reliability gate 融合两者
```

不得把 motion/context 隐状态直接解释为人的真实心理意图或物理状态；它们只是模型中的两个功能状态。

### 7.5 P3 必须通过的机制测试

1. invalid coordinate perturbation：只改 masked placeholder，输出不变；
2. gap length：同样端点位移但不同 gap，状态传播不同；
3. all-valid：退化为 M0 或预注册的等价路径；
4. one-valid-frame：不产生 NaN，显式标记 heading unavailable；
5. padding isolation：padding actor 不影响真实 actor；
6. gap position：相同缺失数但不同位置不能被模型当作相同条件；
7. state ablation：固定 propagation 或固定 write，确认收益来自哪一部分。

### 7.6 P3 晋级门槛

- 超过 GRU-D-style 和显式 gap baseline；
- Hard m=6/7 或连续缺口至少一个关键指标稳定改善；
- Clean 和 Easy m=0 不发生不可接受回归；
- 多场景同向，不只改善 ETH 或单一场景；
- gain 对 invalid perturbation、gap-position 和 actor-order negative control 不敏感；
- 不依赖额外未来信息或测试集调参。

若 P3-B 不超过简单 decay，停止 P3-C，不继续加 dual state。

---

## 8. 阶段 P4：可靠性条件化的未来分布

P4 研究的是：缺失结构不仅影响历史表征，也应影响未来分布的可靠性。

### 8.1 reliability vector

由历史 mask 和可见证据构造：

```text
r = [
    valid_ratio,
    missing_ratio,
    max_gap,
    anchor_lag,
    forecast_gap,
    valid_count,
    heading_degenerate,
    neighbor_freshness
]
```

第一版只使用 mask-derived 特征，避免把隐变量过度解释为真实意图。

### 8.2 条件化位置

按风险从低到高分三步：

| 子阶段 | 条件化位置 | 目的 |
|---|---|---|
| P4-A | State Query / future time embedding | 修正不同预测起点与时间演化 |
| P4-B | mode logits / mode probability | 让证据量影响候选未来分支概率 |
| P4-C | scale / uncertainty head | 让低可靠性条件的分布宽度可表达 |

每一步都保留不条件化的前一版本作为 paired baseline。

### 8.3 不采用“强制缺失越多熵越大”

不能直接添加：

```text
missing ratio 越高 -> 强制 mode entropy 越高
```

这可能只制造无意义的分散预测。应优先使用：

- 原有未来损失保持不变；
- 评估 Energy Score、coverage、Brier、MR 和 ADE@1/FDE@1；
- 若要改变 loss，先单独验证 proper scoring rule，不与 decoder 结构同时改变。

Energy Score 可作为多模态分布的补充评估，因为它不只取最接近 GT 的样本；但它不能替代当前主指标，也不能在测试集上调权重。

### 8.4 P4 负对照

- reliability vector 置零；
- reliability vector 在 batch 内随机打乱；
- 只保留缺失比例、去掉 gap 位置；
- 只保留 forecast gap、去掉其他 summary；
- same encoder、不同 decoder condition。

如果打乱 reliability 后结果不变，不能声称 decoder 使用了有意义的观测可靠性。

### 8.5 P4 晋级门槛

除 minADE/minFDE 外，至少满足以下一项：

- MR 或高缺失 failure rate 稳定下降；
- b-minFDE20 / Energy Score 改善；
- coverage 与校准改善，且不以明显牺牲 minFDE 为代价；
- m=6/7 的 top-1 轨迹质量改善；
- 缺失程度与预测不确定性之间出现可解释、跨场景一致的关系。

如果只有 minFDE 下降而 MR、b-minFDE 或 coverage 恶化，判为概率质量失败，不晋级。

## 9. 阶段 P5：同步社会证据

P5 只有在 focal temporal mechanism 已经通过 P3 后执行。否则社会模块会和时序模块同时改变，无法归因。

### 9.1 P5-A：observation age-aware actor token

每个 actor token 增加：

```text
last_valid_idx
anchor_lag
forecast_gap
valid_ratio
```

attention 中显式提供 actor 的观测新鲜度，避免把不同时刻的最后有效位置当作同一时刻的社会几何。

### 9.2 P5-B：same-time synchronized social evidence

对于历史时刻 `t`，只聚合同一时刻有效的邻居：

\[
s_{i,t}=\operatorname{Attn}(q_{i,t},\{k_{j,t}:m_{j,t}=1\}).
\]

当 focal 缺失而邻居有效时，可以写入 context state；当邻居也缺失时，不得制造虚假社会证据。

### 9.3 必须的负对照

1. time-shuffled neighbors；
2. random-neighbor replacement；
3. neighbor co-missingness；
4. no-interaction / distant-neighbor subset；
5. actor-order permutation；
6. focal-only subset。

只有当真实同步邻居优于时间打乱和随机替换邻居，才可以把收益解释为 evidence transfer，而不是 token 数量或 generic social attention 的收益。

### 9.4 P5 晋级门槛

- 同步邻居证据在至少一个高交互子集改善；
- time-shuffle 后收益明显减弱；
- neighbor co-missingness 时补偿效果下降；
- actor order permutation 不产生不可接受波动；
- 远距离无交互子集不出现虚假的普遍收益。

若 P5 只带来整体平均误差下降，但 negative controls 不支持时间同步解释，则只记为社会编码工程增强，不写成证据转移机制。

## 10. 阶段 P6：最终确认、可靠性和跨域验证

### 10.1 最终候选必须完成

```text
Clean + Easy-direct + Hard-direct
五场景
至少 3 个 seed
```

确认轮固定：

- 相同数据版本；
- 相同训练 epoch、batch、optimizer 和 checkpoint 规则；
- 相同 K=20；
- 相同 macro/micro 聚合；
- 只改变最终方法相对于 M0 的声明变量。

### 10.2 训练分布泛化

最终模型至少报告：

```text
Easy train -> Easy test
Easy train -> Hard test
Mixed train -> Easy test
Mixed train -> Hard test
Hard train -> Hard test
```

这样分别回答 train-adapt、zero-shot 和 missing-distribution generalization。

### 10.3 扩展数据

SDD 或其他数据集只能在 TrajImpute 主线稳定后作为方向验证，不得用旧的自定义缺失结果替代官方 direct 主协议。扩展数据需要重新核查：

- 采样间隔；
- 坐标单位；
- actor 分组；
- 缺失生成方式；
- 训练/验证/测试隔离；
- 未来长度和评价阈值。

## 11. 路线决策树与停止规则

```text
P0 基线/数据/评估审计
  ├─ 失败：先修协议，不做方法结论
  └─ 通过
      ↓
P1 pooling + gap + forecast-gap query
  ├─ 简单修复已解释大部分收益：保留为强 baseline，重新做创新边界审查
  └─ 仍有高缺失失败
      ↓
P2 mixed/zero-shot training distribution
  ├─ 训练分布已解释主要收益：论文重点转向缺失分布泛化
  └─ 仍有结构性失败
      ↓
P3 evidence-gated temporal state
  ├─ 不超过 GRU-D/gap control：停止复杂 SSM 路线
  └─ 通过机制门槛
      ↓
P4 reliability-conditioned future distribution
  ├─ 只改善 best-of-K、概率质量恶化：停止或重做 loss
  └─ coverage/MR/calibration 也改善
      ↓
P5 synchronized social evidence
  ├─ negative controls 不成立：不宣称社会证据转移
  └─ negative controls 成立
      ↓
P6 多 seed、三环境、跨缺失分布确认
```

### 11.1 统一判胜条件

候选版本只有同时满足以下条件，才允许进入下一阶段：

1. Clean 不发生不可接受回归；
2. Easy 或 Hard 的缺失分组出现实际改善；
3. `minADE/minFDE/MR/ADE@1/FDE@1/b-minFDE` 不能出现明显指标分裂；
4. 多场景方向基本一致；
5. 收益能由本阶段新增机制解释；
6. 通过相应 negative controls；
7. 没有 test-set tuning、未来泄漏或 checkpoint 选择差异。

### 11.2 统一判负条件

出现以下任意情况，当前模块保留为 control，但不再叠加下一模块：

- 只改善一个小场景；
- 只改善 minFDE，MR 或 top-1 明显恶化；
- 简单 gap/decay baseline 已达到相同效果；
- all-valid 或 m=0 明显回归；
- 机制负对照不成立；
- 收益只出现在单一种子；
- 复杂模块增加参数但没有任务层收益。

如果 P1–P4 连续失败，正式 fallback 是：

> **TrajImpute 上缺失历史导致的多模态预测可靠性退化、场景差异和失败边界的系统性研究。**

这不是“没有方法”的空结果，而是需要以完整分组、zero-shot、概率质量和配对退化证据支撑的研究结论。

## 14. 根据历史失败实验修订后的执行顺序

本节覆盖并取代前述“直接继续 P1-A pooling”的默认顺序。历史实验已经提供了新的可用证据：

- S2 的 `last-valid + valid-mean pooling` 已完成配对筛选，但因 MR 牺牲判负；它保留为必要 control，不再作为主线候选；
- M1' 的 State Query 全局时间重参数化在 m=0 组也发生退化，说明替换原时间 embedding 会污染完整历史路径；
- B1、M1_obs、M2_history 多次表明朴素运动特征/缺失摘要拼接收益不稳定，不能继续按“再加更多 feature”推进；
- v1/v2 多种子实验表明约 ±5% 的种子波动真实存在，单种子小幅改善不得触发模块升级；
- TrajImpute M0 分组结果表明真正优先级是高缺失尾部的时间锚点、训练分布失配和未来分布可靠性。

因此，下一阶段固定为：

1. **D0：历史结果归因复核**——统一读取 M0/S1/S2/M1' 的 manifest、difficulty、checkpoint 和五指标，建立 paired subgroup 表；
2. **P0：M0 失败曲线冻结**——已完成；按 missing count、anchor lag、valid count、最长连续缺口和 MR/b-minFDE 分层，见《[D0/P0：M0缺失分层失败诊断](../results/D0_M0缺失分层失败诊断_K20.md)》；
3. **P2：训练分布泛化**——P2-A Easy→Hard zero-shot 与 P2-B Mixed 均已完成；severity/evidence-balanced screening 已裁定不采用为主线（2026-09-24），结果见《[采样策略逐场景对照](../results/采样策略逐场景对照.md)》；
4. **尾部诊断审计**——基于已有 artifacts 分层 missing=6/7、valid_count=1、长 gap，确认训练分布调整未解决的尾部失败；
5. **P3-A：GRU-D-style decay control**——作为最便宜的时间间隔强对照，不先做复杂 Mamba 改造；
6. **P3-B：single-state evidence-gated temporal state**——只有在 P3-A 和显式 gap control 仍无法解释高缺失失败时执行；
7. **P4：reliability-conditioned decoder**——以 additive、zero-init、identity-preserving 方式把 reliability 进入 query/logit/scale，禁止全局替换原时间 embedding；
8. **P5：同步社会证据**——最后执行，并必须通过 time-shuffle、random-neighbor、co-missingness 负对照；
9. **P6：三环境、多种子、缺失模式确认**。

`P1-A mask-aware pooling`、`P1-C 全局 forecast-gap query` 和历史 B1/M1_obs/M2_history 不再作为未跑主线，而是进入 control/负证据库。若需要再次研究 pooling，只能提出新的、严格 identity-preserving 且不牺牲 MR 的版本，不能重复原 S2。

每一阶段结束时只做一次裁定：**晋级、保留为 control、或停止该路线**。不把多个未裁定模块合并成“累计提升”。

## 15. 最新结论与路线裁定（基于历史实验）

### 15.1 已经可以确认的事实

1. **M0 的核心失败在高缺失尾部。** TrajImpute 五场景分组中，Easy m=0→m=4 的 MR 增长明显快于 minFDE；Hard m=4→m=7 的 minFDE 和 MR 均发生数量级退化。研究重点应从平均误差转向高缺失可靠性。
2. **训练分布失配是独立变量。** 历史 zero-shot 与 train-adapt 的差异表明，不能把所有退化归咎于 M0 结构；必须先完成 Easy/Hard/Mixed 矩阵。
3. **简单输入特征工程没有形成稳定收益。** B1 的宏平均和微平均方向相反，M1_obs/M2_history 在 v3 首筛中均不超过 M0；这否定的是朴素拼接路线，不是否定所有缺失建模。
4. **全局 decoder 重参数化是高风险路径。** M1' 的 m=0 退化说明，即便条件变量在语义上合理，替换共享 State Query 时间基底也会污染完整历史路径。
5. **pooling alone 不足以解决问题。** S2 已完成等价性和配对初始化修复，但仍因 MR 牺牲判负；因此“最后有效帧读取”只能保留为 control，不能作为主方法。
6. **社会证据尚未获得可引用的正结论。** 旧社会补偿路线已判负并清理，不能声称邻居证据无效；但下一版必须先解决时间同步和邻居可靠性，再谈社会补偿。

### 15.2 最新研究判断

当前最合理的研究假设不再是：

```text
给 M0 增加更多缺失特征 -> 性能提升
```

而是：

```text
缺失观测减少可靠证据
    -> 历史状态应区分“观测更新”和“缺口传播”
    -> 预测起点/观测年龄必须显式建模
    -> 未来 mode probability、scale 和风险应随证据可靠性变化
```

因此推荐的主线变为：

> **evidence-aware multimodal forecasting：用观测更新—缺口传播分离的历史状态，结合可靠性条件化的未来分布，处理缺失历史下的多模态预测退化。**

该主线的最小可证伪版本是：

```text
M0
 -> Mixed missingness training
 -> GRU-D-style decay control
 -> single-state evidence gate
 -> reliability-conditioned decoder
```

不先加入双状态、复杂社会模块、辅助重建头或新的生成目标。

### 15.3 历史失败结果的使用边界

| 历史实验 | 当前归类 | 可以支持的结论 | 不能支持的结论 |
|---|---|---|---|
| v1/v2 多种子缺失实验 | 诊断证据 | 种子波动约 ±5%；高缺失与连续缺失需要分层 | 某个小幅差异是结构收益 |
| v3 M0/M1_obs/M2_history | 负 control | 朴素观测特征/摘要拼接不稳定 | 所有缺失感知方法都无效 |
| B1 运动特征 | 场景依赖 control | 运动特征不是稳定共享骨干增强 | 运动证据完全没有价值 |
| M1' evidence clock | 负 control | 全局替换 State Query 时间基底会污染 m=0 | forecast gap 信息本身无价值 |
| S2 pooling | 负 control | pooling alone 不足，且需保护 MR | 最后有效帧表示一定错误 |
| 旧 M2 社会补偿 | 已关闭 control | 未通过当前归因和可靠性要求 | 社会交互在缺失条件下无用 |

### 15.4 下一轮实验的硬门槛

候选方法进入正式训练前必须通过：

1. **identity test**：all-valid 与 M0 bitwise 或预注册容差等价；
2. **invalid perturbation**：改变 masked placeholder 不改变输出；
3. **paired initialization**：双方共享同一 backbone state；
4. **m=0 protection**：完整历史组不被条件分支污染；
5. **five-metric gate**：minADE、minFDE、MR、ADE@1/FDE@1、b-minFDE20 一起裁定；
6. **high-missing gate**：必须单独报告 m=6/7 或等价高缺失分组；
7. **macro/micro agreement**：若宏平均和微平均方向相反，标记为场景依赖，不得直接判胜；
8. **seed gate**：首轮结果差异小于历史种子波动带时，不得晋级；
9. **cheap-baseline gate**：必须超过简单 gap feature 和 GRU-D-style control，才考虑 evidence-gated SSM；
10. **negative-control gate**：社会证据必须通过时间打乱和随机邻居对照。

### 15.5 No-Go 与 fallback

若 Mixed training、GRU-D control、evidence gate 连续不能改善高缺失可靠性，停止继续堆叠编码器，转向：

> **TrajImpute 上缺失历史导致的多模态预测可靠性退化、场景差异、训练分布泛化和失败边界的系统性研究。**

该 fallback 由现有证据支持，不是把失败实验包装成成功方法：M0 已有官方 direct 结果、按缺失等级的明显退化、zero-shot/train-adapt 差异、场景依赖和概率指标分裂，足以构成可验证的诊断型研究问题。
