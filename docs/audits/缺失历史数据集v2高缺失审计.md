## 4. 模型接口冒烟（方案 §7.2）

脚本 `scripts/审计与校验/smoke_v2_model_interface.py`，GPU 3，5 条件 × {ETH/UCY, SDD}，每条件 64 样本（ETH 用 fold=ETH/test），Dataset → collate → `ModelForecast(use_map=False, dt=0.4, num_modes=20)` 真前向（`use_map` 为当时的接口参数，仓库收缩后已移除，此处为历史记录）：

- 前向输出全部有限（无 NaN/Inf）；
- 真实 agent 帧 6/7 恒可见，每个真实 agent ≥2 个可见历史帧（block6 下成立）；
- 缺失步的 x_positions_diff / x_velocity / x_velocity_diff / x_angles 全为 0（velocity_diff 按两步位移合法性判定）；
- x_centers == 帧 7 位置（最后有效历史位置）；
- ETH/UCY 多行人 actor token 保留（含邻居）；SDD actor 维恒为 1；
- target / target_mask 未被掩码污染（真实 agent 上 target_mask 全 True）。

**10/10 全部 PASS。**

注：collate 对 agent 维做 padding（x_valid_mask/target_mask 的 padding 槽位为 False 是设计行为）——所有断言只作用于真实 agent（x_key_valid_mask 选择），与 v1 口径一致。
