## 0. 第三轮 P1 修复（外部审查反馈）

1. **`x_velocity_diff` 掩码不完整（P1）**：旧逻辑只检查当前步 `diff_mask[t-1]`，未检查前一项速度来源。最小复现（帧 0 缺失、匀速轨迹）：`velocity=[0,0,1,1,...]` → `velocity_diff=[0,0,1,0,...]`，第 2 项是「缺失置零→正常速度」的人为突变，且该字段直接进模型输入。已修 5 处 dataset（ethucy_benchmark / moflow_sdd / sdd_missing / ethucy / moflow_ethucy）：`velocity_diff[t]` 要求 t 与 t-1 两步位移均有效（t=1 只需首步有效，与完整数据语义一致，因 `velocity[0]` 恒 0）；同时补齐 ethucy_dataset / moflow_ethucy_dataset 的 `velocity` 掩码。抽样扫描 sdd+ethucy 两条件全部 0 违例，complete 数据保留真实加速度。
2. **模型时间查询回归 AV2（P1）**：原基线 `arange(60)*0.1+0.1`（AV2 dt=0.1s）被硬编码改为 0.4，导致 AV2 模型查询时间 0.1–6.0s 变 0.4–24.0s。已参数化为 `ModelForecast(dt=...)`，**默认 0.1 保持 AV2 兼容**；4 个 ETH/UCY model conf 显式 `dt: 0.4`（moflow_ethucy / bimamba / ethucy_benchmark / ethucy）。Hydra 组合验证：AV2 `config` → dt 缺省 0.1；`config_ethucy_benchmark`、`config_moflow_sdd` → dt=0.4。
3. **`train.py` 默认配置缺 `precision`（P1）**：`config.yaml`（AV2 默认入口）无 `precision` 字段，Hydra composition 报 missing。已补 `precision: 32-true`（AV2 常规精度；ETH/UCY benchmark 配置仍覆盖为 bf16）。

次要项：`scripts/训练与评估/run_ethucy_benchmark.py` 的 `--data-root` 现已透传给 train.py/eval.py（此前声明了但无效）；`model_forecast.py` trailing whitespace 清除（`git diff --check` 干净）；说明文档 §5.1 补「占位坐标」语义说明（缺失位置经局部变换后非 0，仅靠 mask 区分，所有派生量已置零/跳过）。

第三轮验证：pytest 47 passed；CUDA 接口 smoke（3 条件 × ETH/UCY+SDD，SddMissingDataset + 修复后 diff/angles/velocity/velocity_diff 语义）全过。

## 2. 第二轮整改内容（相对第一轮的变更）

### 2.1 上游覆盖 bug（根因修复）

- **问题**：`ethucy_benchmark_preprocess.py` 对同一 `(fold, split, scene)` 下的多个源 .txt 都从 `000000.pt` 编号，后写覆盖先写。17 个组受影响（UNIV/ZARA2 的 train/val/test），manifest 记录 181,542 个样本、磁盘只剩 119,875，**静默丢失 61,667 个（34%）**。第一轮 missing_v1 继承了该缺陷。
- **修复**：输出文件名改为 `<source_stem>__<NNNNNN>.pt`（如 `students001_train__000123.pt`）。
- **重建**：从 `/home/lbh/MoFlow/data/eth_ucy/original`（74 个 .txt，source_manifest 含 sha256）重新生成 `data/ETHUCY_benchmark_v1`：181,542 样本，逐源文件计数 74/74 全对，官方 audit 脚本全量通过（invalid_focal=0, nan=0, 无跨 split 重叠）。
- 另修复 preprocess 的 source_manifest 格式 bug（`build_manifest()` 返回裸结构未包裹 `{"folds": ...}`，导致二次运行 KeyError）。

### 2.2 掩码身份键加入 source_file

- 身份键：`dataset|fold|split|scene_id|source_index|source_file|focal_id|condition|mask_seed`
- 动机：重建后同一 `(fold,split,scene)` 下不同源 .txt 的 `sample_index` 各自从 0 计，不含 source_file 时不同源的同号样本会得到相同掩码（碰撞）。
- 说明文档 §3.3 与两套 manifest 的 `mask_rng_key_format` 已同步更新。
- 审计脚本以独立重实现的 `expected_mask` 对全部样本复推掩码，逐位一致。

### 2.3 x_angles / velocity 掩码语义修复

- `ethucy_benchmark_dataset.py` 与 `moflow_sdd_dataset.py`（及新 `sdd_missing_dataset.py`）：涉及缺失帧的相邻步 `x_angles` 置零；SDD 侧 `velocity` 补上 `diff_mask`（此前只掩了 diff 未掩 velocity）。
- 影响面：模型 forward 只用 `x_angles[..., -1]`（帧 7←6，v1 恒可见）与 `x_centers`（帧 7 位置），数值行为不变；此修复保证「缺失历史不参与任何派生量」的协议整洁性（§5.3）。
- 此前已修复 `compute_theta` 回溯掩码盲区（第一轮，2.92% 样本 theta 读到垃圾位移）。

### 2.4 新增 SDD missing 读取管线

- `src/datamodule/sdd_missing_dataset.py`：读 `data/SDD_missing_v1/<condition>/<split>/*.pt`，掩码感知 process，focal=唯一行人。
- `src/datamodule/sdd_missing_datamodule.py` + `conf/datamodule/sdd_missing.yaml`（`condition: complete|random_single|random_block2` 覆盖）。
- 对齐验证：3 条件 × 3 split 与 `MoFlowSddDataset` 抽样 50 条/组核对 origin/theta，全部一致（样本顺序与 split 归属相同）。

## 6. 复现命令

```bash
# 1. 重建 benchmark（源文件级命名，无覆盖）
PYTHONPATH=scripts python3 src/datamodule/ethucy_benchmark_preprocess.py \
    --raw-root /home/lbh/MoFlow/data/eth_ucy/original --output-root data/ETHUCY_benchmark_v1

# 2. 生成 missing_v1（身份键含 source_file）
python3 scripts/数据集构建/build_missing_history_dataset.py --dataset ethucy \
    --source-root data/ETHUCY_benchmark_v1 --output-root data/ETHUCY_missing_v1 \
    --conditions complete random_single random_block2 --mask-seed 42
python3 scripts/数据集构建/build_missing_history_dataset.py --dataset sdd \
    --source-root data/sdd --output-root data/SDD_missing_v1 \
    --conditions complete random_single random_block2 --split-seed 2024 --mask-seed 42

# 3. 全量审计
python3 scripts/审计与校验/audit_missing_history_dataset.py --dataset ethucy \
    --data-root data/ETHUCY_missing_v1 --source-root data/ETHUCY_benchmark_v1 --full
python3 scripts/审计与校验/audit_missing_history_dataset.py --dataset sdd \
    --data-root data/SDD_missing_v1 --source-root data/sdd --full
```

训练入口（第一轮实验，§11）：ETH/UCY 侧 Dataset 根目录指向 `data/ETHUCY_missing_v1/<condition>`；SDD 侧用 `conf/datamodule/sdd_missing.yaml`（改 `condition` 字段）。
